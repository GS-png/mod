- `docs/验证与发布/`：启动自检、手工脚本、回归记录、压力测试和发布检查表。

## 构建闸门
1. 先运行 `dotnet build .codex/tmp/neomod_smoke/EraWheel.NeomodSmoke.csproj`。
2. 这一步的作用很像“先看零件能不能拼上”。它证明当前源码、命名空间和引用关系至少还能编。
3. 再按 `docs/验证与发布/` 里的手工脚本进实机验证。尤其是 `EW-114` 到 `EW-119` 这些记录。
4. 没有真实 WorldBox 结果前，不把“编译通过”写成“已经实机通过”。
