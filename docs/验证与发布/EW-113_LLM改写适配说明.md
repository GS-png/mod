# EW-113 LLM 改写适配说明

## 记录目的
- 这份说明对应 `EW-113`。
- 它只解释“故事改写适配层现在怎么接”，不替代故事素材本身。
- 当前设计还没有指定唯一外部服务，所以这里先把接口和离线兜底讲清楚。

## 当前口径
- `Observed`：故事列表、年份分章和结构化导出继续完全依赖真实事件素材，不受 LLM 配置影响。
- `Observed`：当前代码已经补上 `EraStoryRewriteService` 和 `IEraStoryRewriteAdapter`，故事窗口可以额外导出 `JSON` 请求包和 `Markdown` 提示词。
- `Observed`：默认适配器是 `disabled`。也就是没接外部服务时，只会提示“当前未配置在线改写器”，不会挡住故事列表和普通导出。

## 现在能怎么用
1. 先照常在故事窗口查看结构化素材。
2. 如果想把这些素材交给外部模型处理，点击 `导出 LLM 改写请求`。
3. 系统会在 `StoryExports/Rewrite` 目录里同时写出一份 `JSON` 素材包和一份 `Markdown` 提示词。
4. `尝试在线改写` 这个按钮已经接到适配层，但只有未来真正接入桥接器后才会产出改写结果。

## 环境变量
- `ERAWHEEL_STORY_REWRITE_ADAPTER`：当前只识别 `disabled` 或留空。
- 如果以后要接新的在线桥接器，就继续沿这个环境变量扩展，不把密钥或服务地址写死进仓库。

## 已知边界
- `Unknown`：最终会接哪家 LLM、走什么鉴权方式、返回什么字段，设计文档当前没有定死。
- `Observed`：因此这轮只把“可插拔接口 + 离线请求包 + 非阻断兜底”落地，不虚构一个未经确认的第三方协议。
