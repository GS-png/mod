# EW-116 多魔王全量轮回手工脚本

## 记录目的
- 这份脚本对应 `EW-116`。
- 目标是用同一套流程把 `联盟`、`内战`、`随机` 三种多魔王互动模式都走一遍。
- 它关心的是“模式有没有切对、军团有没有继续跑、结算有没有守住最后一名魔王死亡这个口径”。

## 前置准备
- `Observed`：当前运行态摘要已经会显示 `多魔王模式=...`，并持续记录事件流水。
- 建议至少启用 `3` 名魔王，把 `苏醒数量` 调到 `2` 或更高；候选池数量大于苏醒数量时，本轮名单会从启用魔王池里稳定随机抽取。
- 建议继续开启开发模式，用调试窗口快速跳到预兆、苏醒、降临。

## 通用流程
1. 启动环境，先确认启动自检通过。
2. 打开参数页，把本轮启用魔王调到至少 `3` 名，`苏醒数量` 调到 `2` 或更高；如果要指定具体魔王，就只启用那一组魔王。
3. 使用调试窗口依次跳到 `预兆`、`苏醒`、`降临`。
4. 在轮回运行态确认 `本轮魔王 >= 2`、`据点绑定 >= 2`、`军团波次 >= 1`。

## 联盟模式脚本
1. 把互动模式设为 `联盟`。
2. 进入降临后确认运行态显示 `多魔王模式=联盟`。
3. 观察多名魔王之间不会互打，但军团仍会继续攻击王国。
4. 收尾时进入战后重建，确认不会因为其中一名魔王先死亡就提前结算。

## 内战模式脚本
1. 把互动模式设为 `内战`。
2. 进入降临后确认运行态显示 `多魔王模式=内战`，并观察魔王之间会互相敌对。
3. 如果自然打出了唯一胜者，确认事件流水出现 `civil_war_winner` 相关记录。
4. 即使本轮只先验证关系切换，也要确认内战不会让系统忘记继续攻击王国。

## 随机模式脚本
1. 把互动模式设为 `随机`。
2. 进入降临后先记录一次当前关系说明。
3. 再等待至少一个 `关系校验间隔`，或多次刷新运行态。
4. 期望看到关系说明能在联盟与内战口径之间重掷，且事件流水能反映这次重算。

## 通过标准
- 三种模式都能进入对应状态，军团出波不会因为多魔王互动而停摆。
- 联盟不友伤，内战会互打，随机会按间隔重掷关系。
- 全轮结算仍然以“最后一名存活魔王死亡”为准，而不是谁先退出谁就算结束。

## 未验证边界
- `Unknown`：在真实长局里自然跑出“内战胜者 + 正常结算”的耗时和稳定性，还需要后续继续回填记录。
