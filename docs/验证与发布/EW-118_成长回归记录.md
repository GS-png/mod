# EW-118 成长回归记录

## 记录目的
- 这份记录对应 `EW-118`。
- 它把 `轮回进阶`、`等级`、`王国`、`英雄` 四条成长线放到同一轮里联测。
- 要看的不是某一条线能不能单独跑，而是四条线叠在一起后顺序对不对、结果会不会存住。

## 当前证据
- `Observed`：轮回结算后会推进世界档位，并刷新王国档位、魔王换装和幸存王国信息。
- `Observed`：等级系统会给 Actor 写等级账本，连续升多级时按级数逐次结算，不是一次打包糊过去。
- `Observed`：王国系统会维护声望账本，并按累计总声望即时升级，不消耗也不清零。
- `Observed`：英雄系统会维护晋升状态、英雄档案、血脉继承和幸存强化；单位详情页与王国详情页已经有对应摘要入口。
- `Unknown`：仓库里没有真实实机世界，所以这份文档先给联测脚本，还没有填入最终结果。

## 联测前准备
1. 启动后先看 [EW-114_启动自检清单.md](EW-114_启动自检清单.md)。确认没有阻塞项。
2. 用 [EW-115_单魔王完整轮回手工脚本.md](EW-115_单魔王完整轮回手工脚本.md) 或 [EW-116_多魔王全量轮回手工脚本.md](EW-116_多魔王全量轮回手工脚本.md) 跑出一轮完整战斗。
3. 选一个固定观察对象。最好同时选 `1` 名单位和 `1` 个王国，这样前后对比不容易串台。

## 第一段：轮回进阶线
1. 在本轮结算前记下 `世界档位`、目标王国摘要、目标单位当前穿戴与特质实例。
2. 完成战后结算后，确认 `世界档位` 按当前推进模式正确变化。
3. 再打开王国详情页。确认王国档位摘要和当前模式说明能对上。
4. 如果本轮发放了轮回装备或轮回特质实例，要确认它们在详情页里能看到实例属性摘要。

## 第二段：等级线
1. 选定观察单位后，记录它当前等级和详情页里的“等级加成”摘要。
2. 让它连续升至少 `2` 级。这样可以验证“逐级结算”有没有漏账。
3. 升级后重新打开单位详情页。确认摘要是累计后的总加成，不是只显示最后一级。
4. 读档或切换界面回来后再看一次。确认等级账本不会重抽，也不会少一段。

## 第三段：王国线
1. 记录目标王国当前总声望、当前声望等级和王国详情页摘要。
2. 让王国继续发展，直到至少跨过一次声望阈值。
3. 升级后确认王国详情页里的声望等级、累计账本和档位摘要一起变化。
4. 如果王国已经是幸存王国，还要确认它的档位读取口径和当前模式一致。
5. 连续新建 `2` 个世界，各自让同序号的早期王国升到 `Lv1`。确认日志里的世界指纹或本轮种子不同，也确认不会稳定重放同一组声望属性。

## 第四段：英雄线
1. 记录目标王国当前英雄数量，以及是否已有待晋升候选。
2. 触发一次繁荣链或危机链，观察是否真的选出命定英雄。
3. 晋升后打开单位详情页。确认能看到英雄状态、称号后缀、晋升加成和承袭加成。
4. 如果该英雄活到轮回结算，再确认幸存强化只发一次，且跨轮还能保留。

## 串线检查
- 轮回进阶不能把等级账本冲掉。
- 王国声望升级后，英雄和普通单位读到的王国加成要一致。
- 英雄晋升后拿到的新装备或新特质实例，不能覆盖掉已有实例属性。
- 跨轮之后，上一轮留下的成长结果要还能在运行态、HUD、单位页、王国页里对上。

## 通过标准
- 四条成长线都能在同一轮里跑通。
- 叠加顺序稳定，读档后不重抽、不回滚、不重复发放。
- 玩家能从运行态页、单位详情页和王国详情页直接看出成长结果，没有隐藏账。

## 当前边界
- `Observed`：代码已经有等级账本、王国声望账本、英雄档案和幸存强化逻辑。
- `Unknown`：真实长局里四线同开时的边角情况，比如连续晋升、读档后继续升级，还需要实机继续补记录。
