# EW-114 启动自检清单

## 记录目的
- 这份清单对应 `EW-114`。
- 它帮助新手知道：EraWheel 启动时到底查了哪些东西，为什么有些问题会直接拦住加载。
- 当前口径是：`错误` 直接阻断启动，`警告` 只提示但不拦截。

## 当前覆盖项
- `Observed`：参数与版本。会检查轮回阶位上限、苏醒数量、英雄上限、魔王池、配置迁移器和备份策略。
- `Observed`：实体自定义键。所有 `custom_data_*` 键都必须唯一，避免不同系统互相踩数据。
- `Observed`：内容清单。魔王、将领、军团、据点、公共特质、轮回装备、轮回特质的数量和绑定关系都要对齐设计。
- `Observed`：静态资源。名称、摘要、图标路径、模板 ID、资源 ID、装备槽位、据点 footprint 和 `BuildingFundament` 都会检查。
- `Observed`：缺图、重 ID、参数非法现在都按启动错误处理，不再只是记日志继续跑。

## 怎么看结果
1. 启动时先看 `[校验]` 分类日志。
2. 如果看到“启动校验通过”，说明当前没有阻塞项。
3. 如果看到 `EraWheel 启动自检失败`，就先按同批 `[校验]` 日志里的条目逐个修。
4. 自检通过后，运行态摘要里还能看到 `校验：错误=x；警告=y。` 的汇总。

## 当前边界
- `Observed`：图标缺失现在按错误处理，因为设计要求“缺图启动即报错”。
- `Unknown`：真实 WorldBox 运行时里，个别上游资源是否会因为平台路径差异表现不同，还需要进游戏继续确认。
