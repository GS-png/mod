# 纪元之轮：魔王轮回

WorldBox AI协作叙事MOD

## 安装

1. 确保已安装 [NeoModLoader](https://github.com/WorldBoxOpenMods/NeoModLoader)
2. 将 `EraOfWheel` 文件夹复制到 WorldBox 的 Mods 目录
3. 启动游戏

## 功能

- **轮回系统** - 纪元阶段循环，遗产继承
- **魔王系统** - 10个独特魔王，双向进化
- **AI叙事** - LLM驱动的动态事件生成

## 配置

编辑 `Resources/Config/config.json` 配置API密钥和游戏参数。
