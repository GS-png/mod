# Game Brief: 纪元之轮

**Date:** 2026-01-17
**Author:** 吴旭
**Status:** Draft for GDD Development

---

## Executive Summary

《纪元之轮：魔王轮回》是一款基于WorldBox的AI协作叙事MOD，让玩家与AI一起创造独一无二的文明史诗。

**目标受众：** WorldBox沙盒爱好者 + AI技术好奇者（18-35岁）

**核心支柱：** 动态叙事、轮回进化、AI协作、可配置深度

**关键差异化：** 首款LLM接入的WorldBox MOD、轮回进化系统、十大魔王机制库

**平台：** PC（WorldBox MOD）

**成功愿景：** 成为WorldBox社区最受欢迎的叙事MOD，开创AI+沙盒游戏的新赛道

---

## Game Vision

### Core Concept

一款基于WorldBox的AI协作叙事MOD。通过接入LLM API，玩家可以与AI进行交互式对话——AI作为"智能上帝"操控世界演化，玩家作为"观察者上帝"指导、提问或纯粹欣赏。文明与十大魔王在轮回中不断对抗，每次封印后双方都会带着记忆与遗产进入下一纪元，最终走向诸神黄昏或文明永恒守护。

### Elevator Pitch

《纪元之轮：魔王轮回》是首款支持LLM接入的WorldBox史诗叙事MOD。你可以与AI进行自然语言对话，让它代替你操控世界——"让虚无之主提前苏醒"、"帮助人类建立联盟"、"加速这场战争"——或者纯粹作为观察者，看AI如何演绎一场独一无二的文明史诗。无论你是沙盒观众、挑战玩家还是剧情党，都能在这个会"自己思考"的世界中找到沉浸体验。

### Vision Statement

《纪元之轮》的愿景是创造一个会自己思考、会与你对话的世界。我们相信最好的游戏故事不是被编写出来的，而是在人类创意与AI智能的协作中自然涌现的。玩家可以是全知全能的干预者，也可以是悠闲旁观的看客——而AI将成为你最好的"共同创作者"，理解你的意图，演绎你的史诗。每一次轮回都是一场独特的AI协作叙事实验。

**核心动机：**

**市场机会：**
- "首款LLM接入的WorldBox MOD"——独特定位，无直接竞品

**竞争优势：**

- 轮回+遗产系统提供无限重玩价值

## Game Fundamentals

### Core Gameplay Pillars

**1. 动态叙事 (Emergent Narrative)**
世界自己"起承转合"，AI驱动的史诗自然涌现。每一局都是独一无二的文明兴衰史。

**2. 轮回进化 (Cycle Evolution)**
每次轮回双方都会变强——魔王学会新策略，文明继承遗产。无限重玩价值的核心驱动。

**3. AI协作 (AI Collaboration)**
LLM接入实现自然语言交互，玩家可与AI对话操控世界，成为真正的"上帝协作者"。

**4. 可配置深度 (Configurable Depth)**
大量参数可调，从轻松观影到硬核挑战，适配所有玩家类型。

**支柱优先级：** 当支柱冲突时：动态叙事 > 轮回进化 > AI协作 > 可配置深度

### Primary Mechanics

**核心动作：**
- **观察** - 观看世界自动演化、文明兴衰、魔王入侵
- **对话** - 与LLM交互，下达指令、询问状态、请求解说
- **干预** - 触发事件、加速魔王苏醒、帮助文明建立联盟
- **配置** - 调整参数、启用/禁用魔王和系统模块

**核心循环：**
观察演化 → 发现有趣/危机时刻 → 对话/干预 → 观察结果 → 轮回结算 → 纪元遗产继承 → 下一轮回

### Player Experience Goals

**情感体验目标：**
- **惊奇/发现** - 看到AI演绎出意想不到的剧情转折
- **紧张/释放** - 魔王入侵高潮 → 封印成功的解脱
- **掌控/协作** - 与AI对话操控世界的神一般体验
- **成长/积累** - 纪元遗产让下一轮回更有意义

**情感旅程：**
好奇观察 → 投入关注 → 紧张对抗 → 满足封印 → 期待下一轮回

## Scope and Constraints

### Target Platforms

**主平台：** PC（Windows）
**依赖：** WorldBox 0.51.2+ + NeoModLoader
**分发：** MOD社区/Steam创意工坊（待定）

### Budget Considerations

**开发模式：** 自费业余项目
**成本控制：**
- 开发工具：免费/已有（Unity、VS Code等）
- 美术资源：复用WorldBox原有资源 + 简单扩展
- LLM API：按需付费，需考虑成本控制策略
- 营销：社区驱动，低成本传播

### Team Resources

**团队规模：** Solo开发者
**投入时间：** 业余时间开发
**技能覆盖：** 设计 + 编程（C#/Unity）

**技能缺口：**
- 美术（依赖原版资源）
- 音频（依赖原版资源）
- 市场推广（社区自然传播）

### Technical Constraints

**引擎/框架：** Unity（WorldBox基础）+ NeoModLoader
**语言：** C#
**LLM集成：** 外部API调用（需网络连接）

**性能约束：**
- 大地图 + 多单位 + AI计算需优化
- 毒雾/火焰等效果需上限保护
- LLM响应延迟需异步处理

**容错设计：**
- LLM失败时切换到后备事件池
- 参数异常自动回退默认值
- 存档兼容性保护

### Scope Realities

**MVP优先：** 先实现核心轮回+1-2个魔王，验证玩法后再扩展
**迭代策略：** 版本规划已在设计文档中明确
**风险意识：** Solo业余项目，进度弹性大，功能可裁剪

## Reference Framework

### Inspiration Games

**WorldBox**
- 借鉴：上帝模拟、世界自动演化、沙盒自由度、像素美学
- 不借鉴：静态世界状态、缺乏深度叙事结构

**AI Dungeon**
- 借鉴：LLM驱动的动态叙事、自然语言交互模式
- 不借鉴：纯文字体验、缺乏可视化

**Rimworld / Dwarf Fortress**
- 借鉴：涌现叙事、复杂系统交互产生的故事
- 不借鉴：高微操强度、陡峭学习曲线

**Roguelike类（杀戮尖塔等）**
- 借鉴：轮回机制、每局不同、Meta进度
- 不借鉴：玩家直接操作角色、战斗为核心

### Competitive Analysis

**直接竞品：**
- WorldBox原版（成熟稳定，但无深度叙事和AI交互）
- 其他WorldBox MOD（扩展丰富，但无LLM整合）
- AI Dungeon类产品（LLM叙事成熟，但无可视化沙盒）

**竞品优势：** 成熟度高、用户基数大、生态完善
**竞品劣势：** 无LLM+沙盒结合、缺乏轮回进化系统、交互方式传统

### Key Differentiators

1. **首款LLM接入的WorldBox MOD** - 独特市场定位，无直接竞品
2. **轮回进化系统** - 魔王与文明双向成长，提供无限重玩价值
3. **十大魔王机制库** - 丰富的玩法变化和叙事可能性
4. **观察者上帝模式** - AI操控世界+玩家对话指导的创新交互

**独特价值主张：**
"首款让你与AI一起创造史诗的WorldBox MOD——你对话，AI演绎，世界自己写故事。"

## Content Framework

### World and Setting

**神话体系：** 《混沌分裂纪》
- 太初纪元：原初之神「阿卡莎」将混沌之核分裂为十大魔王
- 封印契约：光明诸神耗尽神力将魔王封印于世界各处
- 轮回法则：文明繁荣触发封印松动，魔王苏醒

**氛围：** 史诗、轮回、命运对抗、文明兴衰

### Narrative Approach

**叙事方式：** 涌现叙事（Emergent Narrative）
- AI叙事引擎动态生成事件描述
- 后备事件池（200+预设事件）保证无LLM时也能运行
- 玩家通过UI面板和对话获取叙事内容

**故事交付：** 事件弹窗 + AI对话 + 状态面板

### Content Volume

- 10个魔王系统（每个独立机制）
- 200+预设事件库
- 6个纪元阶段（发展→预兆→苏醒→入侵→封印战→重建）
- 可配置参数系统

## Risk Assessment

### Key Risks

1. **LLM API成本/延迟** - 高可能性/中影响
2. **功能蔓延** - 高可能性/高影响
3. **性能问题** - 中可能性/高影响
4. **Solo进度风险** - 高可能性/中影响

### Technical Challenges

- 大地图+多单位+AI计算的性能优化
- LLM异步调用和超时处理
- 存档兼容性和版本升级

### Market Risks

- MOD可发现性依赖社区传播
- WorldBox版本更新可能破坏兼容性

### Mitigation Strategies

- **后备事件池**：LLM失败时无缝切换
- **参数上限保护**：避免数值爆炸和性能崩溃
- **MVP优先**：先验证核心玩法再扩展
- **版本迭代**：功能可裁剪，进度弹性大
- **社区运营**：视频演示、口碑传播
