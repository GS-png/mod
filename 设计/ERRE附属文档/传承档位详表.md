## 传承档位详表

### 表头说明
- 表内多行用 `<br>` 分行。
- 字段含义以表头为准。
- 装备槽位使用：武器/头盔/护甲/靴子/戒指/护符。
- 数值与参数只做清单，不含实现规则。

### 效果表达规范
- 描述顺序：触发 → 概率 → 条件 → 效果 → 持续 → 限频。
- 未写概率视为 `100%` 触发，但仍受限频。
- 触发只使用：常驻、命中、受击、死亡点、主动。
- 主动表示消耗法力触发，并带冷却。
- “短眩晕/短混乱/短减速”使用原版默认时长。
- 低血未写阈值时，默认 `30%`。
- “回填”表示受击后恢复本次伤害的比例。
- “控制时长缩短”仅作用于 MOD 施加的控制。
- “当前生命伤害”最低保留 `1HP`。

### 可实现映射表
| 术语 | 实现口径 |
|---|---|
| 伤害/生命/防御/移速/攻速/命中/暴击 | 对应 `属性字段速查`；百分比写 `base_stats_meta` |
| AOE系数 | `area_of_effect`（`base_stats_meta`） |
| 状态触发概率 | `status_chance`（`base_stats_meta`） |
| 回血/回蓝 | `Actor.restoreHealthPercent` / `Actor.restoreManaPercent` |
| 当前生命伤害/固定伤害 | `changeHealth(-dmg)` |
| 削蓝 | `Actor.setMana` 或 `restoreManaPercent` 负值 |
| 落雷/火焰 | `ActionLibrary.castLightning` / `ActionLibrary.castFire` |
| 眩晕/中毒/减速/护盾 | `ActionLibrary.addStunnedEffectOnTarget` 等 |
| 传送 | `ActionLibrary.singularityTeleportation` / `teleportRandom` |
| 召唤 | `ActorManager.spawnNewUnit` |
| 易伤/破甲/增益 | 给目标或友军加 trait 并写到期年 |
| 吸血 | 命中后按造成伤害比例回血 |
| 叠层/到期/限频 | 写入 `custom_data_int` 与到期年 |
| 回填 | 在受击钩子里按比例回填本次伤害 |
| 净化 | 由 MOD 移除负面 trait，再移除普通负面 |

### 研究主表
**说明**
- 研究条目注册进原版特质编辑器，列表全局可见。
- 未解锁条目标记为锁定。
- `unlock_tier` 表示世界档位解锁阈值。
- 世界档位达到 `unlock_tier` 后进入原版随机池：`pot_traits_birth`、`pot_traits_growup`。
- 原版随机池包含 `pot_traits_combat`、`pot_traits_mutation_box`。
- 进入随机池由原版字段决定，MOD不改。
- 研究特质资产必须配置 `rate_birth`、`rate_inherit`。
- 研究特质资产必须配置 `rate_acquire_grow_up`、`is_mutation_box_allowed`。
- 研究条目自动授予前按王国生效档位过滤。
- 各王国生效档位独立，自动授予按王国档位判断。
- 仅当 `unlock_tier <= 王国生效档位` 才可授予。
- 不满足则跳过并重新抽取。
- 编辑器手动添加可绕过档位，仅用于调试。
