# 原版特质清单

## 来源说明
- 以 `ActionLibrary` 可调用方法为主。
- 以 `strings.dll` 里的关键词做命名参考。
- 本清单只用于设计参考，不是完整原版列表。

|---|---|---|
| 落雷 | `castLightning` | 触发雷击特效与伤害。 |

| 龙卷 | `castTornado` | 触发小型龙卷风。 |

| 护盾 | `addShieldEffectOnTarget` | 施加护盾效果。 |

## strings关键词
- `death_nuke`：核爆。
- `mega_heartbeat`：心跳波。
- `burning_feet`：灼足。
- `poisoned`/`poison_immune`：中毒/抗毒。
- `frozen`：冻结。
- `plague`：瘟疫。
- `tornado`：龙卷。
- `lightning`：雷击。
- `shield`：护盾。
