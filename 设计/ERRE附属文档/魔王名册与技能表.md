# 魔王名册与技能表

## 文档职责
- 本表只记录魔王条目，不写阶段推进。
- 本表只给条目级口径，不写系统级实现细节。

## 填写规则
- 表内多行用 `<br>` 分行。
- 每名魔王固定 `P0/S1/S2/S3/S4/S5/S6` 七行记录。
- `P0` 为被动，`S1-S6` 为主动。
- `ID` 统一写为 `demon_id#slot`。
- `S1-S5` 统一法力消耗 `10`。
- `S6` 统一法力消耗 `15`。
- `触发方式` 统一写成“主动时/命中时/受击时 + 概率”。
- 随机触发写 `x%`，条件或阈值必触发写 `100%`。
- 时间限制只允许写在 `S6`，`S1-S5` 不写时间限制。
- 技能实现判定口径：`原版直接复用`、`原版修改复用 + MOD自定义`、`MOD自定义`。
- 视觉表现实现只看效果本身，出现可见投射物、可见区域、可见召唤物、地形变化、目标离场/回场时等等这些其它内容（类似于游戏原版的召唤陨石、龙卷风这些视觉效果），纯数值结算或只加减状态图标时无需增视觉表现。

## 敌我判定
- 本表“友军”默认是严格同王国：`Actor.isSameKingdom(target)`。
- 本表“敌军”默认是敌对关系：`self.areFoes(target)`，底层是 `kingdom.isEnemy(target.kingdom)`。
- 技能枚举目标前先判目标存活且存在王国，再做敌我筛选。
- 条目里写 `castXXX` 只表示投放动作，不代表已完成敌我筛选。

## 触发口径
- `主动时 x%` 使用战斗施法链：`Actor.tryToAttack -> addToAttackPool(combat_cast_spell) -> CombatActionLibrary.tryToCastSpell`。
- `命中时 x%` 使用命中回调链：`MapBox.applyAttack -> Actor.attackTargetActions`。
- `受击时 x%` 使用受击回调链：`Actor.getHit -> s_get_hit_action / action_get_hit`。
- 本表里的“主动时/命中时/受击时”是简写，触发入口全部按上面三条解释。
