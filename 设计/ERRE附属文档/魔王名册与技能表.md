# 魔王名册与技能表

## 文档职责
- 本表只登记魔王条目和条目级设计口径。
- 本表不写轮回阶段推进和系统级流程。
- 触发类型只表示条件，不新增触发入口。

## 表头说明
- 表内多行用 `<br>` 分行。
- 字段含义以表头为准。
- 每名魔王拆成 `P0/S1/S2/S3/S4/S5/S6` 七行记录。
- `P0` 为被动，`S1-S6` 为主动。
- `S1-S6` 的触发方式统一写成：`战斗施法链（combat_cast_spell）判定 x%`，并按条目写条件。
- 时间限制只允许写在 `S6`；`S1-S5` 不写时间限制。
- `ID` 统一写为 `demon_id#slot`。
- `技能来源` 固定格式：`主类(证据)`；多段来源用 ` + ` 连接；判定口径固定三档：`原版直接复用`、`原版修改复用 + MOD自定义`、`MOD自定义`。
- `视觉表现` 按玩家可观察事实填写（二选一）：有新增且关键可见变化时写四段（`施法触发/范围或轨迹/命中结果/持续状态`），无新增视觉写固定句“无新增视觉（复用原版...）”。
- `视觉表现` 禁止写演出脚本词；只写玩家在游戏里可直接看到或可由状态图标确认的变化。
- `视觉表现` 判定只看效果本身：出现可见投射物、可见区域、可见召唤物、地形变化、目标离场/回场时写四段；纯数值结算或只加减状态图标时写“无新增视觉（复用原版...）”。
- `触发方式` 必须写清概率：随机触发写 `x%`，条件/阈值必触发写 `100%`。

## 主动技能硬约束
- `S1-S6` 的实现入口固定为：`Actor.attack -> addToAttackPool(combat_cast_spell) -> tryToCastSpell`。
- `S1-S6` 禁止用 `action_get_hit`、`action_attack_target`、`action_special_effect` 作为主触发入口。
- `S1-S6` 禁止直接调用 `spell.action.Invoke(...)` 代替战斗施法入口。
- `S1-S6` 的“施放成功后”定义为：`tryToCastSpell(...)` 返回 `true`，并写入 `recovery_spell`。
- `tryToCastSpell` 的判定顺序固定：法力 -> 概率 -> 目标类型 -> 血量阈值 -> 最小距离 -> 执行动作。
- `S1-S5` 统一法力消耗 `10`。
- `S6` 统一法力消耗 `15`。
- `S1-S6` 复用原版动作时，使用自定义 `SpellAsset` 壳（`cost_mana` 按槽位统一），`action` 指向原版 `ActionLibrary` 函数，不直接复用原版低耗蓝 `SpellID`。
- 能走原版动作入口时，`技能来源` 必须写成“原版修改复用 + MOD自定义”，不得直接标成“MOD自定义”。
- `P0` 不走 `combat_cast_spell`，按条目定义走被动钩子（如 `action_get_hit`、`action_special_effect`、`action_on_object_remove`）。

## 阵营口径
- 魔王、将领、军团统一使用 `wild kingdom` 归属，只用于阵营和敌我判定。
- 本表“友军”默认是严格同王国：`Actor.isSameKingdom(target)`。
- 本表“敌军”默认是敌对关系：`self.areFoes(target)`，底层是 `kingdom.isEnemy(target.kingdom)`。
- 技能枚举目标前先判目标存活且存在王国，再做敌我筛选。
- 条目只写 `castXXX` 代表投放法术，不代表已完成敌我筛选。
- 文中的“据点”是独立对象，不是城市，不触发建城发展链。
