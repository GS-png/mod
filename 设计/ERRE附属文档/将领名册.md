# 将领名册

## 使用规则
- 本表只记录将领名单，不写生成阶段、生成位置和补员规则。
- 每名魔王固定配置 `5` 名将领。
- 将领的生成规则、阶段规则以主文档 [EraWheel_Redesign.md](../EraWheel_Redesign.md) 的“系统总览 -> 将领系统”为准。
- 阵营归属、模板边界和共享敌我口径以 [EraWheel_实现口径.md](../EraWheel_实现口径.md) 的“系统实现细则 -> 魔王阵营通用规则”为准。
