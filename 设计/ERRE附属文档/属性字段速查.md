# 属性字段速查

## 使用规则
- 本表用于字段映射速查和统一命名。
- 适用场景是特质与装备的 `base_stats` / `base_stats_meta`。
- 字段中文来源是 `worldbox_Data/resources.assets` 的 `TextAsset(base_stats)`。
- 先按“字段效果说明”确认字段用途，再按“配置填写方式”填值。
- `multiplier_` 前缀字段统一按百分比填写。
- 表里“显示方式”只描述 UI 展示，不代表底层运算类型。
- 本表不写玩法流程和数值平衡策略；字段授予和生效逻辑以主文档为准。

## 单位字段
说明：适用于所有生物单位。
