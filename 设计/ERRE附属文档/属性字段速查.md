# 属性字段速查

## 使用规则
- 本表用于字段映射速查和统一命名。
- 适用场景是特质与装备的 `base_stats` / `base_stats_meta`。
- 字段中文来源是 `worldbox_Data/resources.assets` 的 `TextAsset(base_stats)`。
- 先按“字段效果说明”确认字段用途，再按“配置填写方式”填值。
- `multiplier_` 前缀字段统一按百分比填写。
- 表里“显示方式”只描述 UI 展示，不代表底层运算类型。
- 本表不写玩法流程和数值平衡策略；字段授予和生效逻辑以 [EraWheel_Redesign.md](../EraWheel_Redesign.md) 与 [EraWheel_实现口径.md](../EraWheel_实现口径.md) 为准。

## 原版四族基础值

### 统计口径
- 本表统计 `human`、`elf`、`dwarf`、`orc` 模板里直接写入的原始字段值。
- 口径是“公共模板继承值 + 种族 `addGenome()` / `base_stats[...]` 直写值”。
- 没有单独写入的字段，按 `BaseStats.get()` 默认读取为 `0`。
- `throwing_range` 在原版里取自 `ActorAsset.base_throwing_range`，不是 `base_stats["throwing_range"]`。
- 下表不把条件型特质和倍率型特质折算进结果，比如精灵 `moonchild`、兽人 `nightchild`、矮人 `fat`。

### 自带特质修正
| 种族 | 自带特质 | 会影响本表字段的内容 |
|---|---|---|
| 人类 | 无直接改本表字段的自带 `ActorTrait` | 主表值就是人类模板底数。 |
| 精灵 | `soft_skin`、`moonchild` | `soft_skin` 常驻让 `armor -5`。`moonchild` 只在月亮时代激活，给 `armor +1`、`intelligence +3`，并额外给 `multiplier_damage +50%`、`multiplier_speed +10%`。 |
| 矮人 | `fat` | `fat` 常驻让 `scale +0.02`，并额外给 `multiplier_damage +10%`、`multiplier_stamina -50%`、`multiplier_mass +30%`。`miner`、`block`、`deflect_projectile` 不直接改这张表里的数值。 |
| 兽人 | `bloodlust`、`nightchild` | `bloodlust` 常驻让 `warfare +5`、`diplomacy -2`。`nightchild` 只在黑夜时代激活，给 `critical_chance +0.03`、`warfare +3`，并额外给 `multiplier_damage +50%`、`multiplier_speed +10%`。`regeneration`、`savage` 不直接改这张表里的数值。 |
