# 系统参数总表

## 文档定位
- 本表是 EraWheel 所有对外可调参数的单一来源。
- 以后主文档只讲“这套系统是干什么的”，不再重复抄完整参数表。
- 如果某个系统在这里没有参数，表示当前版本没有对外公开的独立调参项，不表示这个系统不存在。

## 查表约定
- 除非特别说明，所有表统一按 `系统 / 参数组 / 参数名 / 默认值 / 控件类型 / 生效时机 / 影响范围 / 备注` 阅读。
- `控件类型` 只用 5 种口径：`勾选框`、`下拉单选`、`多选勾选`、`数值输入`、`区间输入`。
- `生效时机` 说的是“系统什么时候真正读取这个值”，不是“玩家什么时候能看到它”。
- `影响范围` 说的是“这项参数主要改的是哪块行为”，方便新手判断调大调小会碰到哪里。

## 轮回进阶系统
- 世界档位计算规则：
  - `自动推进 = min(轮回阶位上限, 上轮世界档位 + 每轮回档位提升)`。
  - `手动控制 = 手动世界档位`。
- 王国档位基值公式：`max(新王国档位下限, floor(当前世界档位 × 掌控度))`。
- 掌控度公式：`基础分 + Σ(指标分 × 权重)`；`指标分 = min(当前值/阈值, 1)`。
- 想看轮回装备的扣材字段映射、锻造口径和 `equipment_value` 换装判定，去看 [轮回装备锻造对比表.md](轮回装备锻造对比表.md)。
