## 统一口径

### 术语
| 术语 | 含义 |
|---|---|
| 轮回 | 从一次封印战胜利到下一次封印战胜利的周期。 |
| 阶段 | 轮回内进程：预发展、预兆、苏醒、降临、封印战、战后重建。 |
| 战斗子状态 | 仅在魔王实体存在时生效，用于描述魔王强弱。 |
| 封印战胜利 | 封印战达成胜利结算，路径为击杀、仪式或双通道。 |
| 王国 | 游戏中的 Kingdom 实体，拥有城市、人口和外交关系。 |
| 将领封印/魔王封印 | 双封印机制，将领封印在预兆衰减，魔王封印在苏醒衰减。 |
| 三钩子 | 技能触发三种钩子：命中、受击、死亡点。 |
| 魔王/将领/军团 | 三层敌对结构：魔王（核心）→ 将领（精英）→ 军团（波次）。 |
| 多魔王互动 | 多个魔王同时存在时的关系规则：联盟、内战、随机。 |
| 机械单位 | 机械暴君阵营单位统称，默认归魔王阵营。 |
| 纪元遗产 | 轮回结算后给予王国、英雄、魔王的长期增益。 |
| P0 / S1-S6 | 技能槽位口径：`P0=被动`，`S1-S6=主动`。 |
| LLM | 大语言模型，仅用于叙事文本组织。 |
| NeoModLoader | WorldBox 的 MOD 加载框架。 |

- 城市与建筑不参与。
- 遗产档位先分类型，再按对象范围应用。
- 英雄晋升从随机池抽取，继承只抽祖先已持有条目。

### 时间
- 时间单位统一为游戏年份。
- 周期与间隔按年计算。

### 触发口径
- 技能触发只允许命中、受击、死亡点。
- 同一技能允许绑定多个触发点。
- 击杀、低血、累计等描述只做触发后条件判定。
- 到期、限频与范围只在触发点处理。
- 命中入口使用 `action_attack_target`。
- 受击入口使用 `action_get_hit`。
- 死亡点入口使用 `action_on_object_remove`。
- 优先使用 `ActionLibrary`，无现成动作再用自定义 `trait`。
- 主动技能统一消耗法力。
- 主动技能触发频率按年限频。
- 技能条目限频与消耗优先于默认值。

### 槽位口径
- 魔王槽位固定为 `P0+S1-S6`。
- 将领槽位固定为 `P0+S1+S2`。

### 技能参数
| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 法力消耗 | 主动技能消耗（普通 `5`）；主动技能消耗（终极 `10`） | 技能释放法力消耗默认值 |
| 触发频率 | 主动技能触发上限（`2次/年`）；终极技最小间隔（`2年`） | 年度限频默认值 |

## 玩法闭环

### 定义
- 轮回起点是上一轮封印战胜利后进入预发展。
- 轮回终点是下一次封印战胜利结算完成。
- 封印战胜利方式由配置决定。

### 阶段总览
1. 预发展。
2. 预兆。
3. 苏醒。
4. 降临。
5. 封印战（衰弱）。
6. 战后重建。

### 系统关系
| 系统 | 主要作用 | 关键输入 | 关键输出 |
|---|---|---|---|
| 轮回系统 | 驱动阶段推进与结算 | 世界人口、世界城市数、封印值、轮回数 | 当前阶段、结算结果 |
| 魔王系统 | 决定魔王行为与强度 | 阶段、HP、魔王类型 | 技能激活、行为策略 |
| 将领系统 | 管理精英单位层 | 魔王类型、轮回数 | 将领生成、将领技能 |
| 军团系统 | 管理波次压制节奏 | 阶段、波次配置、军团库 | 军团数量、军团强度 |
| 封印遗迹 | 提供仪式封印路径 | 阶段、遗迹状态、争夺结果 | 封印进度、仪式胜利 |
| 遗产系统 | 记录跨轮回长期增益 | 轮回结算数据 | 王国、英雄、魔王增益 |
| 王国英雄 | 承担对抗与反哺 | 王国运行态、战果 | 抗魔等级、命定英雄 |
| 世界外交 | 组织共同讨伐窗口 | 魔王存活态、触发条件 | 停战状态、联合作战 |

## 核心系统

### 轮回系统
- 定义：轮回系统负责阶段推进、双封印管理和结算发放。
- 规则：阶段状态是轮回主状态，不与战斗子状态混用。
- 计数：战后重建完成后轮回数 `+1`。

**阶段规则**
1. 预发展。触发条件为新档开始或战后重建结束。系统按“预发展检查间隔”读取人口与城市数。人口或城市达阈值即进入预兆。将领封印与魔王封印保持初始强度。
2. 预兆。触发条件为人口或城市达到阈值。系统确定本轮魔王名单并生成据点。军团进入出波阶段，将领封印开始衰减。遗迹进入显形状态。
3. 苏醒。触发条件为将领封印降为 `0%`。系统激活将领并生成将领单位。魔王封印开始衰减，遗迹进入争夺状态。
4. 降临。触发条件为魔王封印降为 `0%`。系统生成魔王实体并主动进攻。军团波次加速，遗迹保持争夺状态。
5. 封印战（衰弱）。触发条件为魔王 HP 低于衰弱阈值。军团生成降速，遗迹切换为激活状态。魔王优先撤退与恢复，部分将领可能撤退或失控。HP 回升到回退阈值则回到降临。
6. 战后重建。触发条件为封印战胜利结算完成。系统发放遗产并重置魔王位置与强度。阶段回到预发展并写入轮回历史。

**阈值口径**
- 阶段触发阈值来自人口、城市、封印值与 HP。
- 封印战触发=HP 低于衰弱阈值。
- 回退=HP 回升到回退阈值。
- 战斗子状态仅按 HP 阈值切换，不驱动阶段。

**封印战胜利判定**
- 胜利模式包含击杀、仪式、双通道。
- 击杀胜利：直接击杀魔王，立即触发胜利结算。
- 仪式胜利：激活遗迹达到占领数阈值且仪式进度满。
- 双通道胜利：任意一条路径达成即判定胜利。
- 胜利模式由配置选择。
- 判定只按当前模式执行。
- 未选路径即使满足条件也不判胜利。

**存档规则**
- 轮回状态、计数、关键进度写入 MOD 存档。
- 读档后自动恢复阶段、封印值和计时器。

**参数表**
| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 预兆触发 | 世界现存人口阈值（`5000`）；世界现存城市阈值（`20`）；预发展检查间隔（`10年`） | 人口或城市任一达标进入预兆 |
| 据点与节点 | 据点默认半径（`20格`） | 据点范围半径 |
| 将领封印 | 将领封印初始强度（`100%`）；将领封印衰减速率（`1%/年`） | 预兆阶段开始衰减 |
| 魔王封印 | 魔王封印初始强度（`100%`）；魔王封印衰减速率（`1%/年`） | 苏醒阶段开始衰减 |
| 封印胜利 | 封印胜利模式（击杀/仪式/双通道） | 胜利方式选择 |

### 魔王系统
- 定义：魔王系统负责魔王实体、技能行为和强度状态切换。
- 规则：多魔王时由互动模式管理阵营关系。

**状态模型**
- 阶段状态沿用轮回六阶段。
- 战斗子状态仅在实体存在时生效。
- 子状态只做数值修正，不驱动阶段。
- 阶段切换由轮回系统判定。

**阶段行为表**
| 阶段 | 技能激活 | 军团生成 | 将领数量 | 魔王实体 | 说明 |
|---|---|---|---|---|---|
| 预发展 | 否 | 否 | `0` | 否 | 等待人口/城市阈值触发 |
| 预兆 | 否 | 是 | `0` | 否 | 军团出波，将领封印衰减 |
| 苏醒 | 将领技能 | 是 | 固定 `5` | 否 | 将领生成，魔王封印衰减 |
| 降临 | 全部可用 | 是 | 存活数 | 是（全盛/常态） | 魔王入侵 |
| 封印战 | 全部可用 | 是（降速） | 存活数 | 是（衰弱） | 封印战争夺 |
| 战后重建 | 否 | 否 | `0` | 否 | 结算与重置 |

**战斗子状态**
- 全盛：HP 高于全盛阈值，法力恢复 `+50%`，波次速度 `×2`。
- 常态：HP 位于全盛阈值与衰弱阈值之间。
- 衰弱：HP 低于衰弱阈值。
- 子状态只依据 HP 阈值切换。

**多魔王互动**
- 触发条件：本轮苏醒数 `>=2` 或当前存活数 `>=2`。
- 互动模式：联盟、内战、随机。
- 随机模式：关系校验间隔到期时重掷一次并应用。
- 联盟模式：共享敌对关系并强制停火，单体强度下调。
- 内战模式：魔王互相宣战，同时继续攻击王国。
- 内战胜者获得称号和限时属性加成。
- 保护规则：魔王数量 `<2` 时机制不生效。

**阵营外交**
- 魔王阵营单位生成即敌对所有非魔王阵营单位。
- 魔王阵营主动攻击非魔王阵营单位。
- 王国与魔王阵营保持战争。
- 魔王阵营不建城，不参与王国外交。

**魔王势力生成**
- 魔王势力单位指魔王、将领、军团三类。
- 三类单位使用不同 `ActorAsset` 模板 ID 生成。
- 生成后按原版随机池获取特质。

**参数表**
| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 魔王池与苏醒 | 魔王启用默认（多选）；魔王苏醒模式（指定/随机）；苏醒数量（`1`） | 控制本轮魔王构成 |
| 战斗态阈值 | 全盛 HP 阈值（`70%`）；衰弱 HP 阈值（`30%`）；封印战回退阈值（`70%`）；全盛法力恢复倍率（`50%`） | 全盛、衰弱与回退控制 |
| 轮回成长 | 轮回成长倍率（`25%/轮回`）；成长硬上限（`250%`） | 魔王成长参数 |
| 多魔王模式 | 互动模式（联盟/内战/随机）；关系校验间隔（`3年`）；联盟强度系数（`85%`）；内战强度系数（`100%`） | 关系维护和强度修正 |
| 内战主导权 | 内战最大魔王数（`5`）；加成时长（`10年`）；加成属性比例（`10%`） | 胜者限时加成 |

### 将领系统
- 定义：将领是魔王阵营精英单位，用于指挥和关键战斗。
- 数量：每个魔王固定 `5` 名将领。
- 生成：将领只在苏醒阶段生成一次。
- 继承：将领死亡后不补充。
- 位置：生成点优先魔王据点或魔王附近。
- 槽位：将领技能槽位固定为 `P0+S1+S2`。

**参数表**
| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 轮回成长 | 轮回成长倍率（`20%/轮回`）；成长硬上限（`250%`） | 将领成长参数 |

### 军团系统
- 定义：军团是魔王阵营波次单位，用于持续施压。
- 上限：军团总量受“同时上限”约束。

**波次规则**
- 预发展与战后重建不出波。
- 预兆阶段生成第一波。
- 预兆与苏醒阶段使用“军团生成间隔”。
- 降临阶段使用“全盛生成间隔”。
- 封印战阶段使用“封印战生成间隔”。
- 波次强度：`基础强度 × (1 + 递增 × 波次)`。
- 波次数量：按“数量递增”随波次提高。
- 强度与数量都在出波时计算。

**上限处理**
- 本波数量=`min(计划数量, 同时上限-当前存活)`。
- 结果 `<=0` 时跳过本波并记录日志。

**生成规则**
- 军团使用独立模板生成。
- 魔王据点不存在时在魔王附近生成。

**成长规则**
- 军团成长使用通用成长公式。
- 军团最终叠加顺序为随机值 → 轮回成长 → 波次强度。

**参数表**
| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 波次节奏 | 军团生成间隔（`10年`）；军团初始数量（`40`）；军团强度递增（`15%/波`）；军团同时上限（`300`） | 出波节奏与总量控制 |
| 阶段波次 | 军团全盛生成间隔（`5年`）；封印战生成间隔（`15年`） | 降临与封印战节奏 |
| 波次数量 | 波次数量递增（`15%/波`） | 每波单位数增长 |
| 轮回成长 | 轮回成长倍率（`15%/轮回`）；成长硬上限（`250%`） | 军团成长参数 |

### 据点节点
- 定义：预兆期为每个魔王生成 1 个魔气节点并升级为据点。
- 作用：据点用于生成、集结与范围判定中心。
- 范围：据点范围按中心半径计算，可配置。

**生成规则**
1. 进入预兆期后，为每个魔王生成 1 个魔气节点并升级为据点。
2. 选点只要求可行走且避深水。
3. 若无可行走地块，则使用世界中心附近可行走地块兜底。

**生命周期**
- 据点存在阶段为预兆、苏醒、降临、封印战。
- 据点生成后固定，不做刷新。
- 据点被摧毁后不重建。
- 战后重建阶段移除据点。

**多魔王规则**
- 每个魔王绑定 1 个据点。
- 技能提到“据点”时默认指绑定据点。

**存档字段**
```
outposts: [{ demon_id, x, y, radius }]
```

### 封印遗迹
- 定义：封印遗迹是轮回内可见、可争夺、可用于仪式的建筑。
- 状态：遗迹固定为显形、争夺、激活三态。
- 结果：仪式胜利通过激活遗迹推进封印进度达成。

**状态与生命周期**
- 预兆阶段生成或显形遗迹，状态为显形。
- 苏醒和降临阶段为争夺，可交战不推进仪式。
- 封印战阶段切换为激活，允许占领与进度推进。
- 战后重建阶段移除本轮遗迹。
- 生成点需避开深水与拥挤区域。

**仪式规则**
- 仅激活状态可以触发占领与进度推进。
- 非激活状态进度锁定，不增长。
- 触发占领需要范围清场且人数达阈值。
- 占领后进度持续推进，不要求持续驻守。
- 敌方人数达到阈值时按配置中断、回退或清零。
- 达到占领数阈值且总进度满时判定仪式胜利。

**争夺调度闭环**
1. 进入预兆后启动调度计时器。
2. 达到调度间隔后选取目标遗迹。
3. 派遣最近 `N=2` 个王国小队，可配置。
4. 同时派遣魔王阵营小队。
5. 进入遗迹范围后执行占领判定与收益判定。
6. 未达打断阈值时继续推进进度。
7. 达打断阈值后按暂停、回退或清零处理。
8. 封印战胜利或进入战后重建时停止调度并清理队列。

**占领收益**
- 同阵营收益不叠加。
- 占领后友军获得范围增益。
- 收益半径与增益强度可配置。

**参数表**
| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 遗迹数量与阈值 | 封印遗迹数量（`10`）；占领遗迹数量阈值（`8`） | 遗迹总数和达标要求 |
| 仪式占领与进度 | 仪式占领人数阈值（`10`）；仪式进度速度（`3%/年`） | 占领条件和推进速度 |
| 仪式打断与回退 | 仪式中断敌方人数阈值（`15`）；中断处理（暂停/回退/清零）；回退速度（`3%/年`） | 打断规则 |
| 热点调度 | 热点开关；调度间隔（`5年`）；目标策略（敌占领/未占领/最近/随机） | 争夺调度规则 |
| 派遣规模 | 派遣王国数量（`2`）；派遣王国人数（`40`）；派遣魔王人数（`40`） | 每次派遣规模 |
| 占领收益 | 收益半径（`12`）；友军增益（`10%`）；叠加上限（`1`） | 遗迹收益配置 |

## 数值成长

### 通用成长
- 公式：`属性 = 基础值 × (1 + 成长倍率 × 轮回数)`。
- 基础值只在单位生成或晋升时随机写入一次。
- 轮回成长在轮回结算后生效。
- 魔王、将领、军团分别使用各自成长倍率与上限。

### 属性随机
- 属性随机只作用于 MOD 自定义单位。
- 随机值写入基础字段，不写入百分比元字段。
- 属性随机与轮回成长可叠加。

### 触发时机
- 魔王和将领在生成时随机一次。
- 军团每波次随机一次并共享该波结果。
- 命定英雄在晋升时随机一次。

### 叠加顺序
- 随机值 → 轮回成长 → 特质/遗产。

### 首轮随机范围
| 单位类型 | 生命 | 寿命 | 防御 | 伤害 | 法力上限 | 体力 | 暴击率 | 移速 | 攻速 | 时机 |
|---|---|---|---|---|---|---|---|---|---|---|
| 魔王 | `150000-200000` | `99999-99999` | `400-1000` | `800-2000` | `100-300` | `200-500` | `8%-25%` | `8-12` | `0.8-1.2` | 生成时 |
| 将领 | `100000-150000` | `99999-99999` | `80-250` | `200-500` | `100-200` | `120-300` | `6%-18%` | `10-15` | `0.9-1.3` | 生成时 |
| 军团 | `1000-10000` | `99999-99999` | `10-80` | `20-120` | `50-100` | `80-180` | `2%-10%` | `9-13` | `0.9-1.3` | 出波时 |
| 英雄 | `80000-120000` | `200-500` | `50-200` | `120-350` | `100-250` | `150-350` | `6%-18%` | `10-14` | `0.9-1.3` | 晋升时 |

### 范围平移
- 范围平移用本轮生成单位均值更新下轮下限。
- 上限保持初始宽度不变。
- 本轮未生成则不更新范围。
- 玩家手动改动随机范围后清零平移偏移。

## 遗产系统

### 定义
- 轮回结算发放遗产。
- 遗产生效跨轮回继承。
- 遗产分为解锁类与数值类。
- 军备遗产走魔王侧直发链路。

### 类型与对象
| 遗产类型 | 作用对象 | 说明 |
|---|---|---|
| 工艺遗产 | 王国成员 | 扩展装备编辑器条目 |
| 研究遗产 | 王国成员 | 解锁研究条目 |
| 军事遗产 | 王国成员 | 攻防按档位叠加 |
| 军备遗产 | 魔王势力 | 解锁军备池 |
| 领域遗产 | 魔王/将领 | 技能范围与次数提升 |

### 核心规则
- 王国层只做档位与掌控度判定。
- 编辑器可见不等于已授予。
- 工艺遗产只做注册与解锁。
- 装备条目注册进原版装备编辑器。
- 解锁后锻造、入库、取装走原版闭环。
- 研究条目按世界档位与王国档位解锁进入编辑器。
- 研究条目列表全局可见。
- 特质编辑器全局显示，不做王国过滤。
- 自动获得按王国档位过滤。
- 未达标时在同池重抽，次数上限为池大小。
- 互斥与概率按原版执行。
- 手动添加可绕过王国档位限制。
- 魔王势力不建城，军备走直发。

### 档位规则
- 世界档位随轮回结算推进。
- 解锁类遗产只扩展清单，不直接叠数值。
- 数值类遗产按档位叠加。
- 档位上限可配置。

### 掌控度
- 存活王国直接使用世界档位。
- 新建王国按掌控度折算生效档位。
- 生效档位公式：`floor(世界档位 × 掌控度)`。
- 掌控度范围为 `0%-100%`。
- 新王国最低档位可配置。
- 掌控度公式：`基础分 + Σ(指标分 × 权重)`。
- 指标分规则为 `min(当前值/阈值, 1)`。
- 指标包含书籍、城市、人口、军力、建筑。

### 发放流程与默认策略

**原版装备链路**
1. 装备条目注册进装备编辑器并进入原版装备池。
2. 原版锻造产生装备实例（`ItemCrafting`）。
3. 装备进入城市仓库（`City.tryToPutItem`）。
4. 单位按原版取装行为获取装备（`BehActorTryToTakeItemFromCity`）。

**研究解锁链路**
1. 结算推进世界档位。
2. 计算王国生效档位。
3. 按档位解锁研究 `trait_id` 并注册到特质编辑器。
4. 自动获得按王国档位过滤。
5. 未达标则在同池重抽，次数上限=池大小。
6. 互斥与概率按原版执行。
7. 记录日志并写入存档。

**数值遗产链路**
1. 结算推进世界档位。
2. 计算王国生效档位。
3. 按档位计算军事遗产攻防增益。
4. 写入王国成员数值缓存。
5. 按档位写入领域遗产参数。
6. 记录日志并写入存档。

**魔王直发链路**
1. 结算推进军备档位。
2. 计算可用档位与资格。
3. 按档位筛选军备 `asset_id`。
4. 读取 `demon_wargear_delivery` 并截断越界概率。
5. 生成或刷新时按角色概率发放。
6. 未发放则失败计数 `+1`，成功则清零。
7. 将领失败计数达阈值触发保底。
8. 写入槽位，无空槽位时按规则替换。
9. 记录状态与日志，按周期重试。

**直发细则**
- 候选筛选按档位与 `demon_wargear_delivery` 取 `asset_id`。
- 候选筛选按角色范围过滤：`demon_lord/general/legion`。
- 候选筛选按槽位类型过滤：`weapon/armor/accessory`。
- 饰品按直发链路处理，规则与武器/护甲一致。
- 发放仅在生成或刷新时触发。
- 刷新受“刷新间隔”限制。
- 单次最大发放量为 `1`。
- 有空槽位时直接装备。
- 无空槽位时仅替换更好装备。
- 评分一致则不替换。
- 仅“未发到装备”计失败。
- 装备更差被跳过时不计失败。
- 失败达阈值触发保底发放。
- 成功发放后失败次数清零。
- 失败次数、年份、档位与来源写入存档字段。
- 评分优先用原版品质值。
- 无法获取品质时用“档位+词条数量”。

**默认策略**
- 原版锻造与取装随机性保持不变。
- 魔王侧固定直发，覆盖魔王、将领、军团。
- 魔王链路按角色概率发放。
- 装备词条与品质沿用原版生成。
- 无空槽位时只替换更好装备。
- 替换按“武器 > 护甲 > 饰品”优先级。
- 军备默认概率 `1.0/0.7/0.35`，保底阈值 `3`。
- 重试周期 `2` 年，单次最大发放 `1` 件。

### 状态字段
- `custom_data_int["era_war_fail_count"]`：将领连续失败次数。
- `custom_data_int["era_war_last_grant_year"]`：最近一次发放年份。
- `custom_data_int["era_war_last_grant_tier"]`：最近一次发放使用的档位。
- `custom_data_int["era_war_source"]`：魔王军备来源标记，`0=heritage_auto`。
- `era_war_fail_count` 仅用于将领保底，不参与工艺遗产解锁。

### 参数表
| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 档位推进 | 遗产档位上限（`10`）；每轮回档位提升（`1`） | 档位上限和推进节奏 |
| 新王国继承 | 新王国档位下限（`1`）；掌控度刷新间隔（`10年`） | 新王国继承规则 |
| 掌控度基础分 | 数值（`0.20`） | 固定基础分 |
| 掌控度书籍类 | 阈值：文化`5`、宗教`5`、语言`5`、首都`5`、全城`20`；权重：`0.10/0.10/0.05/0.10/0.05` | 书籍评分 |
| 掌控度规模类 | 阈值：城市`5`、人口`688`、军力`200`、建筑`6`；权重：`0.15/0.10/0.10/0.05` | 规模评分 |
| 魔王军备发放（`demon_wargear_delivery`） | 角色概率（`1.0/0.7/0.35`）；将领保底失败次数（`3`）；刷新间隔（`2年`）；单次最大发放（`1`） | 魔王军备概率、保底和重试控制 |

### 数值遗产参数
| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 军事遗产 | 每档攻击加成（默认 `2%`）；每档防御加成（默认 `2%`） | 对王国成员生效 |
| 领域遗产 | 每档范围加成（默认 `3%`）；次数加成参数（起始档位、每N档+1、上限） | 仅影响 MOD 技能 |

### 边界与禁止
- 魔王链路只使用 `generateItem/generateModsFor/ActorEquipment.setItem`。
- 魔王链路必须读取 `demon_wargear_delivery` 并截断越界概率。
- 研究掌控度检查仅在自动获得特质新增时执行。
- 手动授予不触发掌控度检查。
- 禁止使用全局 `ItemAsset.unlock()` 替代资格判定。

## 王国英雄

### 定义
- 王国英雄系统包含抗魔等级、命定英雄、家族继承三部分。
- 抗魔等级是王国维度长期成长。
- 命定英雄是轮回中的关键单位。

### 抗魔等级
- 王国通过击杀魔王阵营单位提升抗魔等级。
- 封印战胜利可提供额外加成。
- 新建或复国王国从 `0` 级开始。

**效果**
| 等级 | 效果1 | 效果2 | 效果3 |
|---|---|---|---|
| Lv1 | 命中 `+5%` | 攻速 `+5%` | - |
| Lv2 | 伤害 `+5%` | 生命 `+5%` | - |
| Lv3 | 体力 `+10%` | 法力 `+10%` | - |
| Lv4 | 防御 `+8%` | 移速 `+5%` | - |
| Lv5 | 暴击率 `+5%` | 暴伤 `+15%` | - |
| Lv6 | 伤害 `+8%` | 防御 `+6%` | - |
| Lv7 | 射程 `+10%` | 投掷射程 `+10%` | - |
| Lv8 | 生命 `+10%` | 移速 `+5%` | - |
| Lv9 | 攻速 `+8%` | 暴击率 `+3%` | - |
| Lv10 | 战斗熟练 `+20%` | 法术熟练 `+20%` | 状态触发 `+10%` |

### 命定英雄
- 每王国有数量上限。
- 事件触发为主，定期兜底检测为辅。
- 达到繁荣条件或危机条件时可触发晋升。

**晋升优先级**
1. 先检查世界总英雄上限。
2. 再检查王国当前英雄上限。
3. 再检查王国晋升冷却是否结束。
4. 再判断繁荣或危机触发条件是否达成。
5. 以上全部满足后进入候选筛选与评分。

**评分规则**
- 候选池为同王国、存活、非魔王阵营。
- 评分指标为等级、击杀、生命、攻击、领导力。
- 公式为 `综合分 = Σ(min(指标/阈值,1) × 权重)`。
- 从前 `N` 名中随机 `1` 名晋升。
- 现英雄单位不参与评分。

**晋升强化**
- 晋升时随机写入基础值。
- 晋升时抽取英雄随机特质与随机技能。
- 命定英雄固定 `P0「英勇」`。

**随机池与补抽**
- 技能池与特质池独立抽取。
- 抽中互斥条目即跳过，不计入数量。
- 持续抽取到数量满足或池内无可用条目。
- 池耗尽仍不足则保留已抽取结果。
- 固定被动：P0「英勇」=基础属性 +10%。

### 家族继承
- 仅王国新生单位在出生时判定继承。
- 出生入口为 `all_actions_actor_birth`。
- 使用 `parent_id_1/parent_id_2` 追溯最近英雄祖先。
- 英雄祖先存活与否不影响继承判定。

**血脉追溯规则**
1. 出生后读取父母 `parent_id_1/parent_id_2`。
2. 在双亲血脉中选择最近英雄祖先。
3. 双亲都命中时按代数最近优先。
4. 超过可继承代数时终止继承。
5. 无英雄祖先时直接结束。

**后裔继承规则**
1. 命中英雄祖先后按概率判定继承。
2. 属性按“祖先晋升基础值 × 继承比例”写入。
3. 继承池只使用英雄随机池条目。
4. 仅从祖先已持有条目里抽取。
5. 每代继承次数受上限约束。

**状态存储**
- 血脉根 ID 写入 `custom_data_long`。
- 血脉代数写入 `custom_data_int`。
- 状态随单位存档与读档恢复。

**参数表**
| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 抗魔等级成长 | 等级上限（`10`）；击杀阈值（`1000/0.5级`）；封印加成（`0.5级/次`） | 抗魔等级成长 |
| 英雄与冷却 | 每王国英雄上限（`1`）；世界总英雄上限（`50`）；晋升冷却（`30年`）；兜底检测间隔（`5年`） | 数量与节奏 |
| 晋升条件繁荣 | 人口阈值（`500`）；城市阈值（`2`） | 繁荣触发条件 |
| 晋升条件危机 | 统计窗口（`10年`）；人口跌幅（`50%`） | 危机触发条件 |
| 候选与评分 | 权重（等级`0.25`、击杀`0.25`、生命`0.15`、攻击`0.15`、领导力`0.20`）；阈值（`10/50/1000/100/100`）；取前N（`3`） | 过滤与评分 |
| 晋升奖励 | 随机特质数（`3`）；随机技能数（`6`） | 晋升强化 |
| 家族继承 | 触发概率（`30%`）；继承属性比例（`30%`）；继承祖先专属特质条目数（`2`）；继承祖先专属技能条目数（`4`）；可继承代数（`10`）；每代继承次数上限（`1`）；晋升评分每档加成（`5%`） | 继承规则 |

## 世界外交

### 定义
- 魔王存活期间可触发世界停战。
- 停战目的是形成共同讨伐窗口。
- 魔王被击败后恢复常规外交。

### 规则
- 触发条件可多选：降临阶段、城市摧毁阈值、世界人口阈值。
- 城市摧毁阈值=废墟城市数/总城市数。
- 满足任一条件即可进入停战状态。
- 停战期间终止王国间战争并统一对抗魔王阵营。
- 复查间隔到达后重新判定是否维持停战。
- 复查未满足条件时退出停战。
- 魔王死亡时立即退出停战。

### 参数表
| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 停战复查 | 停战复查间隔（`3年`） | 停战维持周期 |
| 触发条件与阈值 | 触发条件（多选）；降临阶段；城市摧毁阈值（`30%`）；世界人口阈值（`5000`） | 任一满足即触发 |

## 叙事事件

### 定义
- 叙事事件只记录真实发生内容。
- 不新增人物、地点、时间。
- 不改变先后顺序和因果关系。

### 数据来源
- 世界历史日志。
- 战争系统与阴谋系统。
- MOD 自定义事件。

### 事件结构
```
id: 全局唯一
year: 年份
source: world_log / plot / war / mod
type: city_new / war_started / demon_awake ...
entities: kingdom_id / city_id / unit_id / plot_id / war_id
location: x,y
raw_text: 原文或短句摘要
importance: 重要度
```

### 生成流程
1. 增量采集并记录 `last_year`。
2. 标准化为统一事件结构。
3. 事件年份大于单位 `death_year` 时丢弃。
4. 按年份排序并分章。
5. 生成叙事文本并写入日志。
6. 输出文本附 `event_ids` 映射。

### LLM 约束
- 输入只使用结构化事件与规则。
- 输出每段必须附 `event_ids`。
- 无法追溯来源的句子直接丢弃。

## 配置与界面

### 界面目标
- 一眼看到轮回、阶段和封印进度。
- 先给结论，再给原因。
- 仅关键事件弹窗，降低噪音。

### 界面结构
- HUD 轻量条常驻显示关键状态。
- 主面板结构为左导航 + 中内容 + 右详情。
- 全局搜索支持快速定位，快捷键为 `Ctrl/Cmd+K`。

### 导航栏目
- 总览：轮回、阶段、王国概况。
- 战局：魔王、将领、军团、英雄列表。
- 魔王图鉴：魔王主题和技能摘要。
- 技能库：技能筛选和开关。
- 封印与遗产：封印进度与遗产清单。
- 事件与日志：时间线和回放。
- 玩法百科：新手指引和核心规则。
- 设置：参数、预设、导入导出。
- 调试：仅开发模式显示。

### 页面规则
- 总览页展示轮回数、阶段、封印进度、魔王态势、遗产档位。
- 战局页按“魔王 → 将领 → 军团”展开。
- 遗迹在全阶段显示状态，仅封印战显示有效进度条。
- 技能库仅展示已启用且已注册的技能，军团单位不入库。
- 封印与遗产页上半区显示遗迹与封印，下半区显示遗产。
- 标注为“隐藏”的字段不进入 UI。

### 模式分级
- 玩家模式只显示安全常用参数。
- 高级模式显示全部参数。
- 开发模式显示调试项并二次确认。

### 收藏与展示
- 收藏开关为 `can_be_favorited`。
- 魔王、将领、命定英雄在生成或晋升时自动收藏。

### 导入导出闭环
1. 导出时将当前参数写入 JSON。
2. 导入时先解析并检查 `config_version`。
3. 版本不一致时先执行迁移再校验结果。
4. 展示差异预览，用户确认后继续。
5. 应用前自动创建备份文件。
6. 应用失败时回滚备份并提示失败原因。
7. 应用成功后写入新配置并记录更新时间。
8. 导出文件不包含敏感字段。

### 配置容错
- 可调项必须进入 UI 与配置文件。
- JSON 必须包含 `config_version`。
- 未知字段忽略，缺失字段补默认值。
- 非法值自动修正并给出提示。
- 负时间和负数量按 `0` 处理。
- 间隔 `<=0` 修正为最小正值。
- 概率超范围按 `0%-100%` 截断。
- `NaN/Infinity` 回退到安全值。
- 区间 `min>max` 自动互换。
- 倍率 `<=0` 修正为最小正值。

### 视觉规范
- 风格以信息清晰为先。
- 色彩为青蓝主色、绿色强调、红色警报。
- 字体为标题黑体、正文无衬线。
- 版式为网格对齐，一屏不超过三层信息。

### 资产注册
- 单位使用 `ActorAsset` 注册和生成。
- 建筑使用 `BuildingAsset` 注册和放置。
- 特性使用 `ActorTrait/KingdomTrait` 注册。
- 生成点需可行走并避开拥挤地块。

### 生成与模板
- 独立模板指使用不同 `ActorAsset` 模板 ID 生成。
- 魔王、将领、军团使用不同 `ActorAsset` 模板 ID 生成。
- 生成入口统一使用 `ActorManager.spawnNewUnit(ActorAssetID, ...)`。
- 推荐基于原生模板复制再改，字段更完整。
- 差异很大时再新建模板并补齐字段。
- 模板必须注册到 `AssetManager.actor_library` 才能生成。
- 不新增 MOD 生成判定或平衡规则。

### 字段与对象
- Actor 状态只写 `custom_data_*`。
- 装备归属与词条写入 Item 字段。
- City/Building 不写 Actor 字段。

### 数值口径
- 百分比按 `0%-100%` 展示和配置。
- 伤害默认按当前生命计算，最低扣到 `1HP`。
- 伤害倍率以 `damage` 为基准字段。
- 当前生命字段为 `health_current`。
- 最大生命字段为 `health_max`。
- 绝对值写 `base_stats`。
- 百分比写 `base_stats_meta`。
- 暴击率最终按 `0%-100%` 归一。

### 状态存储
- 状态写入只使用 `custom_data_int/long/float`。
- 计数与到期写 `custom_data_int`。
- 标识类写 `custom_data_long`。
- 比例类写 `custom_data_float`。

### 公共特质与多 MOD 清理
- 公共特质表只维护条目清单。
- 条目仅注册到特质编辑器并展示。
- 适用对象为所有Actor 单位。
- 获得、移除、互斥、随机、触发走原版闭环。
- 随机入口池沿用原版：`pot_traits_birth`、`pot_traits_growup`、`pot_traits_combat`、`pot_traits_mutation_box`。
- 资产字段沿用原版：`rate_birth`、`rate_inherit`。
- 资产字段沿用原版：`rate_acquire_grow_up`、`is_mutation_box_allowed`。
- 原版随机只作用 Actor，建筑与城市不参与。

**多 MOD 清理**
- 清理对象为魔王、将领、军团。
- 触发时机为生成时与刷新时。
- 白名单来源为原版特质 + 公共特质表条目。
- 清理方式为移除非白名单特质。
- 王国成员与英雄不参与清理。
- 清理只在触发点执行，不做高频巡检。

### 性能策略
- 军团 AI 使用低频更新。
- 王国统计按间隔更新。
- 轮回推进使用低频定时器。
- 轮回历史按轮数清理。
- 禁止全图扫描或高频巡检。

### 外观可改
- 单位外观和动画。
- 装备外观和能力。
- 建筑与遗迹外观。
- 技能特效与命名标记。

## 范围说明

### 范围内
- 轮回系统与阶段推进。
- 魔王、将领、军团自定义生成。
- 纪元遗产与跨轮回继承。
- 王国、英雄、外交机制。

## 版本验收

### 验收指标
| 指标 | 目标 |
|---|---|
| 完整轮回 | 同一存档完成 `5` 次轮回且计数正确 |
| 故事感 | LLM 叙事覆盖 `200+` 事件 |
| 可玩性 | 高轮回仍存在可解路径 |
| 易用性 | 关键参数可调且有分级 |
| 稳定性 | 配置错误不崩溃且有提示 |
| 遗产装备兼容 | 装备编辑器全局可见遗产装备条目且不影响公共特质编辑器 |
| 王国档位隔离 | 世界档位 `6` 且掌控度 `50%` 时，仅生效到 `3` 档装备池 |
| 王国装备流转闭环 | 工艺遗产解锁后装备由原版锻造入城库，再由成员取装 |
| 魔王装备直发闭环 | 无城市前提下魔王、将领、军团可直发装备 |
| 魔王参数闭环 | 角色概率、将领保底和周期重试按配置生效 |
| 多 MOD 防串 | 魔王侧仅保留白名单特质，王国侧保持原版逻辑 |
| 存档迁移一致性 | 旧存档升级后档位与掌控度规则保持一致 |

### 遗产装备测试
1. 装备编辑器全局可见遗产装备条目，且不影响公共特质编辑器。
2. 世界档位 `6` 且掌控度 `50%` 时，仅生效到 `3` 档池并入城库。
3. 不同王国掌控度不同，装备池隔离生效。
4. 入城库后成员按原版逻辑取装完成流转。
5. 无城市前提下，魔王、将领、军团可获得军备遗产装备。
6. 旧存档升级后不出现误走链路或全局误解锁。

### 研究遗产测试
1. 世界档位提升后，研究条目按王国档位解锁进入编辑器。
2. 特质编辑器全局显示全部研究条目。
3. 出生/成长/战斗/变异/继承获得时按王国档位过滤。
4. 未达标时在同池重抽，直到达标或耗尽次数。
5. 手动授予可绕过王国档位限制。
6. 旧存档迁移后解锁与档位规则保持一致。

### 数值遗产测试
1. 世界档位 `5`、掌控度 `60%` 时生效档位为 `3`。
2. 军事遗产档位 `3` 时攻防加成为 `+6%`。
3. 新单位生成时继承当前生效档位增益。
4. 领域遗产档位 `7` 时范围 `+21%`，次数 `+2`。
5. 领域遗产仅作用 MOD 技能，不影响原版技能。

### 魔王军备测试
1. 魔王生成时必得军备装备（`rate_demon_lord=1.0`）。
2. 将领连续失败达到 `3` 次后触发保底发放。
3. 无空槽位且新装备更好时执行替换。
4. 新装备更差时不替换，且不计失败。
5. 新装备更好时替换成功，失败次数清零。
6. 读档后失败次数与发放年份恢复正确。
7. 军备饰品可按槽位直发并遵守替换规则。
8. 原版装备链路行为不受影响。

### 多 MOD 特质测试
1. 外部特质注入后，魔王侧会清理非白名单特质。
2. 白名单仅包含原版特质与公共特质表条目。
3. 王国成员与英雄仍按原版逻辑获取外部特质。
4. 周期刷新与读档恢复后可清理旧污染。
5. 军备直发链路不受影响。
6. 刷新只巡检魔王势力单位，运行无明显卡顿。
