## 统一口径

**时间与触发**
- 时间单位统一为“游戏年份”。
- 轮回推进允许低频定时器，不做高频全图扫描。
- 技能触发只允许三钩子：命中、受击、死亡点。
- 到期、限频、范围处理只在触发点执行。

**事件钩子与状态存储**
- 命中钩子：`action_attack_target`。
- 受击钩子：`action_get_hit`。
- 死亡点钩子：`action_on_object_remove`。
- 优先使用 `ActionLibrary`，无现成动作再用自定义 `trait`。
- 状态写入：`custom_data_int/long/float`。

**数值口径**
- 百分比统一按 `0%-100%` 展示和配置。
- 伤害默认按当前生命计算，默认最低扣到 `1HP`。
- 伤害倍率以 `damage` 为基准字段。
- 当前生命字段：`health_current`，最大生命字段：`health_max`。
- 绝对值写 `base_stats`，百分比写 `base_stats_meta`。
- 暴击率最终按 `0%-100%` 归一。

**配置容错**
- 可调项必须进入 UI 与配置文件。
- JSON 必须包含 `config_version`。
- 未知字段忽略，缺失字段补默认值。
- 非法值自动修正并给出提示。
- 负时间和负数量按 `0` 处理。
- 间隔 `<=0` 修正为最小正值。
- 概率超范围按 `0%-100%` 截断。
- `NaN/Infinity` 回退到安全值。
- 区间 `min>max` 自动互换。
- 倍率 `<=0` 修正为最小正值。

**通用成长公式**
- 统一公式：`属性 = 基础值 × (1 + 成长倍率 × 轮回数)`。
- 基础值只在单位生成或晋升时随机写入一次。
- 轮回成长在轮回结算后生效。
- 魔王、将领、军团分别使用各自成长倍率和上限。

**技能资源与频率**
- 本规则仅对 MOD 自定义技能生效。
- 主动技能资源统一使用法力。
- 主动技能触发频率按“年”限频。
- 默认值如下，可在 UI 中调整。

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 法力消耗 | 主动技能消耗（普通 `5`）；主动技能消耗（终极 `10`） | 技能释放法力消耗默认值 |
| 触发频率 | 主动技能触发上限（`2次/年`）；终极技最小间隔（`2年`） | 年度限频默认值 |

**生成与挂载**
- 魔王槽位固定为 `P0+S1-S6`。
- 将领槽位固定为 `P0+S1`。
- 军团单位不挂载专属技能槽位。
- 魔王、将领、军团均使用独立模板生成。
- 不改写原版资产，专属技能表条目不进入公共随机池。
- 技能 trait 只在生成或晋升时挂载。
- 军团和普通生物可持有公共特质库中的条目。

**收藏规则**
- 收藏使用 `can_be_favorited` 与 `switchFavorite()`。
- 自动收藏仅作用于魔王、将领、命定英雄。
- 军团单位不进入自动收藏范围。

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 自动收藏 | 魔王/将领/命定英雄（多选） | 生成或晋升时自动收藏 |

## 特质分发

**概念定义**
- `TraitSourceType` 用于区分特质来源。
- `UnitExclusive` 表示专属技能表来源。
- `SharedPool` 表示公共特质库来源。
- `RuntimeMarker` 表示战斗临时标记来源。

**使用方式**

| 单位类型 | 来源类型 | 获得时机 | 是否随机 | 文档归属 |
|---|---|---|---|---|
| 魔王 | `UnitExclusive` | `Spawn` | 否 | `ERRE附属文档/魔王名册与技能表.md` |
| 魔王 | `SharedPool` | `Spawn/CombatRuntime` | 是 | `ERRE附属文档/公共特质表.md` |
| 将领 | `UnitExclusive` | `Spawn` | 否 | `ERRE附属文档/将领名册与技能表.md` |
| 将领 | `SharedPool` | `Spawn/CombatRuntime` | 是 | `ERRE附属文档/公共特质表.md` |
| 命定英雄 | `UnitExclusive` | `Promotion` | 是 | `ERRE附属文档/英雄专属随机池.md` |
| 命定英雄 | `SharedPool` | `Promotion/Inheritance/CombatRuntime` | 是 | `ERRE附属文档/公共特质表.md` |
| 英雄后裔 | `UnitExclusive` | `Inheritance` | 是（定向抽取） | `ERRE附属文档/英雄专属随机池.md` |
| 英雄后裔 | `SharedPool` | `Inheritance/CombatRuntime` | 是 | `ERRE附属文档/公共特质表.md` |
| 军团 | `SharedPool` | `Spawn/CombatRuntime` | 是（60条全量） | `ERRE附属文档/公共特质表.md` |
| 普通生物 | `SharedPool` | `Spawn/CombatRuntime` | 是（60条全量） | `ERRE附属文档/公共特质表.md` |

**获得流程**
1. 生成阶段先挂载专属技能表条目。
2. 晋升阶段补充英雄专属池条目。
3. 继承阶段先从最近英雄祖先已持有的专属条目池定向抽取。
4. 继承阶段再并行判定公共特质库条目。
5. 战斗中按事件附加运行时标记。

**冲突优先级**

| 优先级 | 规则 | 说明 |
|---|---|---|
| 1 | `UnitExclusive(Inheritance)` 保留 | 已继承祖先专属条目不被公共池替换 |
| 2 | `UnitExclusive` 保留 | 专属技能表条目不被公共池替换 |
| 3 | `SharedPool` 互斥校验 | 命中 `opposite` 时跳过并补抽 |
| 4 | `RuntimeMarker` 临时生效 | 只管理时效，不改永久来源 |

**注意事项**
- `TraitAcquireStage` 只使用 `Spawn/Promotion/Inheritance/CombatRuntime`。
- `TraitEligibility` 仅面向 Actor 单位判定。
- 建筑、地块、非 Actor 对象不参与公共特质资格。
- “专属技能表”“公共特质库”“运行时标记”是固定术语。
- 公共特质库支持混合、技能特效、行为三类共 `60` 条全量随机。

## 玩法闭环

**定义**
- 轮回起点：上一轮封印战胜利后进入预发展。
- 轮回终点：下一次封印战胜利结算完成。
- 封印战胜利支持两条路径：击杀胜利或仪式胜利。

**阶段流程**
1. 预发展
2. 预兆
3. 苏醒
4. 降临
5. 封印战（衰弱）
6. 战后重建

**系统关系**

| 系统 | 主要作用 | 关键输入 | 关键输出 |
|---|---|---|---|
| 轮回系统 | 驱动阶段推进与结算 | 繁荣度、封印值、轮回数 | 当前阶段、结算结果 |
| 魔王系统 | 决定魔王行为与强度 | 阶段、HP、魔王类型 | 技能激活、行为策略 |
| 将领系统 | 管理精英单位层 | 魔王类型、轮回数 | 将领生成、将领技能 |
| 军团系统 | 管理波次压制节奏 | 阶段、波次配置、军团库 | 军团数量、军团强度 |
| 封印遗迹 | 提供仪式封印路径 | 阶段、遗迹状态、争夺结果 | 封印进度、仪式胜利 |
| 遗产系统 | 记录跨轮回长期增益 | 轮回结算数据 | 王国、英雄、魔王增益 |
| 王国英雄 | 承担对抗与反哺 | 王国运行态、战果 | 抗魔等级、命定英雄 |
| 世界外交 | 组织共同讨伐窗口 | 魔王存活态、触发条件 | 停战状态、联合作战 |

## 核心总览

- 本章定义轮回内全部核心系统的职责与边界。
- 系统按“轮回驱动 → 战场对抗 → 结算继承”顺序展开。
- 具体清单和条目统一在附属文档维护。

## 轮回系统

**定义**
- 轮回系统负责阶段推进、双封印管理和结算发放。
- 阶段状态是轮回主状态，不与战斗子状态混用。
- 轮回计数在战后重建完成后 `+1`。

**阶段规则**
1. 预发展：
   - 触发：新档开始或战后重建结束。
   - 过程：按“预发展检查间隔”检测世界繁荣度。
   - 表现：将领封印和魔王封印均为初始强度，生成魔气节点。
   - 结束：人口或城市任一达到阈值，进入预兆。
2. 预兆：
   - 触发：繁荣度达阈值。
   - 过程：确定魔王据点并启动军团波次。
   - 表现：将领封印开始衰减，遗迹进入“显形”状态。
   - 结束：将领封印降为 `0%`，进入苏醒。
3. 苏醒：
   - 触发：将领封印为 `0%`。
   - 过程：激活将领系统并生成将领，魔王封印开始衰减。
   - 表现：遗迹进入“争夺”状态，可交战但不推进仪式进度。
   - 结束：魔王封印降为 `0%`，进入降临。
4. 降临：
   - 触发：魔王封印为 `0%`。
   - 过程：魔王实体生成并主动进攻，军团波次加速。
   - 表现：遗迹保持“争夺”状态，不推进仪式进度。
   - 结束：魔王 HP 低于衰弱阈值，进入封印战。
5. 封印战（衰弱）：
   - 触发：魔王 HP 低于衰弱阈值。
   - 过程：军团生成降速，遗迹切换“激活”并允许仪式推进。
   - 过程：魔王优先撤退与恢复，部分将领可能撤退或失控。
   - 结束：达成封印战胜利则进入战后重建；若 HP 回升到回退阈值则回降临。
6. 战后重建：
   - 触发：封印战胜利结算完成。
   - 过程：发放遗产、重置魔王位置与强度、写入轮回历史。
   - 结果：返回预发展，准备下一轮。

**封印战胜利判定**
- 击杀胜利：直接击杀魔王，立即触发胜利结算。
- 仪式胜利：激活遗迹达到占领数阈值且仪式进度满。
- 双通道胜利：任意一条路径达成即判定胜利。

**存档规则**
- 轮回状态、计数、关键进度写入 MOD 存档。
- 读档后自动恢复阶段、封印值和计时器。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 预兆触发 | 世界现存人口阈值（`5000`）；世界现存城市阈值（`20`）；预发展检查间隔（`10年`） | 人口或城市任一达标进入预兆 |
| 将领封印 | 将领封印初始强度（`100%`）；将领封印衰减速率（`1%/年`） | 预兆阶段开始衰减 |
| 魔王封印 | 魔王封印初始强度（`100%`）；魔王封印衰减速率（`1%/年`） | 苏醒阶段开始衰减 |
| 封印胜利 | 封印胜利模式（击杀/仪式/双通道） | 胜利方式选择 |

## 魔王系统

**定义**
- 魔王系统负责魔王实体、技能行为和强度状态切换。
- 多魔王时由互动模式管理阵营关系。
- 魔王成长使用通用成长公式。

**状态模型**
- 阶段状态：预发展 → 预兆 → 苏醒 → 降临 → 封印战 → 战后重建。
- 战斗子状态：仅在降临期生效，包含“全盛、常态”。
- 阶段状态决定实体和波次，子状态只影响强度与频率。

**阶段行为表**

| 阶段 | 技能激活 | 军团生成 | 将领数量 | 魔王实体 | 说明 |
|---|---|---|---|---|---|
| 预发展 | 否 | 否 | `0` | 否 | 等待繁荣度触发 |
| 预兆 | 否 | 是 | `0` | 否 | 军团出波，将领封印衰减 |
| 苏醒 | 将领技能 | 是 | 固定 `5` | 否 | 将领生成，魔王封印衰减 |
| 降临 | 全部可用 | 是 | 存活数 | 是（全盛/常态） | 魔王入侵 |
| 封印战 | 全部可用 | 是（降速） | 存活数 | 是（虚弱） | 封印战争夺 |
| 战后重建 | 否 | 否 | `0` | 否 | 结算与重置 |

**战斗子状态规则**
- 全盛：HP 高于全盛阈值，法力恢复 `+50%`，波次速度 `×2`。
- 常态：HP 位于衰弱阈值和全盛阈值之间。
- 子状态切换只依据 HP 阈值，不改变轮回阶段。

**多魔王互动**
- 触发：本轮苏醒数 `>=2` 或当前存活数 `>=2`。
- 模式：联盟、内战、随机。
- 联盟模式：共享敌对关系并强制停火，单体强度小幅下调。
- 内战模式：魔王互相宣战，同时继续攻击王国。
- 内战胜者获得称号和限时属性加成。
- 保护规则：魔王数量 `<2` 时，互动机制不生效。

**阵营外交规则**
- 魔王阵营单位生成即敌对所有非魔王阵营单位。
- 魔王阵营主动攻击非魔王阵营单位。
- 王国与魔王阵营保持战争。
- 魔王阵营不建城，不参与王国外交。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 魔王池与苏醒 | 魔王启用默认（多选）；魔王苏醒模式（指定/随机）；苏醒数量（`1`） | 控制本轮魔王构成 |

| 内战主导权 | 内战最大魔王数（`5`）；加成时长（`10年`）；加成属性比例（`10%`） | 胜者限时加成 |

## 军团系统

**定义**
- 军团是魔王阵营波次单位，用于持续施压。
- 军团单位不挂载专属技能槽位。
- 军团可持有公共特质库全部 `60` 条（混合/技能/行为）。
- 军团总量受“同时上限”约束。

**波次规则**
- 预兆阶段生成第一波。
- 后续按“军团生成间隔”持续出波。
- 波次强度：`基础强度 × (1 + 递增 × 波次)`。
- 波次数量：按“数量递增”随波次提高。
- 强度和数量都在“出波时”计算。

**生成规则**
- 军团使用独立模板生成。
- 转化机制使用替换生成实现。
- 据点不存在时在魔王附近生成。
- 生成点必须可行走并避开水域。

**成长规则**
- 军团成长使用通用成长公式。
- 军团最终叠加顺序：随机值 → 轮回成长 → 波次强度。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 波次节奏 | 军团生成间隔（`10年`）；军团初始数量（`40`）；军团强度递增（`15%/波`）；军团同时上限（`300`） | 出波节奏与总量控制 |
| 阶段波次 | 军团全盛生成间隔（`5年`）；封印战生成间隔（`15年`） | 降临与封印战节奏 |
| 波次数量 | 波次数量递增（`15%/波`） | 每波单位数增长 |
| 轮回成长 | 轮回成长倍率（`15%/轮回`）；成长硬上限（`250%`） | 军团成长参数 |

## 封印遗迹

**定义**
- 封印遗迹是轮回内可见、可争夺、可用于仪式的建筑。
- 遗迹状态固定为“显形、争夺、激活”三态。
- 仪式胜利通过激活遗迹推进封印进度达成。

**状态与生命周期**
- 预兆阶段：生成或显形遗迹，状态为“显形”。
- 苏醒和降临：状态为“争夺”，可交战但不推进仪式。
- 封印战：状态切换为“激活”，允许占领和进度推进。
- 战后重建：统一移除本轮遗迹。
- 生成点需避开深水和拥挤区域。

**仪式规则**
- 仅“激活”状态可以触发占领和进度推进。
- 非激活状态进度锁定，不增长。
- 触发占领需要范围清场且人数达阈值。
- 占领后进度持续推进，不要求持续驻守。
- 敌方人数达到阈值时，进度按配置中断、回退或清零。
- 达到占领数阈值且总进度满时，判定仪式胜利。

**争夺调度闭环**
1. 进入预兆后启动调度计时器。
2. 达到调度间隔后选取目标遗迹（敌占领、未占领、最近、随机）。
3. 向目标同时派遣魔王阵营与附近王国小队。
4. 进入遗迹范围后执行占领判定和收益判定。
5. 未达打断阈值时继续推进进度。
6. 达打断阈值后按“暂停/回退/清零”执行处理。
7. 发生封印战胜利或进入战后重建时停止调度并清理队列。

**占领收益**
- 同阵营收益不叠加。
- 占领后友军获得范围增益。
- 收益半径和增益强度可配置。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 遗迹数量与阈值 | 封印遗迹数量（`10`）；占领遗迹数量阈值（`8`） | 遗迹总数和达标要求 |
| 仪式占领与进度 | 仪式占领人数阈值（`10`）；仪式进度速度（`3%/年`） | 占领条件和推进速度 |
| 仪式打断与回退 | 仪式中断敌方人数阈值（`15`）；中断处理（暂停/回退/清零）；回退速度（`3%/年`） | 打断规则 |
| 热点调度 | 热点开关；调度间隔（`5年`）；目标策略（敌占领/未占领/最近/随机） | 争夺调度规则 |
| 派遣规模 | 派遣王国人数（`40`）；派遣魔王人数（`40`） | 每次派遣规模 |
| 占领收益 | 收益半径（`12`）；友军增益（`10%`）；叠加上限（`1`） | 遗迹收益配置 |

## 遗产系统

**定义**
- 纪元遗产在轮回结算时发放。
- 遗产跨轮回继承并长期生效。
- 遗产分为解锁类和数值类两组。

**分类与作用对象**

| 遗产类型 | 规则摘要 | 作用对象 |
|---|---|---|
| 工艺遗产 | 解锁王国装备池，按概率获得 | 王国与英雄 |
| 研究遗产 | 解锁研究技能池，按概率获得 | 王国与英雄 |
| 军事遗产 | 伤害与防御按档位递增 | 王国与英雄 |
| 军备遗产 | 解锁魔王势力装备池，按概率获得 | 魔王势力 |
| 领域遗产 | 领域技能范围与次数提升 | 魔王与将领 |

**档位规则**
- 世界档位随轮回结算推进。
- 解锁类遗产只扩展清单，不直接叠数值。
- 数值类遗产按档位叠加。
- 档位上限可配置。

**王国掌握度规则**
- 存活王国直接使用世界档位。
- 新建王国按掌握度折算生效档位。
- 生效档位公式：`floor(世界档位 × 掌握度)`。
- 掌握度范围是 `0%-100%`。
- 新王国最低档位可配置。

**掌握度计算**
- 公式：`掌握度 = 基础分 + Σ(指标分 × 权重)`。
- 指标：书籍、城市、人口、军力、建筑。
- 权重和阈值由参数表统一配置。

**发放规则**
- 每轮回结算时推进档位。
- 第 `N` 次轮回对应第 `N` 档。
- 工艺、研究、军备清单放在附属文档维护。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 档位推进 | 遗产档位上限（`10`）；每轮回档位提升（`1`） | 档位上限和推进节奏 |
| 新王国继承 | 新王国档位下限（`1`）；掌握度刷新间隔（`10年`） | 新王国继承规则 |
| 掌握度基础分 | 数值（`0.20`） | 固定基础分 |
| 掌握度书籍类 | 阈值：文化`5`、宗教`5`、语言`5`、首都`5`、全城`20`；权重：`0.10/0.10/0.05/0.10/0.05` | 书籍评分 |
| 掌握度规模类 | 阈值：城市`5`、人口`688`、军力`200`、建筑`6`；权重：`0.15/0.10/0.10/0.05` | 规模评分 |

**数值类遗产参数**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 军事遗产 | 每档攻击加成（默认 `2%`）；每档防御加成（默认 `2%`） | 对王国和英雄生效 |
| 领域遗产 | 每档范围加成（默认 `3%`）；次数加成公式（默认 `floor((档位-1)/3)`，上限 `3`） | 仅影响 MOD 技能 |

**口径约束**
- 军事遗产只对王国和英雄生效。
- 魔王侧数值强化由军备遗产承接。

## 王国英雄

**定义**
- 王国英雄系统包含抗魔等级、命定英雄、家族继承三部分。
- 抗魔等级是王国维度长期成长。
- 命定英雄是轮回中的关键单位。

**抗魔等级**
- 王国通过击杀魔王阵营单位提升抗魔等级。
- 封印战胜利可提供额外加成。
- 新建或复国王国从 `0` 级开始。

**抗魔等级效果**

| 等级 | 效果1 | 效果2 | 效果3 |
|---|---|---|---|
| Lv1 | 命中 `+5%` | 攻速 `+5%` | - |
| Lv2 | 伤害 `+5%` | 生命 `+5%` | - |
| Lv3 | 体力 `+10%` | 法力 `+10%` | - |
| Lv4 | 防御 `+8%` | 移速 `+5%` | - |
| Lv5 | 暴击率 `+5%` | 暴伤 `+15%` | - |
| Lv6 | 伤害 `+8%` | 防御 `+6%` | - |
| Lv7 | 射程 `+10%` | 投掷射程 `+10%` | - |
| Lv8 | 生命 `+10%` | 移速 `+5%` | - |
| Lv9 | 攻速 `+8%` | 暴击率 `+3%` | - |
| Lv10 | 战斗熟练 `+20%` | 法术熟练 `+20%` | 状态触发 `+10%` |

**命定英雄规则**
- 每王国有数量上限。
- 事件触发为主，定期兜底检测为辅。
- 达到繁荣条件或危机条件时可触发晋升。

**晋升优先级（闭环）**
1. 先检查世界总英雄上限。
2. 再检查王国当前英雄上限。
3. 再检查王国晋升冷却是否结束。
4. 再判断繁荣或危机触发条件是否达成。
5. 以上全部满足后，才进入候选筛选与评分。

**评分规则**
- 候选池：同王国、存活、非魔王阵营。
- 指标：等级、击杀、生命、攻击、领导力。
- 公式：`综合分 = Σ(min(指标/阈值,1) × 权重)`。
- 从前 `N` 名中随机 `1` 名晋升。
- 现英雄单位不参与评分。

**晋升强化**
- 晋升时随机写入基础值。
- 晋升时抽取英雄随机特质与随机技能。
- 命定英雄固定 `P0「英勇」`。

**家族继承**
- 仅王国新生单位在出生时判定继承。
- 出生入口为 `all_actions_actor_birth`。
- 使用 `parent_id_1/parent_id_2` 追溯最近英雄祖先。
- 英雄祖先存活与否不影响继承判定。

**血脉追溯规则**
1. 出生后读取父母 `parent_id_1/parent_id_2`。
2. 在双亲血脉中选择最近英雄祖先。
3. 双亲都命中时按代数最近优先。
4. 超过可继承代数时终止继承。
5. 无英雄祖先时直接结束。

**后裔继承规则**
1. 命中英雄祖先后按概率判定继承。
2. 属性按“祖先晋升基础值 × 继承比例”写入。
3. 继承池只使用“最近英雄祖先当前已持有的英雄专属技能与专属特质”。
4. 按配置条目数在祖先持有池内定向抽取，不使用全局英雄池盲抽。
5. 祖先专属继承完成后，才进入公共特质池并行判定。
6. 每代继承次数受上限约束。

**状态存储**
- 血脉根 ID 写入 `custom_data_long`。
- 血脉代数写入 `custom_data_int`。
- 状态随单位存档与读档恢复。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 抗魔等级成长 | 等级上限（`10`）；击杀阈值（`1000/0.5级`）；封印加成（`0.5级/次`） | 抗魔等级成长 |
| 英雄与冷却 | 每王国英雄上限（`1`）；世界总英雄上限（`50`）；晋升冷却（`30年`）；兜底检测间隔（`5年`） | 数量与节奏 |
| 晋升条件繁荣 | 人口阈值（`500`）；城市阈值（`2`） | 繁荣触发条件 |
| 晋升条件危机 | 统计窗口（`10年`）；人口跌幅（`50%`） | 危机触发条件 |
| 候选与评分 | 权重（等级`0.25`、击杀`0.25`、生命`0.15`、攻击`0.15`、领导力`0.20`）；阈值（`10/50/1000/100/100`）；取前N（`3`） | 过滤与评分 |
| 晋升奖励 | 随机特质数（`3`）；随机技能数（`6`） | 晋升强化 |
| 家族继承 | 触发概率（`30%`）；继承属性比例（`30%`）；继承祖先专属特质条目数（`2`）；继承祖先专属技能条目数（`4`）；可继承代数（`10`）；每代继承次数上限（`1`）；晋升评分每档加成（`5%`） | 继承规则 |

## 叙事事件

**定义**
- 叙事事件只记录真实发生内容。
- 不新增人物、地点、时间。
- 不改变先后顺序和因果关系。

**数据来源**
- 世界历史日志。
- 战争系统与阴谋系统。
- MOD 自定义事件。

**统一事件结构**
```
id: 全局唯一
year: 年份
source: world_log / plot / war / mod
type: city_new / war_started / demon_awake ...
entities: kingdom_id / city_id / unit_id / plot_id / war_id
location: x,y
raw_text: 原文或短句摘要
importance: 重要度
```

**生成流程**
1. 增量采集并记录 `last_year`。
2. 标准化为统一事件结构。
3. 维护死亡时间线校验。
4. 按年份排序并分章。
5. 生成叙事文本并附来源映射。

**LLM 约束**
- 输入只使用结构化事件和规则。
- 输出每段必须附 `event_ids`。
- 无法追溯来源的句子直接丢弃。

**LLM 输入与输出**
```
inputs:
  events: [{ id, year, type, raw_text, entities, location }]
  rules: ["不得新增人物/地点/时间", "不得改变先后与因果", "每句必须引用 event_ids"]
outputs:
  paragraphs: [{ text: "...", event_ids: [1,2,3] }]
```

## 属性随机

**定义**
- 属性随机只作用于 MOD 自定义单位。
- 随机值写入基础字段，不写入百分比元字段。
- 属性随机与轮回成长可叠加。

**触发时机**
- 魔王和将领：生成时随机一次。
- 军团：每波次随机一次并共享该波结果。
- 命定英雄：晋升时随机一次。

**字段范围**
- 生命、寿命、防御、伤害。
- 法力上限、体力、暴击率。
- 移速、攻速。

**叠加顺序**
- 随机值 → 轮回成长 → 特质/遗产。

**随机范围（首轮）**

| 单位类型 | 生命 | 寿命 | 防御 | 伤害 | 法力上限 | 体力 | 暴击率 | 移速 | 攻速 | 时机 |
|---|---|---|---|---|---|---|---|---|---|---|
| 魔王 | `80000-200000` | `99999-99999` | `400-1000` | `800-2000` | `100-300` | `200-500` | `8%-25%` | `8-12` | `0.8-1.2` | 生成时 |
| 将领 | `4000-12000` | `99999-99999` | `80-250` | `200-500` | `100-200` | `120-300` | `6%-18%` | `10-15` | `0.9-1.3` | 生成时 |
| 军团 | `200-1200` | `99999-99999` | `10-80` | `20-120` | `50-100` | `80-180` | `2%-10%` | `9-13` | `0.9-1.3` | 出波时 |
| 英雄 | `2000-8000` | `200-500` | `50-200` | `120-350` | `100-250` | `150-350` | `6%-18%` | `10-14` | `0.9-1.3` | 晋升时 |

**随机范围平移**
- 本轮平均值作为下轮下限。
- 上限保持初始宽度不变。
- 本轮未生成则沿用当前范围。
- 玩家手动改动后清零偏移。

## 配置界面

**界面目标**
- 一眼看到轮回、阶段和封印进度。
- 先给结论，再给原因。
- 仅关键事件弹窗，降低噪音。

**界面结构**
- HUD 轻量条常驻显示关键状态。
- 主面板结构为“左导航 + 中内容 + 右详情”。
- 全局搜索支持快速定位，快捷键是 `Ctrl/Cmd+K`。

**导航栏目**
- 总览：轮回、阶段、王国概况。
- 战局：魔王、将领、军团、英雄列表。
- 魔王图鉴：魔王主题和技能摘要。
- 技能库：技能筛选和开关。
- 封印与遗产：封印进度与遗产清单。
- 事件与日志：时间线和回放。
- 玩法百科：新手指引和核心规则。
- 设置：参数、预设、导入导出。
- 调试：仅开发模式显示。

**页面规则**
- 总览页展示轮回数、阶段、封印进度、魔王态势、遗产档位。
- 战局页按“魔王 → 将领 → 军团”展开。
- 遗迹在全阶段显示状态，仅封印战显示有效进度条。
- 技能库仅展示可用技能，军团单位不入库。
- 封印与遗产页上半区显示遗迹与封印，下半区显示遗产。

**模式分级**
- 玩家模式：只显示安全常用参数。
- 高级模式：显示全部参数。
- 开发模式：显示调试项并二次确认。

**导入导出闭环**
1. 导出：将当前参数写入 JSON。
2. 导入：先解析并检查 `config_version`。
3. 若版本不一致，先执行迁移再校验结果。
4. 展示差异预览，用户确认后继续。
5. 应用前自动创建备份。
6. 应用失败时立刻回滚备份并提示失败原因。
7. 应用成功后写入新配置并记录更新时间。

**导入导出约束**
- 未知字段忽略，缺失字段补默认。
- 导出文件不包含敏感字段。
- 非法值在导入阶段执行统一容错修正。

**视觉规范**
- 风格：信息清晰优先。
- 色彩：青蓝主色、绿色强调、红色警报。
- 字体：标题黑体、正文无衬线。
- 版式：网格对齐，一屏不超过三层信息。

**核心 API 口径**

| API/功能 | 用途 | 状态 |
|---|---|---|
| `AssetManager.actor_library` | 注册单位模板 | 已确认 |
| `AssetManager.buildings` | 注册建筑模板 | 已确认 |

| `World.world.units/kingdoms/cities/wars` | 运行态数据入口 | 已确认 |
| `World.world.wars.newWar/endWar` | 建战与结束战争 | 已确认 |

| JSON 文件 IO | 存档与配置 | 已确认 |
| `WorldTile.setTileType(...)` | 地形改造 | 已确认 |

**资产注册原则**
- 单位使用 `ActorAsset` 注册和生成。
- 建筑使用 `BuildingAsset` 注册和放置。
- 特性使用 `ActorTrait/KingdomTrait` 注册。
- 生成点需可行走并避开拥挤地块。

**性能策略**
- 军团 AI 使用低频更新。
- 王国统计按间隔更新。
- 轮回推进使用低频定时器。
- 轮回历史按轮数清理。

**可自定义外观**
- 单位外观和动画。
- 装备外观和能力。
- 建筑与遗迹外观。
- 技能特效与命名标记。

**明确不做**
- 新音效资源加载。
- 骨骼或 3D 动画替换。

**公共特质**
- `ERRE附属文档/公共特质表.md` 是公共特质库的唯一清单。
- 公共特质库可作用于全生物 Actor 单位。
- 魔王、将领、英雄的专属技能表不承担公共特质库定义。

## 版本验收

**范围内**
- 轮回系统与阶段推进。
- 魔王、将领、军团自定义生成。
