# 基础口径

## 术语
| 术语 | 含义 |
|---|---|
| 轮回 | 从一次封印战胜利到下一次封印战胜利的周期。 |
| 阶段 | 轮回内的进程分段，按固定顺序推进。 |
| 封印战胜利 | 封印战达成胜利结算，可由击杀或仪式触发。 |
| 王国 | 游戏中的 Kingdom 实体，拥有城市、人口和外交关系。 |
| 将领封印/魔王封印 | 控制将领与魔王解封进度的双封印机制。 |
| 三钩子 | 技能触发三种钩子：命中、受击、死亡点。 |
| 魔王/将领/军团 | 三层敌对结构：魔王（核心）→ 将领（精英）→ 军团（波次）。 |
| 轮回传承 | 轮回结算后给予王国、英雄、魔王的长期增益。 |
| LLM | 大语言模型，仅用于叙事文本组织。 |
| NeoModLoader | WorldBox 的 MOD 加载框架。 |

## 时间口径
- 时间单位统一为游戏年份。
- 周期与间隔按年计算。

## 对象口径
- 先确认目标是否为 Actor 单位。
- 城市与建筑不参与。
- 传承档位先分类型，再按对象范围应用。

## 技能口径
- 触发类型只允许：常驻、命中、受击、死亡点、主动。
- 同一技能可绑定多个触发点。
- 击杀、低血、累计只做触发后条件判定。
- 到期、限频与范围只在触发点处理。
- 主动技能统一消耗法力。
- 主动技能按年限频。
- 条目限频与消耗优先于默认值。

## 槽位口径
- `P0` 表示被动技能。
- `S1-S6` 表示主动技能。

## 技能参数
| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 法力消耗 | 主动技能消耗（普通 `5`）；主动技能消耗（终极 `10`） | 技能释放法力消耗默认值。 |
| 触发频率 | 主动技能触发上限（`2次/年`）；终极技最小间隔（`2年`） | 年度限频默认值。 |

## 效果表达
- 描述顺序：触发 → 概率 → 条件 → 效果 → 持续 → 限频。
- 未写概率视为 `100%`，仍受限频。
- 主动表示消耗法力触发，并带冷却。
- “短眩晕/短混乱/短减速”使用原版默认时长。
- 低血未写阈值时默认 `30%`。
- “回填”表示受击后恢复本次伤害比例。
- “控制时长缩短”只作用于 MOD 控制。
- “当前生命伤害”最低保留 `1HP`。

# 玩法闭环

## 阶段顺序
1. 预发展。
2. 预兆。
3. 苏醒。
4. 降临。
5. 封印战。
6. 战后重建。

## 胜利路径
- 击杀魔王。
- 仪式封印。
- 任一路径达成即进入结算。

## 闭环说明
- 轮回系统推进阶段。
- 封印战胜利触发结算。
- 结算发放传承并进入下一轮。

## 轮回系统

### 定义
- 轮回系统负责阶段推进、双封印管理和结算发放。
- 战后重建完成后轮回数 `+1`。

### 规则
- 阶段状态由轮回系统驱动。
- 阶段触发阈值来自人口、城市、封印进度与 HP。
- 封印战触发条件为 HP 低于封印战触发阈值。
- HP 回升到封印战回退阈值则回到降临。
- 胜利条件由配置指定，可多选。
- 只有勾选条件才参与判定。
- 任一勾选条件达成即胜利结算。
- 未勾选条件即使满足也不判胜利。

### 流程
1. 预发展。新档或战后重建结束进入。系统按检查间隔读取人口与城市，达阈值进入预兆。
2. 预兆。系统确定本轮魔王名单并各自生成据点。军团进入出波阶段，将领封印开始衰减，遗迹显形。
3. 苏醒。将领封印降为 `0%` 触发。系统生成将领并激活其技能，魔王封印开始衰减，遗迹进入争夺。
4. 降临。魔王封印降为 `0%` 触发。系统生成魔王实体并主动进攻，军团波次加速，遗迹保持争夺。
5. 封印战。魔王 HP 低于阈值触发。军团生成降速，遗迹切换为激活。魔王优先撤退与恢复，HP 回升到回退阈值则回到降临。
6. 战后重建。封印战胜利后进入。系统发放传承并重置魔王位置与强度。阶段回到预发展并写入轮回历史。

### 参数表
| 参数组 | UI可调控参数 | 说明 |
|---|---|---|
| 预兆触发 | 世界现存人口阈值（`5000`）；世界现存城市阈值（`20`）；预发展检查间隔（`10年`） | 人口或城市任一达标进入预兆。 || 将领封印 | 将领封印初始强度（`100%`）；将领封印衰减速率（`1%/年`） | 预兆阶段开始衰减。 |
| 魔王封印 | 魔王封印初始强度（`100%`）；魔王封印衰减速率（`1%/年`） | 苏醒阶段开始衰减。 |
| 封印胜利 | 封印胜利条件（击杀/仪式，可多选） | 胜利条件选择。 |
| 封印战阈值 | 触发阈值（`40%`）；回退阈值（`70%`） | 降临与封印战切换阈值。 |

### 存档
- 轮回状态、计数与进度写入 MOD 存档。
- 读档后恢复阶段、封印进度与计时器。

### 边界
- 轮回系统只管理阶段推进与结算。
- 战斗子状态不驱动阶段。

## 魔王系统

### 定义
- 魔王系统负责魔王实体、技能行为与强度切换。
- 多魔王关系由互动模式管理。

### 战斗子状态
- 全盛：HP 高于全盛阈值。
- 常态：HP 位于全盛阈值与衰弱阈值之间。
- 衰弱：HP 低于衰弱阈值。
- 子状态只做数值修正，不驱动阶段。

### 多魔王互动
- 触发条件：本轮苏醒数 `>=2` 或当前存活数 `>=2`。
- 互动模式：联盟、内战、随机。
- 随机模式：关系校验间隔到期时重掷并应用。
- 联盟模式：共享敌对关系并强制停火。
- 联盟强度=原强度 × 联盟强度系数。
- 内战模式：魔王互相宣战，同时继续攻击王国。
- 内战强度=原强度 × 内战强度系数。
- 内战胜者获得称号与限时属性加成。
- 魔王数量 `<2` 时机制不生效。

### 阵营外交
- 魔王阵营单位生成即敌对所有非魔王阵营单位。
- 魔王阵营主动攻击非魔王阵营单位。
- 王国与魔王阵营保持战争。

### 魔王势力生成
- 魔王势力单位指魔王、将领、军团三类。
- 三类单位使用不同 `ActorAsset` 模板 ID 生成。
- 生成后按原版随机池获取特质。
- 魔王技能槽位固定为 `P0+S1-S6`。

### 阶段行为表
| 阶段 | 技能激活 | 军团生成 | 将领数量 | 魔王实体 | 说明 |
|---|---|---|---|---|---|
| 预发展 | 否 | 否 | `0` | 否 | 等待人口/城市阈值触发。 |
| 预兆 | 否 | 是 | `0` | 否 | 军团出波，将领封印衰减。 |
| 苏醒 | 将领技能 | 是 | 固定 `5` | 否 | 将领生成，魔王封印衰减。 |
| 降临 | 全部可用 | 是 | 存活数 | 是（全盛/常态） | 魔王入侵。 |
| 封印战 | 全部可用 | 是（降速） | 存活数 | 是（衰弱） | 封印战争夺。 |
| 战后重建 | 否 | 否 | `0` | 否 | 结算与重置。 |

### 参数表
| 参数组 | UI可调控参数 | 说明 |
|---|---|---|
| 魔王池与苏醒 | 魔王启用默认（多选）；魔王苏醒模式（指定/随机）；苏醒数量（`1`） | 控制本轮魔王构成。 |
| 战斗态阈值 | 战斗全盛阈值（`70%`）；战斗衰弱阈值（`30%`） | 子状态阈值与强度。 |
| 轮回成长 | 轮回成长倍率（`25%/轮回`）；成长硬上限（`250%`） | 魔王成长参数。 |
| 多魔王模式 | 互动模式（联盟/内战/随机）；关系校验间隔（`3年`）；联盟强度系数（`85%`）；内战强度系数（`100%`） | 关系维护和强度修正。 |
| 内战主导权 | 内战最大魔王数（`5`）；加成时长（`10年`）；加成属性比例（`10%`） | 胜者限时加成。 |

### 边界
- 魔王阵营不建城。
- 魔王阵营不参与王国外交。

## 将领系统

### 定义
- 将领是魔王阵营精英单位，用于指挥和关键战斗。

### 规则
- 每个魔王固定 `5` 名将领。
- 将领只在苏醒阶段生成一次。
- 将领死亡后不补充。
- 生成点优先魔王据点或魔王附近。
- 将领技能槽位固定为 `P0+S1+S2`。

### 参数表
| 参数组 | UI可调控参数 | 说明 |
|---|---|---|
| 轮回成长 | 轮回成长倍率（`20%/轮回`）；成长硬上限（`250%`） | 将领成长参数。 |

## 军团系统

### 定义
- 军团是魔王阵营波次单位，用于持续施压。

### 规则
- 军团总量受“同时上限”约束。

### 波次规则
- 预发展与战后重建不出波。
- 预兆阶段生成第一波。
- 预兆与苏醒阶段使用“军团生成间隔”。
- 降临阶段使用“全盛生成间隔”。
- 封印战阶段使用“衰弱生成间隔”。
- 波次强度：`基础强度 × (1 + 递增 × 波次)`。
- 波次数量：按“数量递增”随波次提高。
- 强度与数量都在出波时计算。

### 上限处理
- 本波数量=`min(计划数量, 同时上限-当前存活)`。
- 结果 `<=0` 时跳过本波并记录日志。

### 生成规则
- 军团使用独立模板生成。
- 魔王据点不存在时在魔王附近生成。

### 成长规则
- 军团成长使用通用成长公式。

### 参数表
| 参数组 | UI可调控参数 | 说明 |
|---|---|---|
| 波次节奏 | 军团生成间隔（`10年`）；军团初始数量（`40`）；军团强度递增（`15%/波`）；军团同时上限（`300`） | 出波节奏与总量控制。 |
| 降临与封印战 | 全盛生成间隔（`5年`）；衰弱生成间隔（`15年`） | 降临与封印战节奏。 |
| 波次数量 | 波次数量递增（`15%/波`） | 每波单位数增长。 |
| 轮回成长 | 轮回成长倍率（`15%/轮回`）；成长硬上限（`250%`） | 军团成长参数。 |

## 封印遗迹

### 定义
- 封印遗迹是轮回内可见、可争夺、可用于仪式的建筑。

### 规则
- 遗迹固定为显形、争夺、激活三态。
- 仪式胜利通过激活遗迹推进封印进度达成。
- 小队为派遣单位集合，人数由派遣人数参数控制。

### 状态与生命周期
- 预兆阶段生成或显形遗迹，状态为显形。
- 苏醒和降临阶段为争夺，可交战不推进仪式。
- 封印战阶段切换为激活，允许占领与进度推进。
- 战后重建阶段移除本轮遗迹。
- 生成点需避开深水与拥挤区域。

### 仪式规则
- 仅激活状态可以触发占领与进度推进。
- 非激活状态进度锁定，不增长。
- 友军人数达到阈值且敌军人数低于中断阈值时才推进。
- 占领后进度持续推进，不要求持续驻守。
- 敌方人数达到阈值时按配置中断、回退或清零。
- 达到占领数阈值且总进度满时判定仪式胜利。

### 争夺调度闭环
1. 进入预兆阶段后启动调度计时器。
2. 达到调度间隔后选取目标遗迹。
3. 派遣最近 `N=2` 个王国小队，可配置。
4. 同时派遣魔王阵营小队。
5. 进入遗迹范围后执行占领与收益判定。
6. 未达打断阈值时继续推进进度。
7. 达打断阈值后按暂停、回退或清零处理。
8. 封印战胜利或进入战后重建时清理队列。

### 收益
- 同阵营收益不叠加。
- 占领后友军获得范围增益。
- 收益半径与强度可配置。

| 参数组 | UI可调控参数 | 说明 |
|---|---|---|
| 遗迹数量与阈值 | 封印遗迹数量（`10`）；占领遗迹数量阈值（`8`） | 遗迹总数和达标要求。 |
| 仪式占领与进度 | 仪式占领人数阈值（`10`）；仪式进度速度（`3%/年`） | 占领条件和推进速度。 |
| 仪式打断与回退 | 仪式中断敌方人数阈值（`15`）；中断处理（暂停/回退/清零）；回退速度（`3%/年`） | 打断规则。 |
| 热点调度 | 热点开关；调度间隔（`5年`）；目标策略（敌占领/未占领/最近/随机） | 争夺调度规则。 |
| 派遣规模 | 派遣王国数量（`2`）；派遣王国人数（`40`）；派遣魔王人数（`40`） | 每次派遣规模。 |
| 占领收益 | 收益半径（`12`）；友军增益（`10%`）；叠加上限（`1`） | 遗迹收益配置。 |

## 传承系统

### 定义
- 轮回结算后发放传承。
- 传承效果跨轮回生效。
- 传承分为解锁类与数值类。
- 装备传承包含王国锻造链路与魔王直发链路。

### 类型与对象
| 传承类型 | 作用对象 | 说明 |
|---|---|---|
| 装备传承 | 王国成员/魔王势力 | 解锁装备条目，按链路发放。 |
| 特质传承 | 王国成员/魔王势力 | 解锁特质条目（扩展特质编辑器）。 |
| 军事传承 | 王国成员 | 攻防按档位叠加。 |
| 领域传承 | 魔王/将领 | 技能范围与次数提升。 |

### 通用规则
- 编辑器可见不等于已授予。
- 解锁类传承只扩展清单，不直接叠数值。
- 数值类传承按档位叠加。
- 王国成员按王国档位，魔王势力按世界档位。
- 特质传承只登记条目并走原版随机池。
- 特质传承不做自动授予。

### 装备传承规则
- 每档位仅 `3` 件装备。
- 王国锻造链路只做条目注册与解锁。
- 槽位按武器、头盔、盔甲、靴子、戒指、护符六类。
- 六槽位可跨档位覆盖。
- 条目数量由附属清单维护。

### 档位与掌控度
- 世界档位随轮回结算推进。
- 世界档位上限见参数表。
- 王国生效档位公式：`max(新王国档位下限, floor(世界档位 × 掌控度))`。
- 魔王装备档位等于世界档位。
- 掌控度范围为 `0%-100%`。
- 掌控度公式：`基础分 + Σ(指标分 × 权重)`。
- 指标分规则为 `min(当前值/阈值, 1)`。
- 指标包含书籍、城市、人口、军力、建筑。
- 示例：世界档位 `6`，掌控度 `50%`，生效档位 `3`。

### 数值传承
- 数值传承包含军事传承与领域传承。
- 军事传承作用对象为王国成员。
- 领域传承只影响 MOD 技能。

### 军事传承
- 攻击加成公式：`档位 × 每档攻击加成`。
- 防御加成公式：`档位 × 每档防御加成`。
- 示例：每档 `2%`，档位 `3` 时为 `+6%`。

### 领域传承
- 范围加成公式：`档位 × 每档范围加成`。
- 次数加成规则：从起始档位起，每 N 档 +1。
- 次数上限由参数控制。
- 示例：每档范围 `3%`，档位 `7` 为 `+21%`。
- 示例：起始档位 `3`，每 `2` 档 +1。
- 上限 `2` 时，档位 `7` 为 `+2`。

### 发放链路
王国装备链路：
1. 装备条目注册进装备编辑器。
2. 解锁后进入原版装备池。
3. 锻造前按王国档位过滤候选池。
4. 原版锻造产生装备实例。
5. 装备进入城市仓库。
6. 单位按原版取装行为获取装备。

特质链路：
1. 结算推进世界档位。
2. 标记特质条目可获得状态。
3. 编辑器全局可见，未解锁标记锁定。
4. 王国成员按王国档位过滤。
5. 魔王势力按世界档位过滤。
6. 未达标直接跳过，不做重抽。
7. 互斥与概率按原版执行。
8. 记录日志并写入存档。

数值链路：
1. 结算推进世界档位。
2. 计算王国生效档位。
3. 按档位计算军事传承加成。
4. 写入王国成员数值缓存。
5. 按档位写入领域传承参数。
6. 记录日志并写入存档。

魔王直发链路：
1. 结算推进世界档位并作为魔王装备档位。
2. 计算可用档位与资格。
3. 按档位筛选装备 `asset_id`。
4. 读取 `demon_wargear_delivery` 并截断越界概率。
5. 生成或刷新时按角色概率发放。
6. 未发放则失败计数 `+1`。
7. 发放成功则失败计数清零。
8. 将领失败计数达阈值触发保底。
9. 写入槽位并按规则替换。
10. 记录状态与日志，按周期重试。

### 直发规则
- 候选筛选按档位与 `demon_wargear_delivery` 取 `asset_id`。
- 候选筛选按角色范围过滤：`demon_lord/general/legion`。
- 候选筛选按槽位类型过滤：`weapon/helmet/armor/boots/ring/amulet`。
- 发放仅在生成或刷新时触发。
- 刷新受“刷新间隔”限制。
- 单次最大发放量为 `1`。
- 有空槽位时直接装备。
- 无空槽位时仅替换更好装备。
- 评分一致则不替换。
- 仅“未发到装备”计失败。
- 装备更差被跳过时不计失败。
- 失败达阈值触发保底发放。
- 成功发放后失败次数清零。
- 失败次数、年份、档位与来源写入存档字段。
- 评分优先用原版品质值。
- 无法获取品质时用“档位+词条数量”。

### 默认行为
- 原版锻造与取装随机性保持不变。
- 魔王侧使用直发链路覆盖魔王、将领、军团。
- 直发按角色概率发放。
- 装备词条与品质沿用原版生成。
- 无空槽位时只替换更好装备。
- 替换优先级为：武器 → 护甲 → 头盔 → 靴子 → 戒指 → 护符。

### 状态字段
- `custom_data_int["era_war_fail_count"]`：将领连续失败次数。
- `custom_data_int["era_war_last_grant_year"]`：最近一次发放年份。
- `custom_data_int["era_war_last_grant_tier"]`：最近一次发放使用的档位。
- `custom_data_int["era_war_source"]`：魔王装备来源标记，`0=heritage_auto`。
- `era_war_fail_count` 仅用于将领保底。

### 参数表
| 参数组 | UI可调控参数 | 说明 |
|---|---|---|
| 档位推进 | 传承档位上限（`10`）；每轮回档位提升（`1`） | 档位上限和推进节奏。 |
| 新王国继承 | 新王国档位下限（`1`）；掌控度刷新间隔（`10年`） | 新王国继承规则。 |
| 掌控度基础分 | 数值（`0.20`） | 固定基础分。 |
| 掌控度书籍类 | 阈值：文化`5`、宗教`5`、语言`5`、首都`5`、全城`20`。<br>权重：`0.10/0.10/0.05/0.10/0.05`。 | 书籍评分。 |

| 领域传承 | 每档范围加成（默认 `3%`）；次数加成参数（起始档位、每 N 档 +1、上限） | 仅影响 MOD 技能。 |

### 边界与禁止
- 魔王链路只使用 `generateItem/generateModsFor/ActorEquipment.setItem`。
- 魔王链路必须读取 `demon_wargear_delivery` 并截断越界概率。
- 特质过滤仅在原版随机池授予时执行。
- 手动授予不做档位过滤。
- 禁止使用全局 `ItemAsset.unlock()` 替代资格判定。

## 王国英雄

### 定义
- 王国英雄系统包含抗魔等级、命定英雄、家族继承。
- 抗魔等级是王国维度长期成长。
- 命定英雄是轮回中的关键单位。
- 家族继承让英雄血脉影响后裔成长。

### 抗魔等级
- 王国通过击杀魔王阵营单位提升抗魔等级。
- 每累计 `1000` 次击杀提升 `0.5` 级。
- 封印战胜利可提供额外加成。
- 新建或复国王国从 `0` 级开始。

### 抗魔等级效果
| 等级 | 效果1 | 效果2 | 效果3 |
|---|---|---|---|
| Lv1 | 命中 `+5%` | 攻速 `+5%` | - |
| Lv2 | 伤害 `+5%` | 生命 `+5%` | - |
| Lv3 | 体力 `+10%` | 法力 `+10%` | - |
| Lv4 | 防御 `+8%` | 移速 `+5%` | - |
| Lv5 | 暴击率 `+5%` | 暴伤 `+15%` | - |
| Lv6 | 伤害 `+8%` | 防御 `+6%` | - |
| Lv7 | 射程 `+10%` | 投掷射程 `+10%` | - |
| Lv8 | 生命 `+10%` | 移速 `+5%` | - |
| Lv9 | 攻速 `+8%` | 暴击率 `+3%` | - |
| Lv10 | 战斗熟练 `+20%` | 法术熟练 `+20%` | 状态触发 `+10%` |

### 家族继承
- 仅王国新生单位在出生时判定继承。
- 出生入口为 `all_actions_actor_birth`。
- 继承只追溯英雄祖先。
- 英雄祖先存活与否不影响继承判定。
- 继承成功写入血脉标记。
- 血脉标记用于晋升评分加成。
- 血脉加成：带血脉标记的候选，综合分 × `1.05`。

### 血脉追溯规则
1. 出生后读取父母 `parent_id_1/parent_id_2`。
2. 在双亲血脉中选择最近英雄祖先。
3. 双亲都命中时按代数最近优先。
4. 超过可继承代数时终止继承。
5. 无英雄祖先时直接结束。

### 后裔继承规则
1. 命中英雄祖先后按概率判定继承。
2. 属性按“祖先晋升基础值 × 继承比例”写入。
3. 继承池只使用英雄随机池条目。
4. 仅从祖先已持有条目里抽取。
5. 每代继承次数受上限约束。
6. 池耗尽仍不足则保留已抽取结果。

### 状态存储
- 血脉根 ID 写入 `custom_data_long`。
- 血脉代数写入 `custom_data_int`。
- 状态随单位存档与读档恢复。

### 命定英雄
- 每王国有数量上限。
- 晋升触发分为繁荣触发与危机触发。
- 兜底检测按间隔执行，作为补触发。

### 触发规则
- 繁荣触发：人口≥阈值且城市≥阈值。
- 危机触发：统计窗口内人口跌幅≥阈值。

### 晋升流程
1. 先检查世界总英雄上限。
2. 再检查王国当前英雄上限。
3. 再检查王国晋升冷却是否结束。
4. 再判断繁荣或危机触发条件是否达成。
5. 以上满足后进入候选筛选与评分。

### 候选与评分
- 候选池为同王国、存活、非魔王阵营。
- 评分指标为等级、击杀、生命、攻击、指挥。
- 公式为 `综合分 = Σ(min(指标/阈值,1) × 权重)`。
- 带血脉标记的候选按血脉加成修正综合分。
- 从前 `N` 名中随机 `1` 名晋升。
- 现英雄单位不参与评分。

### 晋升强化
- 晋升时随机写入基础值。
- 晋升时抽取英雄随机特质与随机技能。
- 命定英雄固定 `P0「英勇」`。
- `英勇` 效果为基础属性 `+10%`。

### 随机池与补抽
- 技能池与特质池独立抽取。
- 抽中互斥条目即跳过，不计入数量。
- 持续抽取到数量满足或池内无可用条目。
- 池耗尽仍不足则保留已抽取结果。
- 随机池条目以 `ERRE附属文档/英雄专属随机池.md` 为准。

### 幸存强化
- 轮回结算时检查命定英雄存活状态。
- 存活到结算的命定英雄获得幸存强化。
- 幸存强化每轮只发放一次。
- 本轮中途死亡的英雄不获得本轮强化。
- 本轮新晋升且活到结算的英雄可获得强化。
- 强化按“当前基础值 × 幸存强化比例”增加属性。
- 达到强化上限后不再继续叠加。
- 幸存强化不参与随机范围平移统计。

### 参数表
| 参数组 | UI可调控参数 | 说明 |
|---|---|---|
| 抗魔等级成长 | 等级上限（`10`）；击杀阈值（`1000/0.5级`）；封印加成（`0.5级/次`） | 抗魔等级成长。 |
| 英雄与冷却 | 每王国英雄上限（`1`）；世界总英雄上限（`50`）；晋升冷却（`30年`）；兜底检测间隔（`5年`） | 数量与节奏。 |
| 晋升条件繁荣 | 人口阈值（`500`）；城市阈值（`2`） | 繁荣触发条件。 |
| 晋升条件危机 | 统计窗口（`10年`）；人口跌幅（`50%`） | 危机触发条件。 |
| 候选与评分 | 权重（等级`0.25`、击杀`0.25`、生命`0.15`、攻击`0.15`、指挥`0.20`）；阈值（`10/50/1000/100/100`）；取前 N（`3`） | 过滤与评分。 |
| 晋升奖励 | 随机特质数（`3`）；随机技能数（`6`） | 晋升强化。 |
| 幸存强化 | 幸存强化开关；每轮强化比例（`10%`）；强化上限（`200%`） | 仅对命定英雄生效。 |
| 家族继承 | 触发概率（`30%`）；继承属性比例（`30%`）；继承祖先专属特质条目数（`2`）；继承祖先专属技能条目数（`4`）；可继承代数（`10`）；每代继承次数上限（`1`）；血脉评分加成（`5%`） | 继承规则。 |

## 世界外交

### 定义
- 魔王存活期间可触发世界停战。
- 停战目的是形成共同讨伐窗口。
- 魔王被击败后恢复常规外交。

### 规则
- 触发条件可多选：降临阶段、城市摧毁阈值、世界人口阈值。
- 城市摧毁阈值=废墟城市数/总城市数。
- 满足任一条件即可进入停战状态。
- 停战期间终止王国间战争并统一对抗魔王阵营。
- 复查间隔到达后重新判定是否维持停战。
- 复查未满足条件时退出停战。
- 魔王死亡时立即退出停战。

### 参数表
| 参数组 | UI可调控参数 | 说明 |
|---|---|---|
| 停战复查 | 停战复查间隔（`3年`） | 停战维持周期。 |
| 触发条件与阈值 | 触发条件（多选）；降临阶段；城市摧毁阈值（`30%`）；世界人口阈值（`5000`） | 任一满足即触发。 |

## 叙事事件

### 定义
- 叙事事件只记录真实发生内容。
- 不新增人物、地点、时间。
- 不改变先后顺序和因果关系。

### 数据来源
- 世界历史日志。
- 战争系统与阴谋系统。
- MOD 自定义事件。

### 事件结构
```
id: 全局唯一
year: 年份
source: world_log / plot / war / mod
type: city_new / war_started / demon_awake ...
entities: kingdom_id / city_id / unit_id / plot_id / war_id
location: x,y
raw_text: 原文或短句摘要
importance: 重要度
```

### 生成流程
1. 增量采集并记录 `last_year`。
2. 标准化为统一事件结构。
3. 事件年份大于单位 `death_year` 时丢弃。
4. 按年份排序并分章。
5. 生成叙事文本并写入日志。
6. 输出文本附 `event_ids` 映射。

### LLM 约束
- 输入只使用结构化事件与规则。
- 输出每段必须附 `event_ids`。
- 无法追溯来源的句子直接丢弃。

# 数值成长

## 通用成长
- 公式：`属性 = 基础值 × (1 + 成长倍率 × 轮回数)`。
- 基础值只在单位生成或晋升时随机写入一次。
- 轮回成长在轮回结算后生效。
- 魔王、将领、军团分别使用各自成长倍率与上限。

## 属性随机
- 属性随机只作用于 MOD 自定义单位。
- 随机值写入基础字段，不写入百分比元字段。
- 属性随机与轮回成长可叠加。

## 触发时机
- 魔王和将领在生成时随机一次。
- 军团每波次随机一次并共享该波结果。
- 命定英雄在晋升时随机一次。
- 触发只负责抽样写入，不更新随机范围。

## 轮回内口径
- 同一轮回内，随机范围固定不变。
- 同类单位在本轮使用同一随机范围。
- 本轮新增单位不会触发范围平移。

## 叠加顺序
- 随机值 → 轮回成长 → 波次强度（仅军团） → 特质/传承。

## 首轮随机范围
| 单位类型 | 生命 | 寿命 | 防御 | 伤害 | 法力上限 | 体力 | 暴击率 | 移速 | 攻速 | 时机 |
|---|---|---|---|---|---|---|---|---|---|---|
| 魔王 | `800000-1000000` | `99999-99999` | `600-1200` | `1800-3200` | `1000-2000` | `1500-3000` | `20%-30%` | `30-40` | `1.8-2.6` | 生成时 |
| 将领 | `300000-600000` | `99999-99999` | `400-700` | `700-1100` | `800-1200` | `1000-1500` | `14%-22%` | `15-25` | `1.4-1.7` | 生成时 |
| 英雄 | `300000-400000` | `300-500` | `400-600` | `700-1100` | `700-1300` | `1000-1500` | `10%-25%` | `20-33` | `1.2-1.7` | 晋升时 |
| 军团 | `5000-10000` | `99999-99999` | `50-100` | `20-80` | `100-300` | `100-500` | `2%-7%` | `14-20` | `1.0-1.5` | 出波时 |

## 首轮新增随机属性
- 本轮不新增：命中、普攻距离、投掷距离。
- 下列属性加入首轮随机，并沿用同一触发时机。

| 单位类型 | 暴击伤害倍率 | 状态触发率 | 击退强度 | 战斗熟练 | 施法熟练 | 体形大小 |
|---|---|---|---|---|---|---|
| 魔王 | `3.0-4.5` | `45%-50%` | `3.0-4.5` | `45%-70%` | `45%-75%` | `0.28-0.40` |
| 将领 | `2.6-3.1` | `25%-35%` | `2.6-3.1` | `30%-44%` | `28%-44%` | `0.20-0.30` |
| 英雄 | `2.5-3.0` | `25%-35%` | `2.5-3.0` | `33%-55%` | `25%-40%` | `0.10-0.20` |
| 军团 | `2.0-2.5` | `5%-14%` | `2.0-2.5` | `5%-17%` | `0%-15%` | `0.08-0.15` |

## 展示口径
- 百分比字段统一用 `%` 展示。

## 范围平移
- 范围平移只在轮回结算时执行一次。
- 范围平移用本轮生成单位均值更新下轮下限。
- 上限按“下限 + 初始宽度”重算。
- 本轮未生成则不更新范围。
- 玩家手动改动随机范围后清零平移偏移。

# 配置与界面

## 界面目标
- 一眼看到轮回、阶段和封印进度。
- 先给结论，再给原因。
- 仅关键事件弹窗，降低噪音。

## 界面结构
- HUD 轻量条常驻显示关键状态。
- 主面板结构为左导航 + 中内容 + 右详情。
- 全局搜索支持快速定位，快捷键为 `Ctrl/Cmd+K`。

## 导航栏目
- 总览：轮回、阶段、王国概况。
- 战局：魔王、将领、军团、英雄列表。
- 魔王图鉴：魔王主题和技能摘要。
- 技能库：技能筛选和开关。
- 封印与传承：封印进度与传承清单。
- 事件与日志：时间线和回放。
- 玩法百科：新手指引和核心规则。
- 设置：参数、预设、导入导出。
- 调试：仅开发模式显示。

## 页面规则
- 总览页展示轮回数、阶段、封印进度、魔王态势、传承档位。
- 战局页按“魔王 → 将领 → 军团”展开。
- 遗迹在全阶段显示状态，仅封印战显示有效进度条。
- 技能库仅展示已启用且已注册的技能，军团单位不入库。
- 封印与传承页上半区显示遗迹与封印，下半区显示传承。

- 玩家模式只显示安全常用参数。
- 高级模式显示全部参数。
- 开发模式显示调试项并二次确认。

## 收藏与展示
- 收藏开关为 `can_be_favorited`。
- 魔王、将领、命定英雄在生成或晋升时自动收藏。

## 导入导出闭环
1. 导出时将当前参数写入 JSON。
2. 导入时先解析并检查 `config_version`。
3. 版本不一致时先执行迁移再校验结果。
4. 展示差异预览，用户确认后继续。
5. 应用前自动创建备份文件。
6. 应用失败时回滚备份并提示失败原因。
7. 应用成功后写入新配置并记录更新时间。
8. 导出文件不包含敏感字段。

## 配置容错
- 可调项必须进入 UI 与配置文件。
- JSON 必须包含 `config_version`。
- 未知字段忽略，缺失字段补默认值。
- 非法值自动修正并给出提示。
- 时间类参数小于 `0` 按 `0` 处理。
- 数量类参数小于 `0` 按 `0` 处理。
- 间隔类参数 `<=0` 修正为最小正值。
- 概率超范围按 `0%-100%` 截断。
- `NaN/Infinity` 回退到安全值。
- 区间 `min>max` 自动互换。
- 倍率 `<=0` 修正为最小正值。

## 视觉规范
- 风格以信息清晰为先。
- 色彩为青蓝主色、绿色强调、红色警报。
- 字体为标题黑体、正文无衬线。
- 版式为网格对齐，一屏不超过三层信息。

## 资产注册
- 单位使用 `ActorAsset` 注册和生成。
- 建筑使用 `BuildingAsset` 注册和放置。
- 特性使用 `ActorTrait/KingdomTrait` 注册。
- 生成点需可行走并避开拥挤地块。

## 生成与模板
- 独立模板指使用不同 `ActorAsset` 模板 ID 生成。
- 魔王、将领、军团使用不同 `ActorAsset` 模板 ID 生成。
- 生成入口统一使用 `ActorManager.spawnNewUnit(ActorAssetID, ...)`。
- 推荐基于原生模板复制再改，字段更完整。
- 差异很大时再新建模板并补齐字段。
- 模板必须注册到 `AssetManager.actor_library` 才能生成。
- 不新增 MOD 生成判定或平衡规则。

## 触发入口
- 命中入口用 `action_attack_target`。
- 受击入口用 `action_get_hit`。
- 死亡点入口用 `action_on_object_remove`。
- 优先使用 `ActionLibrary`。
- 无现成动作再用自定义 `trait`。

## 字段与对象
- Actor 状态只写 `custom_data_*`。
- 装备归属与词条写入 Item 字段。
- City/Building 不写 Actor 字段。

## 术语映射
| 术语 | 实现口径 |
|---|---|
| 伤害/生命/防御/移速/攻速/命中/暴击 | 对应 `BaseStatsLibrary` 字段。百分比写 `base_stats_meta`。 |
| AOE系数 | `area_of_effect`（`base_stats_meta`） |
| 状态触发概率 | `status_chance`（`base_stats_meta`） |
| 回血/回蓝 | `Actor.restoreHealthPercent` / `Actor.restoreManaPercent` |
| 当前生命伤害/固定伤害 | `changeHealth(-dmg)` |
| 削蓝 | `Actor.setMana` 或 `restoreManaPercent` 负值 |
| 落雷/火焰 | `ActionLibrary.castLightning` / `ActionLibrary.castFire` |
| 眩晕/中毒/减速/护盾 | `ActionLibrary.addStunnedEffectOnTarget` 等 |
| 传送 | `ActionLibrary.singularityTeleportation` / `teleportRandom` |
| 召唤 | `ActorManager.spawnNewUnit` |
| 易伤/破甲/增益 | 给目标或友军加 trait 并写到期年 |
| 吸血 | 命中后按造成伤害比例回血 |
| 叠层/到期/限频 | 写入 `custom_data_int` 与到期年 |
| 回填 | 在受击钩子里按比例回填伤害 |
| 净化 | 先移除 MOD 负面，再移除普通负面 |

## 数值口径
- 百分比按 `0%-100%` 展示和配置。
- 当前生命百分比伤害按当前生命计算。
- 默认保留 `1HP`。
- 处决或击杀类技能例外。
- 伤害倍率以 `damage` 为基准字段。
- 当前生命字段为 `health_current`。
- 最大生命字段为 `health_max`。
- 绝对值写 `base_stats`。
- 百分比写 `base_stats_meta`。
- 暴击率最终按 `0%-100%` 归一。

## 状态存储
- 状态写入只使用 `custom_data_int/long/float`。
- 计数与到期写 `custom_data_int`。
- 标识类写 `custom_data_long`。
- 比例类写 `custom_data_float`。

## 特质清理
- 不新增获得入口，不改随机池。
- 是否获得由原版随机池与资产字段决定。
- 随机入口池沿用原版：`pot_traits_birth`、`pot_traits_growup`、`pot_traits_combat`、`pot_traits_mutation_box`。
- 资产字段沿用原版：`rate_birth`、`rate_inherit`。
- 资产字段沿用原版：`rate_acquire_grow_up`、`is_mutation_box_allowed`。
- 原版随机只作用 Actor，建筑与城市不参与。

### 多 MOD 清理
- 该清理仅用于魔王侧兼容，不改变公共特质获取逻辑。
- 清理对象为魔王、将领、军团。
- 触发时机为生成时与刷新时。
- 白名单来源为原版特质 + 公共特质表条目 + 特质传承条目。
- 清理方式为移除非白名单特质。
- 王国成员与英雄不参与清理。
- 清理只在触发点执行，不做高频巡检。

## 性能策略
- 军团 AI 使用低频更新。
- 王国统计按间隔更新。
- 轮回推进使用低频定时器。
- 轮回历史按轮数清理。
- 禁止全图扫描或高频巡检。

## 装备传承测试
1. 装备编辑器全局可见装备传承条目，且不影响公共特质编辑器。
2. 世界档位 `6` 且掌控度 `50%` 时，仅生效到 `3` 档池并入城库。
3. 不同王国掌控度不同，装备池隔离生效。
4. 入城库后成员按原版逻辑取装完成流转。
5. 无城市前提下，魔王、将领、军团可获得装备传承直发装备。
6. 旧存档升级后不出现误走链路或全局误解锁。

## 特质传承测试
1. 特质编辑器全局可见全部特质条目，未解锁显示锁定。
2. 世界档位提升后，条目标记为可获得状态。
3. 原版随机池授予时按世界或王国档位过滤。
4. 未达标直接跳过，不做重抽。
5. 原版特质获得不受档位过滤。
6. 编辑器手动授予不做档位过滤。
7. 魔王势力单位获得入口只走原版随机池。
8. 旧存档迁移后解锁与档位规则保持一致。

## 数值传承测试
1. 世界档位 `5`、掌控度 `60%` 时生效档位为 `3`。
2. 军事传承档位 `3` 时攻击/防御加成为 `+6%`。
3. 新单位生成时继承当前生效档位增益。
4. 领域传承档位 `7` 时技能范围 `+21%`，次数 `+2`。
5. 领域传承仅作用 MOD 技能，不影响原版技能。

## 首轮随机范围测试
1. 静态校验所有随机属性区间，满足 `min<=max`。
2. 每类单位采样 `10000` 次，不超出配置区间。
3. UI 展示中，百分比字段统一显示 `%`。
4. 旧存档读入后，新增随机属性缺失时自动补默认值。
5. 同一轮回内多次晋升或出波后，随机范围保持不变。
6. 范围平移仅在轮回结算执行，且下一轮才生效。

## 命定英雄幸存强化测试
1. 上轮存活命定英雄在轮回结算时获得强化。
2. 本轮多次晋升不会提前触发幸存强化。
3. 本轮死亡的命定英雄不获得本轮强化。
4. 强化达到上限后继续结算不再增长。
5. 幸存强化不参与随机范围平移统计。

## 魔王装备直发测试
1. 魔王生成时必得装备（`rate_demon_lord=1.0`）。
2. 将领连续失败达到 `3` 次后触发保底发放。
3. 无空槽位且新装备更好时执行替换。
4. 新装备更差时不替换，且不计失败。
5. 新装备更好时替换成功，失败次数清零。
6. 读档后失败次数与发放年份恢复正确。
7. 戒指/护符可按槽位直发并遵守替换规则。
8. 原版装备链路行为不受影响。

## 多 MOD 特质测试
1. 外部特质注入后，魔王侧会清理非白名单特质。
2. 白名单仅包含原版特质、公共特质表条目、特质传承条目。
3. 王国成员与英雄仍按原版逻辑获取外部特质。
4. 周期刷新与读档恢复后可清理旧污染。

6. 刷新只巡检魔王势力单位，运行无明显卡顿。
