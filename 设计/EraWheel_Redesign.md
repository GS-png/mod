## 统一口径

**时间与触发**
- 时间单位统一为游戏年份。
- 轮回推进使用低频定时器，不做高频全图扫描。
- 技能触发只允许命中/受击/死亡点。
- 到期、限频与范围只在触发点处理。

**事件钩子与状态存储**
- 命中钩子：`action_attack_target`。
- 受击钩子：`action_get_hit`。
- 死亡点钩子：`action_on_object_remove`。
- 优先使用 `ActionLibrary`，无现成动作再用自定义 `trait`。
- 状态写入：`custom_data_int/long/float`。

**字段与对象**
- Actor 状态只写 `custom_data_*`。
- 装备归属与词条写入 Item 字段。
- City/Building 不写 Actor 字段。

**数值口径**
- 百分比按 `0%-100%` 展示和配置。
- 伤害默认按当前生命计算，最低扣到 `1HP`。
- 伤害倍率以 `damage` 为基准字段。
- 当前生命字段：`health_current`，最大生命字段：`health_max`。
- 绝对值写 `base_stats`，百分比写 `base_stats_meta`。
- 暴击率最终按 `0%-100%` 归一。

**配置容错**
- 可调项必须进入 UI 与配置文件。
- JSON 必须包含 `config_version`。
- 未知字段忽略，缺失字段补默认值。
- 非法值自动修正并给出提示。
- 负时间和负数量按 `0` 处理。
- 间隔 `<=0` 修正为最小正值。
- 概率超范围按 `0%-100%` 截断。
- `NaN/Infinity` 回退到安全值。
- 区间 `min>max` 自动互换。
- 倍率 `<=0` 修正为最小正值。

**技能资源与频率**
- 本规则仅对 MOD 自定义技能生效。
- 主动技能资源统一使用法力。
- 主动技能触发频率按年限频。
- 默认值如下，可在 UI 中调整。

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 法力消耗 | 主动技能消耗（普通 `5`）；主动技能消耗（终极 `10`） | 技能释放法力消耗默认值 |
| 触发频率 | 主动技能触发上限（`2次/年`）；终极技最小间隔（`2年`） | 年度限频默认值 |

**生成与挂载**
- 魔王槽位固定为 `P0+S1-S6`。
- 将领槽位固定为 `P0+S1+S2`。
- 魔王、将领、军团均使用独立模板生成。

**收藏规则**
- 收藏开关：`can_be_favorited`。
- 自动收藏：魔王/将领/命定英雄在生成或晋升时触发。

## 玩法闭环

**定义**
- 轮回起点：上一轮封印战胜利后进入预发展。
- 轮回终点：下一次封印战胜利结算完成。
- 封印战胜利支持击杀胜利或仪式胜利。

**阶段流程**
1. 预发展
2. 预兆
3. 苏醒
4. 降临
5. 封印战（衰弱）
6. 战后重建

**系统关系**

| 系统 | 主要作用 | 关键输入 | 关键输出 |
|---|---|---|---|
| 轮回系统 | 驱动阶段推进与结算 | 世界人口、世界城市数、封印值、轮回数 | 当前阶段、结算结果 |
| 魔王系统 | 决定魔王行为与强度 | 阶段、HP、魔王类型 | 技能激活、行为策略 |
| 将领系统 | 管理精英单位层 | 魔王类型、轮回数 | 将领生成、将领技能 |
| 军团系统 | 管理波次压制节奏 | 阶段、波次配置、军团库 | 军团数量、军团强度 |
| 封印遗迹 | 提供仪式封印路径 | 阶段、遗迹状态、争夺结果 | 封印进度、仪式胜利 |
| 遗产系统 | 记录跨轮回长期增益 | 轮回结算数据 | 王国、英雄、魔王增益 |
| 王国英雄 | 承担对抗与反哺 | 王国运行态、战果 | 抗魔等级、命定英雄 |
| 世界外交 | 组织共同讨伐窗口 | 魔王存活态、触发条件 | 停战状态、联合作战 |

## 轮回系统

**定义**
- 轮回系统负责阶段推进、双封印管理和结算发放。
- 阶段状态是轮回主状态，不与战斗子状态混用。
- 轮回计数在战后重建完成后 `+1`。

**阶段规则**
1. 预发展
   - 触发：新档开始或战后重建结束。
   - 过程：按“预发展检查间隔”检测世界现存人口与城市数。
   - 表现：将领封印和魔王封印均为初始强度。
   - 结束：人口或城市任一达到阈值，进入预兆。
2. 预兆
   - 触发：世界现存人口或城市数达到阈值。
   - 过程：确定本轮魔王名单并生成据点；启动军团波次。
   - 表现：将领封印开始衰减，遗迹进入显形状态。
   - 结束：将领封印降为 `0%`，进入苏醒。
3. 苏醒
   - 触发：将领封印为 `0%`。
   - 过程：激活将领系统并生成将领；魔王封印开始衰减。
   - 表现：遗迹进入争夺状态，可交战不推进仪式。
   - 结束：魔王封印降为 `0%`，进入降临。
4. 降临
   - 触发：魔王封印为 `0%`。
   - 过程：魔王实体生成并主动进攻，军团波次加速。
   - 表现：遗迹保持争夺状态，不推进仪式。
   - 结束：魔王 HP 低于衰弱阈值，进入封印战。
5. 封印战（衰弱）
   - 触发：魔王 HP 低于衰弱阈值。
   - 过程：军团生成降速；遗迹切换激活并允许仪式推进。
   - 表现：魔王优先撤退与恢复，部分将领可能撤退或失控。
   - 结束：封印战胜利进入战后重建。
   - 回退：HP 回升到回退阈值则回到降临。
   - 默认规则：回退后重算战斗子状态，可能直接回全盛。
6. 战后重建
   - 触发：封印战胜利结算完成。
   - 过程：发放遗产、重置魔王位置与强度、写入轮回历史。
   - 结果：返回预发展，准备下一轮。

**封印战胜利判定**
- 击杀胜利：直接击杀魔王，立即触发胜利结算。
- 仪式胜利：激活遗迹达到占领数阈值且仪式进度满。
- 双通道胜利：任意一条路径达成即判定胜利。

**存档规则**
- 轮回状态、计数、关键进度写入 MOD 存档。
- 读档后自动恢复阶段、封印值和计时器。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 预兆触发 | 世界现存人口阈值（`5000`）；世界现存城市阈值（`20`）；预发展检查间隔（`10年`） | 人口或城市任一达标进入预兆 |
| 据点与节点 | 据点默认半径（`20格`） | 据点范围半径 |
| 将领封印 | 将领封印初始强度（`100%`）；将领封印衰减速率（`1%/年`） | 预兆阶段开始衰减 |
| 魔王封印 | 魔王封印初始强度（`100%`）；魔王封印衰减速率（`1%/年`） | 苏醒阶段开始衰减 |
| 封印胜利 | 封印胜利模式（击杀/仪式/双通道） | 胜利方式选择 |

## 魔王系统

**定义**
- 魔王系统负责魔王实体、技能行为和强度状态切换。
- 多魔王时由互动模式管理阵营关系。

**状态模型**
- 阶段状态沿用轮回六阶段。
- 战斗子状态仅在实体存在时生效。
- 子状态只做数值修正，不驱动阶段。
- 阶段切换由轮回系统判定。

**阶段行为表**

| 阶段 | 技能激活 | 军团生成 | 将领数量 | 魔王实体 | 说明 |
|---|---|---|---|---|---|
| 预发展 | 否 | 否 | `0` | 否 | 等待人口/城市阈值触发 |
| 预兆 | 否 | 是 | `0` | 否 | 军团出波，将领封印衰减 |
| 苏醒 | 将领技能 | 是 | 固定 `5` | 否 | 将领生成，魔王封印衰减 |
| 降临 | 全部可用 | 是 | 存活数 | 是（全盛/常态） | 魔王入侵 |
| 封印战 | 全部可用 | 是（降速） | 存活数 | 是（衰弱） | 封印战争夺 |
| 战后重建 | 否 | 否 | `0` | 否 | 结算与重置 |

**战斗子状态规则**
- 全盛：HP 高于全盛阈值，法力恢复 `+50%`，波次速度 `×2`。
- 常态：HP 位于全盛阈值与衰弱阈值之间。
- 衰弱：HP 低于衰弱阈值。
- 子状态只依据 HP 阈值切换。

**多魔王互动**
- 触发：本轮苏醒数 `>=2` 或当前存活数 `>=2`。
- 模式：联盟、内战、随机。
- 联盟模式：共享敌对关系并强制停火，单体强度小幅下调。
- 内战模式：魔王互相宣战，同时继续攻击王国。
- 内战胜者获得称号和限时属性加成。
- 保护规则：魔王数量 `<2` 时，互动机制不生效。

**阵营外交规则**
- 魔王阵营单位生成即敌对所有非魔王阵营单位。
- 魔王阵营主动攻击非魔王阵营单位。
- 王国与魔王阵营保持战争。
- 魔王阵营不建城，不参与王国外交。

**魔王势力生成闭环**

**定义**
- 魔王势力单位指魔王/将领/军团三类。
- 三类单位使用独立模板生成。
- 生成后按原版入口参与四个随机特质池。

**流程要点**
1. 预兆期生成据点并出军团首波。
2. 苏醒期生成将领，每魔王固定 5 名。
3. 降临期生成魔王实体并开始进攻。
4. 军团按生成间隔持续出波。
5. 生成点优先据点，缺失则靠近魔王。
6. 生成点必须可行走并避开水域。
7. 战后重建移除据点并清理本轮生成残留。

**注意事项**
- 随机池为 `pot_traits_birth/growup/combat/mutation_box`。
- 原版互斥与 `traits_ignore` 仍生效。
- 不新增 MOD 生成判定或平衡规则。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 魔王池与苏醒 | 魔王启用默认（多选）；魔王苏醒模式（指定/随机）；苏醒数量（`1`） | 控制本轮魔王构成 |
| 战斗态阈值 | 全盛 HP 阈值（`70%`）；衰弱 HP 阈值（`30%`）；封印战回退阈值（`70%`）；全盛法力恢复倍率（`50%`） | 全盛、衰弱与回退控制 |
| 轮回成长 | 轮回成长倍率（`25%/轮回`）；成长硬上限（`250%`） | 魔王成长参数 |
| 多魔王模式 | 互动模式（联盟/内战/随机）；关系校验间隔（`3年`）；联盟强度系数（`85%`）；内战强度系数（`100%`） | 关系维护和强度修正 |
| 内战主导权 | 内战最大魔王数（`5`）；加成时长（`10年`）；加成属性比例（`10%`） | 胜者限时加成 |

## 将领系统

**定义**
- 将领是魔王阵营精英单位，用于指挥和关键战斗。
- 每个魔王固定 `5` 名将领。

**规则**
- 将领只在苏醒阶段生成一次。
- 将领死亡后不补充。
- 生成点优先魔王据点或魔王附近。
- 将领技能槽位固定为 `P0+S1+S2`。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 轮回成长 | 轮回成长倍率（`20%/轮回`）；成长硬上限（`250%`） | 将领成长参数 |

## 军团系统

**定义**
- 军团是魔王阵营波次单位，用于持续施压。
- 军团总量受“同时上限”约束。

**波次规则**
- 预兆阶段生成第一波。
- 后续按“军团生成间隔”持续出波。
- 波次强度：`基础强度 × (1 + 递增 × 波次)`。
- 波次数量：按“数量递增”随波次提高。
- 强度和数量都在出波时计算。

**上限处理（默认规则）**
- 本波数量=`min(计划数量, 同时上限-当前存活)`。
- 结果 `<=0` 时跳过本波并记录日志。

**生成规则**
- 军团使用独立模板生成。
- 魔王据点不存在时在魔王附近生成。
- 生成点必须可行走并避开水域。

**成长规则**
- 军团成长使用通用成长公式。
- 军团最终叠加顺序：随机值 → 轮回成长 → 波次强度。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 波次节奏 | 军团生成间隔（`10年`）；军团初始数量（`40`）；军团强度递增（`15%/波`）；军团同时上限（`300`） | 出波节奏与总量控制 |
| 阶段波次 | 军团全盛生成间隔（`5年`）；封印战生成间隔（`15年`） | 降临与封印战节奏 |
| 波次数量 | 波次数量递增（`15%/波`） | 每波单位数增长 |
| 轮回成长 | 轮回成长倍率（`15%/轮回`）；成长硬上限（`250%`） | 军团成长参数 |

## 据点节点

**定义**
- 魔气节点：预兆期为每个魔王生成 1 个节点，生成后立即升级为据点。
- 魔王据点：预兆期生成，用于生成、集结与据点范围判定中心。
- 据点范围：以据点中心计算半径距离，默认半径可配置。

**生成规则**
1. 进入预兆期后，为每个魔王生成 1 个魔气节点并直接升级为据点。
2. 选点只要求可行走且避深水。
3. 若无可行走地块，则使用世界中心附近可行走 tile 兜底。

**生命周期**
- 据点存在阶段：预兆、苏醒、降临、封印战。
- 据点生成后固定，不做刷新。
- 据点被摧毁：不重建。
- 战后重建：移除据点。

**多魔王规则**
- 每个魔王绑定 1 个据点。
- 生成与技能提到“据点”时，默认指该魔王的据点。

**存档字段（写入 MOD 存档）**
```
outposts: [{ demon_id, x, y, radius }]
```

## 封印遗迹

**定义**
- 封印遗迹是轮回内可见、可争夺、可用于仪式的建筑。
- 遗迹状态固定为显形、争夺、激活三态。
- 仪式胜利通过激活遗迹推进封印进度达成。

**状态与生命周期**
- 预兆阶段：生成或显形遗迹，状态为显形。
- 苏醒和降临：状态为争夺，可交战不推进仪式。
- 封印战：状态切换为激活，允许占领和进度推进。
- 战后重建：统一移除本轮遗迹。
- 生成点需避开深水和拥挤区域。

**仪式规则**
- 仅激活状态可以触发占领和进度推进。
- 非激活状态进度锁定，不增长。
- 触发占领需要范围清场且人数达阈值。
- 占领后进度持续推进，不要求持续驻守。
- 敌方人数达到阈值时按配置中断、回退或清零。
- 达到占领数阈值且总进度满时判定仪式胜利。

**争夺调度闭环**
1. 进入预兆后启动调度计时器。
2. 达到调度间隔后选取目标遗迹。
3. 默认规则：派遣最近 `N=2` 个王国小队，可配置。
4. 同时派遣魔王阵营小队。
5. 进入遗迹范围后执行占领判定和收益判定。
6. 未达打断阈值时继续推进进度。
7. 达打断阈值后按暂停/回退/清零处理。
8. 发生封印战胜利或进入战后重建时停止调度并清理队列。

**占领收益**
- 同阵营收益不叠加。
- 占领后友军获得范围增益。
- 收益半径和增益强度可配置。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 遗迹数量与阈值 | 封印遗迹数量（`10`）；占领遗迹数量阈值（`8`） | 遗迹总数和达标要求 |
| 仪式占领与进度 | 仪式占领人数阈值（`10`）；仪式进度速度（`3%/年`） | 占领条件和推进速度 |
| 仪式打断与回退 | 仪式中断敌方人数阈值（`15`）；中断处理（暂停/回退/清零）；回退速度（`3%/年`） | 打断规则 |
| 热点调度 | 热点开关；调度间隔（`5年`）；目标策略（敌占领/未占领/最近/随机） | 争夺调度规则 |
| 派遣规模 | 派遣王国数量（`2`）；派遣王国人数（`40`）；派遣魔王人数（`40`） | 每次派遣规模 |
| 占领收益 | 收益半径（`12`）；友军增益（`10%`）；叠加上限（`1`） | 遗迹收益配置 |

## 数值成长

**通用成长公式**
- 公式：`属性 = 基础值 × (1 + 成长倍率 × 轮回数)`。
- 基础值只在单位生成或晋升时随机写入一次。
- 轮回成长在轮回结算后生效。
- 魔王、将领、军团分别使用各自成长倍率和上限。

**属性随机**
- 属性随机只作用于 MOD 自定义单位。
- 随机值写入基础字段，不写入百分比元字段。
- 属性随机与轮回成长可叠加。

**触发时机**
- 魔王和将领：生成时随机一次。
- 军团：每波次随机一次并共享该波结果。
- 命定英雄：晋升时随机一次。

**叠加顺序**
- 随机值 → 轮回成长 → 特质/遗产。

**随机范围（首轮）**

| 单位类型 | 生命 | 寿命 | 防御 | 伤害 | 法力上限 | 体力 | 暴击率 | 移速 | 攻速 | 时机 |
|---|---|---|---|---|---|---|---|---|---|---|
| 魔王 | `150000-200000` | `99999-99999` | `400-1000` | `800-2000` | `100-300` | `200-500` | `8%-25%` | `8-12` | `0.8-1.2` | 生成时 |
| 将领 | `100000-150000` | `99999-99999` | `80-250` | `200-500` | `100-200` | `120-300` | `6%-18%` | `10-15` | `0.9-1.3` | 生成时 |
| 军团 | `1000-10000` | `99999-99999` | `10-80` | `20-120` | `50-100` | `80-180` | `2%-10%` | `9-13` | `0.9-1.3` | 出波时 |
| 英雄 | `80000-120000` | `200-500` | `50-200` | `120-350` | `100-250` | `150-350` | `6%-18%` | `10-14` | `0.9-1.3` | 晋升时 |

**随机范围平移**
- 范围平移：用本轮生成单位的均值更新下轮下限。
- 上限保持初始宽度不变。
- 本轮未生成则不更新范围。
- 玩家手动改动随机范围后清零平移偏移。

## 遗产系统

**定义**
- 轮回结算发放遗产。
- 遗产生效跨轮回继承。
- 遗产分为解锁类与数值类。
- 工艺遗产装备仅扩展装备编辑器条目。
- 研究遗产仅扩展特质编辑器条目。
- 清单维护在 `ERRE附属文档/遗产档位详表.md`。

**清单口径**
- 主表只写效果与叠加。
- 技术附表只写实现字段。
- 固定维护工艺、研究、军备。

**类型与对象**

| 遗产类型 | 作用对象 | 说明 |
|---|---|---|
| 工艺遗产 | 王国成员 | 扩展装备编辑器条目 |
| 研究遗产 | 王国成员 | 解锁研究条目 |
| 军事遗产 | 王国成员 | 攻防按档位叠加 |
| 军备遗产 | 魔王势力 | 解锁军备池 |
| 领域遗产 | 魔王/将领 | 技能范围与次数提升 |

**作用层规则**
- 王国层只做档位与掌控度判定。
- 编辑器可见不等于已授予。
- 工艺装备入城库，成员按原版取装。
- 研究条目按世界档位解锁进入编辑器。
- 研究条目列表全局可见。
- 解锁后默认进入原版随机池。
- 随机授予前按王国生效档位过滤。
- 手动添加不受王国档位限制。
- 魔王势力不建城，军备走直发。
- 英雄属于王国成员。

**档位规则**
- 世界档位随轮回结算推进。
- 解锁类遗产只扩展清单，不直接叠数值。
- 数值类遗产按档位叠加。
- 档位上限可配置。

**王国掌控度规则**
- 存活王国直接使用世界档位。
- 新建王国按掌控度折算生效档位。
- 生效档位公式：`floor(世界档位 × 掌控度)`。
- 掌控度范围是 `0%-100%`。
- 新王国最低档位可配置。

**掌控度计算**
- 公式：`掌控度 = 基础分 + Σ(指标分 × 权重)`。
- 默认规则：指标分=`min(当前值/阈值, 1)`。
- 指标：书籍、城市、人口、军力、建筑。
- 权重和阈值见参数表。

**发放规则**

**王国装备链路（`city_storage_then_pickup`）**
1. 结算推进世界档位。
2. 计算王国生效档位。
3. 按王国生效档位筛选工艺 `asset_id`。
4. 工艺装备入城库，成员取装走原版逻辑。
5. 记录日志并写入存档。

**研究解锁链路（`heritage_unlock`）**
1. 结算推进世界档位。
2. 计算王国生效档位。
3. 按世界档位解锁研究 `trait_id` 进入编辑器。
4. 解锁后进入原版随机池：`pot_traits_birth`、`pot_traits_growup`。
5. 原版随机池包含 `pot_traits_combat`、`pot_traits_mutation_box`。
6. 研究特质资产必须配置 `rate_birth`、`rate_inherit`。
7. 研究特质资产必须配置 `rate_acquire_grow_up`、`is_mutation_box_allowed`。
8. 随机授予前按王国生效档位过滤。
9. 仅当 `unlock_tier <= 王国生效档位` 才可授予。
10. 不满足则跳过并重新抽取。
11. 手动添加不受王国档位限制。
12. 记录日志并写入存档。

**魔王链路（`direct_equip_on_spawn_or_refresh`）**
1. 结算推进军备档位。
2. 计算可用档位与资格。
3. 按档位筛选军备 `asset_id`。
4. 读取 `demon_wargear_delivery` 并截断。
5. 生成或刷新时按角色概率发放。
6. 默认规则：未发放则失败计数 `+1`，成功则清零。
7. 将领失败计数达阈值触发保底。
8. 写入槽位；无槽位按优先级替换。
9. 记录状态与日志；按周期重试。

**概率口径**
- 王国装备链路随机性来自原版机制。
- 魔王链路按角色概率发放。
- 装备词条与品质沿用原版生成。

**默认选择**
- 王国装备先进城库，再由成员取装。
- 魔王侧固定直发，覆盖魔王/将领/军团。
- 无槽位按“武器 > 护甲 > 饰品”替换。
- 军备默认概率 `1.0/0.7/0.35`，保底阈值 `3`。
- 重试周期 `2` 年，单次最大发放 `1` 件。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 档位推进 | 遗产档位上限（`10`）；每轮回档位提升（`1`） | 档位上限和推进节奏 |
| 新王国继承 | 新王国档位下限（`1`）；掌控度刷新间隔（`10年`） | 新王国继承规则 |
| 掌控度基础分 | 数值（`0.20`） | 固定基础分 |
| 掌控度书籍类 | 阈值：文化`5`、宗教`5`、语言`5`、首都`5`、全城`20`；权重：`0.10/0.10/0.05/0.10/0.05` | 书籍评分 |
| 掌控度规模类 | 阈值：城市`5`、人口`688`、军力`200`、建筑`6`；权重：`0.15/0.10/0.10/0.05` | 规模评分 |
| 魔王军备发放（`demon_wargear_delivery`） | 角色概率（`1.0/0.7/0.35`）；将领保底失败次数（`3`）；刷新间隔（`2年`）；单次最大发放（`1`） | 魔王军备概率、保底和重试控制 |

**数值类遗产参数**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 军事遗产 | 每档攻击加成（默认 `2%`）；每档防御加成（默认 `2%`） | 对王国成员生效 |
| 领域遗产 | 每档范围加成（默认 `3%`）；次数加成公式（默认 `floor((档位-1)/3)`，上限 `3`） | 仅影响 MOD 技能 |

**实现边界与禁止项**
- 遗产相关 trait 只使用三钩子：命中、受击、死亡点。
- 王国装备链路只使用 `generateItem/generateModsFor/tryToPutItem/BehActorTryToTakeItemFromCity`。
- 魔王链路只使用 `generateItem/generateModsFor/ActorEquipment.setItem`。
- 王国装备链路不叠加 MOD 二次概率。
- 王国装备链路只允许入城库门控 + 原版取装。
- 魔王链路必须读取 `demon_wargear_delivery` 并截断越界概率。
- 研究掌控度检查仅在特质新增时执行。
- 禁止全图扫描或高频巡检。
- 禁止使用全局 `ItemAsset.unlock()` 替代资格判定。

## 王国英雄

**定义**
- 王国英雄系统包含抗魔等级、命定英雄、家族继承三部分。
- 抗魔等级是王国维度长期成长。
- 命定英雄是轮回中的关键单位。

**抗魔等级**
- 王国通过击杀魔王阵营单位提升抗魔等级。
- 封印战胜利可提供额外加成。
- 新建或复国王国从 `0` 级开始。

**抗魔等级效果**

| 等级 | 效果1 | 效果2 | 效果3 |
|---|---|---|---|
| Lv1 | 命中 `+5%` | 攻速 `+5%` | - |
| Lv2 | 伤害 `+5%` | 生命 `+5%` | - |
| Lv3 | 体力 `+10%` | 法力 `+10%` | - |
| Lv4 | 防御 `+8%` | 移速 `+5%` | - |
| Lv5 | 暴击率 `+5%` | 暴伤 `+15%` | - |
| Lv6 | 伤害 `+8%` | 防御 `+6%` | - |
| Lv7 | 射程 `+10%` | 投掷射程 `+10%` | - |
| Lv8 | 生命 `+10%` | 移速 `+5%` | - |
| Lv9 | 攻速 `+8%` | 暴击率 `+3%` | - |
| Lv10 | 战斗熟练 `+20%` | 法术熟练 `+20%` | 状态触发 `+10%` |

**命定英雄规则**
- 每王国有数量上限。
- 事件触发为主，定期兜底检测为辅。
- 达到繁荣条件或危机条件时可触发晋升。

**晋升优先级（闭环）**
1. 先检查世界总英雄上限。
2. 再检查王国当前英雄上限。
3. 再检查王国晋升冷却是否结束。
4. 再判断繁荣或危机触发条件是否达成。
5. 以上全部满足后进入候选筛选与评分。

**评分规则**
- 候选池：同王国、存活、非魔王阵营。
- 指标：等级、击杀、生命、攻击、领导力。
- 公式：`综合分 = Σ(min(指标/阈值,1) × 权重)`。
- 从前 `N` 名中随机 `1` 名晋升。
- 现英雄单位不参与评分。

**晋升强化**
- 晋升时随机写入基础值。
- 晋升时抽取英雄随机特质与随机技能。
- 命定英雄固定 `P0「英勇」`。

**英雄随机池与补抽规则**
- 技能池与特质池独立抽取。
- 抽中互斥条目即跳过，不计入数量。
- 持续抽取到数量满足或池内无可用条目。
- 池耗尽仍不足则保留已抽取结果。
- 固定被动：P0「英勇」=基础属性 +10%。
- 条目清单以 `ERRE附属文档/英雄专属随机池.md` 为准。

**家族继承**
- 仅王国新生单位在出生时判定继承。
- 出生入口为 `all_actions_actor_birth`。
- 使用 `parent_id_1/parent_id_2` 追溯最近英雄祖先。
- 英雄祖先存活与否不影响继承判定。

**血脉追溯规则**
1. 出生后读取父母 `parent_id_1/parent_id_2`。
2. 在双亲血脉中选择最近英雄祖先。
3. 双亲都命中时按代数最近优先。
4. 超过可继承代数时终止继承。
5. 无英雄祖先时直接结束。

**后裔继承规则**
1. 命中英雄祖先后按概率判定继承。
2. 属性按“祖先晋升基础值 × 继承比例”写入。
3. 默认规则：继承池只使用英雄随机池条目。
4. 默认规则：仅从祖先已持有条目里抽取。
5. 每代继承次数受上限约束。

**状态存储**
- 血脉根 ID 写入 `custom_data_long`。
- 血脉代数写入 `custom_data_int`。
- 状态随单位存档与读档恢复。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 抗魔等级成长 | 等级上限（`10`）；击杀阈值（`1000/0.5级`）；封印加成（`0.5级/次`） | 抗魔等级成长 |
| 英雄与冷却 | 每王国英雄上限（`1`）；世界总英雄上限（`50`）；晋升冷却（`30年`）；兜底检测间隔（`5年`） | 数量与节奏 |
| 晋升条件繁荣 | 人口阈值（`500`）；城市阈值（`2`） | 繁荣触发条件 |
| 晋升条件危机 | 统计窗口（`10年`）；人口跌幅（`50%`） | 危机触发条件 |
| 候选与评分 | 权重（等级`0.25`、击杀`0.25`、生命`0.15`、攻击`0.15`、领导力`0.20`）；阈值（`10/50/1000/100/100`）；取前N（`3`） | 过滤与评分 |
| 晋升奖励 | 随机特质数（`3`）；随机技能数（`6`） | 晋升强化 |
| 家族继承 | 触发概率（`30%`）；继承属性比例（`30%`）；继承祖先专属特质条目数（`2`）；继承祖先专属技能条目数（`4`）；可继承代数（`10`）；每代继承次数上限（`1`）；晋升评分每档加成（`5%`） | 继承规则 |

## 世界外交

**定义**
- 魔王存活期间可触发世界停战。
- 停战目的是形成共同讨伐窗口。
- 魔王被击败后恢复常规外交。

**规则**
- 触发条件可多选：降临阶段、城市摧毁阈值、世界人口阈值。
- 城市摧毁阈值=废墟城市数/总城市数。
- 满足任一条件即可进入停战状态。
- 停战期间终止王国间战争并统一对抗魔王阵营。
- 复查间隔到达后重新判定是否维持停战。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 停战复查 | 停战复查间隔（`3年`） | 停战维持周期 |
| 触发条件与阈值 | 触发条件（多选）；降临阶段；城市摧毁阈值（`30%`）；世界人口阈值（`5000`） | 任一满足即触发 |

## 叙事事件

**定义**
- 叙事事件只记录真实发生内容。
- 不新增人物、地点、时间。
- 不改变先后顺序和因果关系。

**数据来源**
- 世界历史日志。
- 战争系统与阴谋系统。
- MOD 自定义事件。

**统一事件结构**
```
id: 全局唯一
year: 年份
source: world_log / plot / war / mod
type: city_new / war_started / demon_awake ...
entities: kingdom_id / city_id / unit_id / plot_id / war_id
location: x,y
raw_text: 原文或短句摘要
importance: 重要度
```

**生成流程**
1. 增量采集并记录 `last_year`。
2. 标准化为统一事件结构。
3. 校验死亡时间线：事件 year 大于单位 death_year 时丢弃。
4. 按年份排序并分章。
5. 生成叙事文本并附来源映射。

**LLM 约束**
- 输入只使用结构化事件和规则。
- 输出每段必须附 `event_ids`。
- 无法追溯来源的句子直接丢弃。

## 配置界面

**界面目标**
- 一眼看到轮回、阶段和封印进度。
- 先给结论，再给原因。
- 仅关键事件弹窗，降低噪音。

**界面结构**
- HUD 轻量条常驻显示关键状态。
- 主面板结构为左导航 + 中内容 + 右详情。
- 全局搜索支持快速定位，快捷键是 `Ctrl/Cmd+K`。

**导航栏目**
- 总览：轮回、阶段、王国概况。
- 战局：魔王、将领、军团、英雄列表。
- 魔王图鉴：魔王主题和技能摘要。
- 技能库：技能筛选和开关。
- 封印与遗产：封印进度与遗产清单。
- 事件与日志：时间线和回放。
- 玩法百科：新手指引和核心规则。
- 设置：参数、预设、导入导出。
- 调试：仅开发模式显示。

**页面规则**
- 总览页展示轮回数、阶段、封印进度、魔王态势、遗产档位。
- 战局页按“魔王 → 将领 → 军团”展开。
- 遗迹在全阶段显示状态，仅封印战显示有效进度条。
- 技能库仅展示可用技能，军团单位不入库。
- 封印与遗产页上半区显示遗迹与封印，下半区显示遗产。

**模式分级**
- 玩家模式：只显示安全常用参数。
- 高级模式：显示全部参数。
- 开发模式：显示调试项并二次确认。

**导入导出闭环**
1. 导出：将当前参数写入 JSON。
2. 导入：先解析并检查 `config_version`。
3. 若版本不一致，先执行迁移再校验结果。
4. 展示差异预览，用户确认后继续。
5. 应用前自动创建备份。
6. 应用失败时立刻回滚备份并提示失败原因。
7. 应用成功后写入新配置并记录更新时间。

**导入导出约束**
- 未知字段忽略，缺失字段补默认。
- 导出文件不包含敏感字段。
- 非法值在导入阶段执行统一容错修正。

**视觉规范**
- 风格：信息清晰优先。
- 色彩：青蓝主色、绿色强调、红色警报。
- 字体：标题黑体、正文无衬线。
- 版式：网格对齐，一屏不超过三层信息。

**资产注册原则**
- 单位使用 `ActorAsset` 注册和生成。
- 建筑使用 `BuildingAsset` 注册和放置。
- 特性使用 `ActorTrait/KingdomTrait` 注册。
- 生成点需可行走并避开拥挤地块。

**公共特质注册口径**
- 公共特质表只扩展原版特质编辑器条目数量。
- 只做注册与展示，不改任何逻辑。
- 授予、移除、互斥、效果全部走原版闭环。
- 随机入口池：`pot_traits_birth`、`pot_traits_growup`。
- 随机入口池：`pot_traits_combat`、`pot_traits_mutation_box`。
- 资产字段按原版要求配置：`rate_birth`、`rate_inherit`。
- 资产字段按原版要求配置：`rate_acquire_grow_up`、`is_mutation_box_allowed`。
- 适用对象为 Actor，含魔王/将领/军团。
- 不新增 MOD 随机判定或平衡规则。
- 原版随机只作用 Actor，建筑与城市不参与。

**性能策略**
- 军团 AI 使用低频更新。
- 王国统计按间隔更新。
- 轮回推进使用低频定时器。
- 轮回历史按轮数清理。

**可自定义外观**
- 单位外观和动画。
- 装备外观和能力。
- 建筑与遗迹外观。
- 技能特效与命名标记。

**明确不做**
- 新音效资源加载。
- 骨骼或 3D 动画替换。

## 版本验收

**范围内**
- 轮回系统与阶段推进。
- 魔王、将领、军团自定义生成。
- 纪元遗产与跨轮回继承。
- 王国、英雄、外交机制。
- 事件池与叙事系统。
- 控制面板与配置导入导出。

**范围外**
- 完全控制原版战斗 AI。
- 大规模无上限地形改造。

**验收指标**

| 指标 | 目标 |
|---|---|
| 完整轮回 | 同一存档完成 `5` 次轮回且计数正确 |
| 故事感 | LLM 叙事覆盖 `200+` 事件 |
| 可玩性 | 高轮回仍存在可解路径 |
| 易用性 | 关键参数可调且有分级 |
| 稳定性 | 配置错误不崩溃且有提示 |
| 遗产装备兼容 | 装备编辑器全局可见遗产装备条目且不影响公共特质编辑器 |
| 王国档位隔离 | 世界档位 `6` 且掌控度 `50%` 时，仅生效到 `3` 档装备池 |
| 王国装备流转闭环 | 结算后工艺装备先进城市仓库，再由王国成员按原版逻辑取装 |
| 魔王装备直发闭环 | 无城市前提下，魔王/将领/军团可在生成或刷新时获得军备装备 |
| 魔王参数闭环 | 角色概率、将领保底和周期重试按配置生效 |
| 多 MOD 防串 | 魔王侧仅保留白名单特质，王国侧保持原版逻辑 |
| 存档迁移一致性 | 旧存档升级后不出现全局误解锁，档位和掌控度规则保持一致 |

**遗产装备测试场景**
1. 装备编辑器全局可见遗产装备条目，且不影响公共特质编辑器流程。
2. 世界档位 `6` 且掌控度 `50%` 时，仅生效到 `3` 档池并入城库。
3. 不同王国掌控度不同，装备池隔离生效。
4. 入城库后成员按原版逻辑取装完成流转。
5. 无城市前提下，魔王/将领/军团可获得军备遗产装备。
6. 旧存档升级后不出现误走链路或全局误解锁。

**研究遗产测试场景**
1. 世界档位提升后，研究条目在编辑器全局可见。
2. 随机授予按王国生效档位过滤并复核。
3. 手动授予可绕过王国档位限制。
4. 旧存档迁移后解锁与档位规则保持一致。

**魔王军备参数化测试场景**
1. 魔王生成时必得军备装备（`rate_demon_lord=1.0`）。
2. 将领连续失败达到 `3` 次后触发保底发放。
3. 无可用槽位时按 `weapon > armor > accessory` 替换。
4. 读档后失败次数与发放年份恢复正确。
5. 王国装备链路行为不受影响。

**多 MOD 特质防串测试场景**
1. 外部特质注入后，魔王侧会清理非白名单特质。
2. 王国成员与英雄仍按原版逻辑获取外部特质。
3. 周期刷新与读档恢复后可清理旧污染。
4. 军备直发链路不受影响。
5. 刷新只巡检魔王势力单位，运行无明显卡顿。
