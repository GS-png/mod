## 统一口径

**时间与触发**
- 时间单位使用游戏年份。
- 轮回推进允许低频定时器。
- 技能只允许三钩子触发。
- 三钩子指命中、受击、死亡点。

**事件触发与状态存储**
- 命中使用 `action_attack_target`。
- 受击使用 `action_get_hit`。
- 死亡点使用 `action_on_object_remove`。
- 优先用 `ActionLibrary` 做效果。
- 无现成动作时用自定义 trait。
- 状态写入 `custom_data_int/long/float`。
- 到期与限频只在三钩子内处理。
- 范围效果只在触发点枚举半径。
- 禁止全图扫描与长期名单维护。

**数值口径**
- 百分比按 0%-100% 归一。
- 伤害默认按当前生命计算。
- 默认最低扣到 1HP。
- 伤害倍率以 `damage` 为基准。
- 当前生命字段：`health_current`。
- 最大生命字段：`health_max`。
- 绝对值写 `base_stats`。
- 百分比写 `base_stats_meta`。
- 暴击率最终按 0%-100% 归一。

**配置与容错**
- 可调项进入 UI 与配置文件。
- JSON 必须包含 `config_version`。
- 未知字段忽略，缺失字段补默认。
- 非法值自动修正并提示。
- 时间与数量小于 0 按 0 处理。
- 间隔 <=0 修正为最小正值。
- 概率超出范围按 0-100% 处理。
- `NaN/Infinity` 回退安全值。
- 范围 `min>max` 自动互换。
- 倍率 <=0 修正为最小正值。

**生成与挂载**
- 魔王槽位：P0+S1-S6。
- 将领槽位：P0+S1。
- 军团无技能。
- 魔王/将领/军团用独立模板生成。
- 不改写原版资产。
- 技能 trait 不进随机池。
- 技能 trait 仅在生成或晋升时挂载。

**技能资源与消耗**
- 仅对 MOD 自定义技能生效。
- 主动技能用法力作为资源。
- 触发频率按年限频。
- 频率与消耗均可配置。
- 实际默认值与可调范围以“参数总表/技能法力参数”为准。

**收藏与排版**
- 收藏用 `can_be_favorited` 与 `switchFavorite()`。
- 自动收藏仅作用于魔王/将领/命定英雄。
- 军团不进入自动收藏范围。

## 玩法闭环

**定义**
- 轮回从“魔王被再封印”开始。
- 下一次再封印结束本轮回。

**流程**
1. 预发展
2. 预兆
3. 苏醒
4. 降临
5. 封印战（衰弱）
6. 战后重建

**系统关系**

| 系统 | 主要作用 | 关键输入 | 关键输出 |
|---|---|---|---|
| 轮回系统 | 驱动阶段与结算 | 繁荣度/封印值/轮回数 | 当前阶段/结算结果 |
| 魔王系统 | 决定魔王行为与技能 | 阶段/HP/魔王类型 | 技能激活/强度与行为 |
| 纪元遗产 | 轮回的长期记忆 | 轮回结算数据 | 王国/魔王遗产 |
| 军团波次 | 敌军生成节奏 | 阶段/波次配置/军团库 | 军团生成与规模 |
| 王国与英雄 | 反哺与对抗系统 | 王国/英雄运行态 | 抗魔等级/英雄晋升 |
| 将领系统 | 精英单位与指挥层 | 魔王类型/轮回数 | 将领激活与技能 |
| 军团系统 | 单位库与规格 | 魔王类型/军团配置 | 军团单位与生成规则 |

## 轮回系统

**目标**
- 驱动阶段推进与轮回结算。
- 控制魔王封印、将领封印与封印战。

**阶段详解**

**预发展**
- 触发：游戏开始或战后重建结束。
- 持续：按“预发展_检查间隔”检查繁荣度。
- 表现：魔王与将领封印为初始强度。
- 表现：周围生成魔气节点（可视化）。
- 结束：人口或城市达阈值。

**预兆**
- 触发：繁荣度达阈值。
- 持续：确定魔王据点并显示。
- 持续：军团波次启动。
- 表现：将领封印开始衰减。
- 表现：封印遗迹进入“显形”状态（可见，不可占领，不推进进度）。
- 表现：显示据点标记与将领封印条。
- 结束：将领封印降为 0%。

**苏醒**
- 触发：将领封印为 0%。
- 持续：将领系统激活并生成将领。
- 持续：魔王封印开始衰减。
- 持续：军团波次继续。
- 表现：封印遗迹进入“争夺”状态（可交战，不推进进度）。
- 表现：显示将领标记与魔王封印条。
- 结束：魔王封印降为 0%。

**降临**
- 触发：魔王封印为 0%。
- 持续：魔王实体生成并进入全盛。
- 持续：军团波次继续，生成速度加快。
- 持续：封印遗迹保持“争夺”状态（可交战，不推进进度）。
- 持续：魔王主动进攻。
- 表现：显示魔王标记与视觉效果变化。
- 结束：魔王 HP 低于衰弱阈值。

**封印战（衰弱）**
- 触发：魔王 HP 低于衰弱阈值。
- 持续：军团波次生成时间增加。
- 持续：魔王优先撤退与恢复。
- 持续：封印遗迹进入“激活”状态并允许推进仪式封印。
- 持续：部分将领可能撤退或失控。
- 持续：进入胜利判定。
- 表现：显示虚弱标记。
- 结束：魔王被再封印或击杀。
- 结束：恢复到回退阈值则回到降临。

**胜利判定**
1. 击杀封印：直接击杀魔王。
2. 仪式封印：封印战激活期内，占领遗迹数达阈值且进度满。
3. 双通道：任一达成即胜。

**战后重建**
- 触发：魔王被再封印。
- 持续：结算轮回并发放遗产。
- 持续：重置魔王位置与强度。
- 结果：进入预发展并轮回计数 +1。

**实现要点**
- 轮回数据写入 MOD 存档。
- 读档自动恢复阶段与计数。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 预兆触发 | 世界现存人口阈值（5000）；世界现存城市阈值（20）；预发展_检查间隔（10年） | 人口/城市任一达标进入预兆 |
| 将领封印 | 将领封印_初始强度（100%）；将领封印_衰减速率（1%/年） | 预兆阶段开始衰减 |
| 魔王封印 | 魔王封印_初始强度（100%）；魔王封印_衰减速率（1%/年） | 苏醒阶段开始衰减 |
| 封印胜利 | 封印胜利模式（击杀/仪式/双通道） | 胜利方式选择 |

## 魔王系统

**目标**
- 用状态机驱动魔王行为与强度。
- 支持多魔王互动模式。

**状态机**
- 阶段状态：预发展→预兆→苏醒→降临→封印战→战后重建。
- 战斗子状态：仅在降临生效，全盛/常态。
- 阶段状态决定实体与军团。
- 子状态只影响强度与频率。

**状态行为对照**

| 阶段 | 技能激活 | 军团生成 | 将领数量 | 魔王实体 | 说明 |
|---|---|---|---|---|---|
| 预发展 | 否 | 否 | 0 | 否 | 等待繁荣度触发 |
| 预兆 | 否 | 是 | 0 | 否 | 军团出波，将领封印衰减 |
| 苏醒 | 将领技能 | 是 | 固定 5 | 否 | 将领生成，魔王封印衰减 |
| 降临 | 全部可用 | 是 | 存活数 | 是（全盛） | 魔王入侵 |
| 封印战 | 全部可用 | 是（降速） | 存活数 | 是（虚弱） | 封印战争夺 |
| 战后重建 | 否 | 否 | 0 | 否 | 结算与重置 |

**战斗子状态**
- 全盛：HP 高于全盛阈值，法力恢复 +50%，波次速度 ×2。
- 常态：HP 介于衰弱阈值与全盛阈值之间。
- 转换：HP 低于全盛阈值进入常态。
- 转换：HP 回升超过全盛阈值回全盛。

**魔王成长**
- 公式：`属性 = 基础值 × (1 + 轮回成长倍率 × 轮回数)`。
- 基础值在生成时写入随机值。
- 成长在轮回结算后生效。

**多魔王互动**
- 触发：本轮苏醒数 ≥2 或当前存活数 ≥2。
- 模式：联盟/内战/随机。
- 联盟：共享敌对关系并强制停火。
- 联盟：单体强度小幅下调。
- 内战：魔王互相宣战并继续攻击王国。
- 内战：胜者获得属性加成与称号。
- 内战：参与上限可配置。
- 主导权加成时长可配置。
- 保护：魔王数量 <2 时不生效。

**阵营与外交**
- 魔王阵营单位生成即对所有非魔王阵营单位敌对。
- 魔王阵营单位会主动攻击非魔王阵营单位。
- 王国与魔王阵营保持战争。
- 魔王阵营不建城。
- 魔王阵营不参与外交。

**实现要点**
- 每个魔王使用独立 Kingdom 阵营。
- 宣战/结束战争用 `World.world.wars`。
- 防重复用 `DiplomacyHelpers.isThereFightBetween`。
- 联盟用 `AllianceManager.forceAlliance`。
- 关系按间隔校验并修正。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 魔王池与苏醒 | 魔王启用默认（多选）；魔王苏醒模式（指定/随机）；苏醒数量（1） | 控制本轮魔王 |
| 战斗态阈值 | 全盛 HP 阈值（70%）；衰弱 HP 阈值（30%）；封印战回退阈值（70%）；全盛法力恢复倍率（50%） | 全盛/衰弱控制 |
| 轮回成长 | 轮回成长倍率（25%/轮回）；成长硬上限（250%） | 魔王成长 |
| 多魔王模式 | 互动模式（联盟/内战/随机）；关系校验间隔（3年）；联盟强度系数（85%）；内战强度系数（100%） | 关系与强度 |
| 内战主导权 | 内战最大魔王数（5）；加成时长（10年）；加成属性比例（10%） | 胜者加成 |

## 封印遗迹系统

**定义**
- 封印遗迹是轮回内可见的可互动建筑。
- 遗迹状态统一为“显形/争夺/激活”。
- 仪式封印通过激活状态的遗迹推进进度。

**生成与移除**
- 预兆阶段生成或显形自定义遗迹建筑。
- 苏醒与降临阶段，遗迹保持争夺状态。
- 封印战开始时，遗迹切换为激活状态。
- 生成的遗迹有遗迹范围。
- 再封印后统一移除遗迹。
- 生成点避开深水与拥挤区域。

**仪式封印规则**
- 仅激活状态可触发占领与进度推进。
- 非激活状态进度锁定为 0 增长。
- 范围清场且人数达阈值才能触发占领。
- 占领后进度条持续推进。
- 触发后无需继续驻守。
- 人数离开不暂停进度。
- 敌方人数达阈值则中断或倒退。
- 已占领遗迹数达阈值且进度满即封印。

**遗迹争夺调度**
- 定期派遣“魔王阵营”和“附近王国”小队争夺遗迹。
- 目标策略可选：敌占领/未占领/最近/随机。
- 同阵营收益不叠加。
- 占领后友军获得范围增益。

**实现要点**
- 封印遗迹使用自定义 `BuildingAsset`。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 遗迹数量与占领阈值 | 封印遗迹数量（10）；占领遗迹数量阈值（8） | 遗迹总数与达标要求 |
| 仪式占领与进度 | 仪式占领_人数阈值（10）；仪式进度速度（3%/年） | 占领条件与推进速度 |
| 仪式打断与回退 | 仪式中断_敌方人数阈值（15）；中断处理（暂停/回退/清零）；回退速度（3%/年） | 打断规则 |

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 热点调度 | 热点开关；调度间隔（5年）；目标策略（敌占领/未占领/最近/随机） | 遗迹调度规则 |
| 派遣规模 | 派遣_王国人数（40）；派遣_魔王人数（40） | 每次派遣人数 |
| 占领收益 | 收益半径（12）；友军增益（10%）；叠加上限（1） | 遗迹收益 |

## 遗产系统

**定义**
- 轮回结算时发放纪元遗产。
- 遗产跨轮回继承并长期生效。

**分类与规则**

| 遗产类型 | 规则摘要 | 作用对象 |
|---|---|---|
| 工艺遗产 | 解锁王国装备池，按概率获得 | 王国与英雄 |
| 研究遗产 | 解锁研究技能池，按概率获得 | 王国与英雄 |
| 军事遗产 | 伤害与防御按档位递增 | 王国与英雄 |
| 军备遗产 | 解锁魔王势力装备池，按概率获得 | 魔王势力 |
| 领域遗产 | 领域类技能范围与次数提升 | 魔王与将领 |

**档位规则**
- 世界档位随轮回结算推进。
- 解锁类遗产只扩展清单。
- 数值类遗产按档位叠加。
- 档位上限可配置。

**生效规则**
- 解锁类通过制作/补给概率获得。
- 数值类为被动加成。
- 英雄与精英单位权重更高。

**清单位置**
- 工艺/研究/军备清单在 `ERRE附属文档/遗产档位详表.md`。

**王国掌握度**
- 存活王国直接使用世界档位。
- 新建王国按掌握度折算档位。
- 公式：`生效档位 = floor(世界档位 × 掌握度)`。
- 掌握度范围为 0-100%。
- 最低档位可配置。

**掌握度计算**
- 公式：`掌握度 = 基础分 + Σ(指标分 × 权重)`。
- 指标：书籍、城市、人口、军力、建筑。
- 权重与阈值可配置。

**发放规则**
- 轮回结算时推进档位。
- 第 N 次轮回对应第 N 档。

**实现要点**
- 王国遗产用 `KingdomTrait`。
- 魔王遗产用 `ActorTrait`。
- 解锁类仅扩展池，不直接叠数值。
- 装备与技能为 MOD 自定义资产。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 档位推进 | 遗产档位上限（10）；每轮回档位提升（1） | 档位上限与节奏 |
| 新王国继承 | 新王国档位下限（1）；掌握度刷新间隔（10年） | 新王国继承 |

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 掌握度_基础分 | 数值（0.20） | 固定基础分 |
| 掌握度_书籍类 | 阈值：文化5/宗教5/语言5/首都5/全城20；权重：0.10/0.10/0.05/0.10/0.05 | 书籍评分 |
| 掌握度_规模类 | 阈值：城市5/人口688/军力200/建筑6；权重：0.15/0.10/0.10/0.05 | 规模评分 |

**数值类遗产档位参数（可调）**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 军事遗产 | 每档攻击加成（默认 2%）；每档防御加成（默认 2%） | 对王国与英雄生效 |
| 领域遗产 | 每档范围加成（默认 3%）；次数加成公式（默认 floor((档位-1)/3)，上限 3） | 只影响 MOD 技能 |

- 口径：军事遗产只对王国与英雄生效。
- 魔王侧数值由军备遗产承接。

## 将领系统

**定义**
- 将领是魔王阵营的精英单位。
- 将领负责指挥与关键战斗。
- 每个魔王固定 5 名将领。

**生成规则**
- 将领只在苏醒阶段生成一次。
- 将领死亡后不补充。
- 生成点优先据点或魔王附近。
- 将领槽位固定 P0+S1。

**成长规则**
- 公式：`基础值 × (1 + 轮回成长倍率 × 轮回数)`。
- 基础值在生成时随机写入。

**实现要点**
- 将领用独立模板生成。
- 生成入口为 `ActorManager.spawnNewUnit`。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 轮回成长 | 轮回成长倍率（20%/轮回）；成长硬上限（250%） | 将领成长 |

## 军团系统

**定义**
- 军团是魔王阵营的波次单位。
- 军团用于持续施压并制造节奏。
- 军团单位无技能。
- 军团受同时上限约束。

**波次规则**
- 预兆阶段生成第 1 波。
- 后续按“军团_生成间隔”出波。
- 单波强度递增：`基础强度 × (1 + 递增 × 波次)`。
- 波次强度在出波时计算。

**成长规则**
- 公式：`基础值 × (1 + 轮回成长倍率 × 轮回数)`。
- 基础值在生成时随机写入。
- 叠加顺序：随机值→轮回成长→波次强度。

**生成规则**
- 军团用独立模板生成。
- 转化用替换生成实现。
- 据点不存在时在魔王附近生成。
- 生成点需可行走并避开水域。

**实现要点**
- 军团单位用 `ActorAsset` 直接生成。
- 生成入口为 `ActorManager.spawnNewUnit`。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 波次节奏 | 军团_生成间隔（10年）；军团_初始数量（40）；军团_强度递增（15%/波）；军团_同时上限（300） | 出波节奏与上限 |
| 阶段波次 | 军团_全盛生成间隔（5年）；封印战生成间隔（15年） | 全盛/衰弱生成间隔 |
| 波次数量 | 波次_数量递增（15%/波） | 军团生成波次数量递增 |
| 轮回成长 | 轮回成长倍率（15%/轮回）；成长硬上限（250%） | 军团成长 |

## 王国英雄

**抗魔等级**
- 王国通过击杀魔王阵营单位提升抗魔等级。
- 抗魔等级为王国维度数据。
- 封印战胜利提供额外加成。
- 新建或复国王国从 0 开始。
- 抗魔等级用 `KingdomTrait` 持久化。

**提升规则**
```
击杀魔王阵营单位达到阈值 → 抗魔等级 +1
完成封印战结算（胜利）     → 额外加成
```

**抗魔等级效果**

| 等级 | 效果1 | 效果2 | 效果3 |
|---|---|---|---|
| Lv1 | 命中+5% | 攻速+5% | - |
| Lv2 | 伤害+5% | 生命+5% | - |
| Lv3 | 体力+10% | 法力+10% | - |
| Lv4 | 防御+8% | 移速+5% | - |
| Lv5 | 暴击率+5% | 暴伤+15% | - |
| Lv6 | 伤害+8% | 防御+6% | - |
| Lv7 | 射程+10% | 投掷射程+10% | - |
| Lv8 | 生命+10% | 移速+5% | - |
| Lv9 | 攻速+8% | 暴击率+3% | - |
| Lv10 | 战斗熟练+20% | 法术熟练+20% | 状态触发+10% |

**命定英雄**
- 每王国每轮回有上限。
- 事件触发为主，定期兜底检测。
- 满足繁荣或危机条件时晋升。

**评分规则**
- 候选池：同王国、存活、非魔王阵营。
- 指标：等级、击杀、生命、攻击、领导力。
- 归一化后按权重加权求和。
- 从前 N 名中随机 1 名。

**评分公式**
- `综合分 = Σ( min(指标/阈值, 1) × 权重 )`。

**晋升强化**
- 晋升时随机写入基础值。
- 晋升时抽取英雄专属随机特质与技能。

**英雄随机池**
- 英雄池清单在 `ERRE附属文档/英雄专属随机池.md`。
- 命定英雄固定 P0「英勇」。
- 从技能池随机抽取技能。

**家族继承**
- 定义：仅王国新生单位在出生时判定家族继承。
- 出生入口使用 `all_actions_actor_birth`。
- 使用 `ActorData.parent_id_1/parent_id_2` 追溯最近英雄祖先。
- 英雄存活与否不影响继承判定。

**血脉追溯规则**
1. 出生后读取父母 `parent_id_1/parent_id_2`。
2. 从父母血脉中选择最近英雄祖先。
3. 双亲均命中时按代数最近优先。
4. 超过可继承代数时不触发继承。
5. 无英雄祖先时直接结束。

**后裔继承规则**
1. 命中英雄祖先后按触发概率判定继承。
2. 属性按“祖先晋升基础值 × 继承比例”写入。
3. 特质与技能按配置数量随机抽取。
4. 每代继承次数受上限约束。

**状态存储与校验**
- 血脉根 ID 写入 `custom_data_long`。
- 血脉代数写入 `custom_data_int`。
- 调试可用 `getParents()/getChildren()` 校验。
- 状态随单位存档与读档恢复。

**晋升评分加成规则**
- 遗产档位提供命定英雄晋升评分加成。
- 评分加成只影响候选评分。
- 评分加成不直接增加后裔基础属性。

**实现要点**
- 晋升用 `Actor.addTrait(...)` 完成。
- 命定英雄标记为 `trait_era_destined`。
- 家族继承判定挂在 `all_actions_actor_birth`。
- 血脉追溯依赖 `parent_id_1/parent_id_2`。
- 血脉状态写入 `custom_data_long/custom_data_int`。
- 英雄档案写入 MOD 存档。

**参数表**

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 抗魔等级成长 | 等级上限（10）；击杀阈值（1000/0.5级）；封印加成（0.5级/次） | 抗魔等级成长 |

| 参数组 | 可调控（UI） | 说明 |
|---|---|---|
| 英雄与冷却 | 每王国英雄上限（1）；世界总英雄上限（50）；晋升冷却（30年）；兜底检测间隔（5年） | 数量与节奏 |
| 晋升条件_繁荣 | 人口阈值（500）；城市阈值（2） | 繁荣条件 |
| 晋升条件_危机 | 统计窗口（10年）；人口跌幅（50%） | 危机条件 |
| 英雄候选与评分 | 权重（等级0.25/击杀0.25/生命值0.15/攻击0.15/领导力0.20）；阈值（10/50/1000/100/100）；取前 N（3） | 过滤与评分 |
| 晋升奖励 | 随机特质数（3）；随机技能数（6） | 晋升强化 |
| 家族继承 | 触发概率（30%）；继承属性比例（30%）；继承随机特质数量（2）；继承随机技能数量（4）；可继承代数（10）；每代继承次数上限（1）；晋升评分每档加成（5%） | 继承规则 |

## 叙事事件

**目标**
- 只记录真实发生的事件。
- 不新增人物、地点与时间。

**数据来源**
- 世界历史日志。
- 战争与阴谋系统。
- MOD 自定义事件。

**统一事件结构**
```
id: 全局唯一
year: 年份
source: world_log / plot / war / mod
type: city_new / war_started / demon_awake ...
entities: kingdom_id / city_id / unit_id / plot_id / war_id
location: x,y
raw_text: 原文或短句摘要
importance: 重要度
```

**生成流程**
1. 增量采集，记录 last_year。
2. 标准化为统一结构。
3. 维护死亡时间线校验。
4. 按年份排序分章。
5. 生成叙事文本。

**LLM 模式约束**
- 不新增人物、地点与时间。
- 不改变先后与因果。
- 每段必须能追溯来源。

**一致性规则**
- 真实优先，不写无法验证内容。
- 时间有序，严格按年份排列。
- 角色清晰，不写不存在关系。
- 每章保留事件来源列表。

**LLM 输入与输出**
```
inputs:
  events: [{ id, year, type, raw_text, entities, location }]
  rules: ["不得新增人物/地点/时间", "不得改变先后与因果", "每句必须引用 event_ids"]
outputs:
  paragraphs: [{ text: "...", event_ids: [1,2,3] }]
```

## 属性随机

**规则**
- 仅对 MOD 自定义单位生效。
- 魔王/将领生成时随机一次。
- 军团每波次随机一次并共享。
- 英雄晋升时随机一次。
- 随机值写入基础字段。
- 基础字段包含生命/寿命/防御/伤害/法力上限/体力/暴击率/移速/攻速。
- 随机值覆盖模板同名字段。
- 暴击率写入绝对百分比。
- 叠加顺序：随机值→轮回成长→特质/遗产。

**随机范围（首轮）**

| 单位类型 | 生命 | 寿命 | 防御 | 伤害 | 法力上限 | 体力 | 暴击率 | 移速 | 攻速 | 时机 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 魔王 | 80000-200000 | 99999-99999 | 400-1000 | 800-2000 | 100-300 | 200-500 | 8%-25% | 8-12 | 0.8-1.2 | 生成时 |
| 将领 | 4000-12000 | 99999-99999 | 80-250 | 200-500 | 100-200 | 120-300 | 6%-18% | 10-15 | 0.9-1.3 | 生成时 |
| 军团 | 200-1200 | 99999-99999 | 10-80 | 20-120 | 50-100 | 80-180 | 2%-10% | 9-13 | 0.9-1.3 | 出波时 |
| 英雄 | 2000-8000 | 200-500 | 50-200 | 120-350 | 100-250 | 150-350 | 6%-18% | 10-14 | 0.9-1.3 | 晋升时 |

**随机范围平移**
- 以本轮平均值作为下轮下限。
- 上限保持初始宽度不变。
- 本轮未生成则沿用当前范围。
- 玩家手动改动后清零偏移。
- 英雄不参与平移规则。
- 魔王平均取本轮魔王随机均值。
- 将领平均取本轮将领随机均值。
- 军团平均取本轮波次基准均值。

**界面目标**

**导航栏目**

- 封印与遗产：封印进度与遗产清单。
- 事件与日志：时间线与回放。
- 玩法百科：新手指引与核心规则。
- 设置：参数、预设与导入导出。
- 调试：仅开发模式显示。

**设置与模式**

- 导出不包含敏感字段。
- 导入做版本校验与迁移。
- 导入前自动备份，失败回退。

**视觉规范**
- 风格：信息清晰优先。
- 色彩：青蓝主色，绿色强调，红色警报。
- 字体：标题黑体，正文无衬线。
- 版式：网格对齐，一屏不超过 3 层信息。
