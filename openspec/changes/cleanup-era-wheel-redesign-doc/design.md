## Context

当前《EraWheel_Redesign.md》存在多处口径冲突、重复段落与内容错位，导致阅读与实现依据不一致。本次变更不改代码逻辑，仅对文档内容进行统一口径、合并重排与补全缺失条目，确保出现“唯一权威”的描述。

## Goals / Non-Goals

**Goals:**
- 以 2.1.2 为唯一权威，统一阶段触发/封印衰减描述并同步状态图。
- 将领数量固定为 5 名，军团无技能，遗产数值口径改为“递增”。
- 删除“第 2+ 轮回自动进入预兆”的说法，保证每轮完整流程。
- 补齐“英雄技能池”并确保字段完整、可直接查用。
- 对重复内容执行“合并成新内容或融合进现有内容并删除原文”，避免遗留引用痕迹。
- 修复目录/锚点与跨章节跳转。

**Non-Goals:**
- 不调整游戏数值或玩法设计，只改文档表述。
- 不引入新系统或新章节，仅在现有结构内合并与归位。
- 不新增实现细节或代码层面的改动。

## Decisions

1) **合并策略采用“生成新 C 或融入 B 并删 A”**
- 备选：保留旧段落并加“参见”引用
- 选择理由：避免遗留痕迹，减少读者跳转负担，形成唯一权威表述。

2) **以 2.1.2 作为轮回阶段口径唯一权威**
- 备选：融合 2.1/2.2/2.4 的多版本描述
- 选择理由：2.1.2 描述最完整，且用户明确指定为正确来源。

3) **英雄技能池补齐在 2.5.2 主体段落，并在附录给出清单**
- 备选：仅在附录补齐
- 选择理由：2.5.2 是规则主入口，读者更易发现；附录用于速查。

4) **重复表格只保留一份权威表**
- 备选：保留多份表格并保持内容完全一致
- 选择理由：多表维护成本高，容易再次产生口径偏差。

## Risks / Trade-offs

- [Risk] 大量移动与合并可能导致锚点失效 → Mitigation：逐段检查目录与锚点，必要时重建锚点并更新目录。
- [Risk] 合并后信息密度过高影响可读性 → Mitigation：合并时重写为“新 C”，保持条理化结构与必要的小标题。
- [Risk] 删除旧段落可能误删需要的细节 → Mitigation：合并前先梳理 A/B 要点并确认全部融入 C。
