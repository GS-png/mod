## Why

现有文档内容分散、重复与错位明显，阅读成本高且容易产生理解偏差。现在需要集中梳理，形成唯一权威与清晰路径，便于开发与玩家快速定位信息。

## What Changes

- 重排文档结构：按“使用指南 → 概述 → 玩法闭环 → 系统细节 → 数值 → UI → 技术 → 版本 → 默认值 → 附录”组织。
- 合并/删除重复段落与提示语，建立单一权威来源。
- 纠正错位内容，归并到对应章节，减少跳读。
- 统一段落模板与写法（概念→触发→持续→表现→结束→参数入口→实现引用）。
