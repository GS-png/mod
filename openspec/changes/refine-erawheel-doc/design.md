## Context

- 目标文档：`EraWheel_Redesign.md`
- 当前问题：内容重复、错位、跳读、提示语反复出现，导致阅读成本高
- 约束：不改动玩法含义与默认值，不新增机制，不改代码；只做结构整理与表述优化

## Goals / Non-Goals

**Goals:**
- 建立清晰的阅读路径与章节顺序
- 去重与合并，形成唯一权威来源
- 纠正错位内容，保持章节语义一致
- 统一段落模板与写法，降低阅读负担
- 保持目录与锚点可用

**Non-Goals:**
- 不改变任何玩法规则与数值含义
- 不新增、删除或调整系统功能
- 不修改实现口径与技术方案（仅移动与整理）
- 不改动代码或资源文件

## Decisions

1. **按“使用指南 → 概述 → 玩法闭环 → 系统细节 → 数值 → UI → 技术 → 版本 → 默认值 → 附录”重排**
   - 理由：先让读者建立阅读路径，再从玩法闭环进入细节，最后集中参数与大表。
   - 备选方案：保持原顺序，仅做局部移动；但难以消除跳读。

2. **统一口径提示语集中到“使用指南”**
   - 理由：减少重复提示与噪音；正文只保留一次引用。
   - 备选方案：各章节保留提示；仍会造成反复。

3. **保留“玩家视角/开发视角”双线，但以节末简短提示呈现**
   - 理由：满足不同读者需要，同时不打断主线叙述。

4. **采用固定段落模板（概念→触发→持续→表现→结束→参数入口→实现引用）**
   - 理由：读者可以形成固定阅读节奏；利于快速检索。

## Risks / Trade-offs

- [风险] 章节移动导致目录/锚点失效 → [缓解] 每次移动同步更新目录与锚点引用，最终检查跳转
- [风险] 合并时遗漏细节 → [缓解] 合并前做“去重清单”，逐条对照保留要点
- [取舍] 文本更短但信息密度提高 → [缓解] 保留“快速检索入口”和表格索引

## Migration Plan

- 先输出“移动/合并/删除清单”作为检查表
- 按清单重排章节与内容
- 更新目录与锚点
- 完成自检：目录跳转、关键表格索引、段落模板一致性
