## Context

当前 EraWheel_Redesign.md 体量很大，规则、UI、实现与参数交叉出现，存在重复与错位，阅读成本高且容易造成“口径不一致”。本次变更只做文档整理，不改玩法与数值。

## Goals / Non-Goals

**Goals:**
- 形成单一权威结构：规则、UI、实现、参数、附录各归位
- 去重与合并：同一内容只保留一处，其他位置仅引用跳转
- 纠正错位内容，确保上下文连续、阅读顺畅
- 维持“方案 B”：各系统保留简短参数入口表，默认值仍只在第七部分
- 锚点与目录一致，引用可用

**Non-Goals:**
- 不修改任何数值、规则或玩法含义
- 不合并或改动其他文档（除非后续明确要求）
- 不引入新的功能设计或实现细节

## Decisions

1) **采用“方案 B”参数入口表**
- 选择：各系统保留简短入口表，默认值统一在第七部分
- 备选：集中所有入口表到第七部分
- 理由：既保留就近查找的便利，又避免默认值分散

2) **十魔王列表只保留一处权威表述**
- 选择：保留完整列表在“魔王图鉴”或“核心特色”中的单一位置，其它改为引用
- 备选：多处重复列表
- 理由：减少重复与维护成本

3) **英雄技能实现细节移入附录**
- 选择：正文只保留规则与入口，细节集中到附录
- 备选：正文保留完整实现细节
- 理由：正文面向规则阅读，细节放附录更清晰

4) **不改动含义，只重排与去重**
- 选择：通过“移动/合并/删除重复”达成清晰结构
- 备选：同时微调规则措辞或数值
- 理由：避免引入新的含义变化与争议

## Risks / Trade-offs

- [锚点变更导致链接失效] → 统一校验目录与内部跳转，必要时保留旧锚点别名
- [去重时误删关键信息] → 合并前标注来源与唯一权威，合并后对照核对
- [内容错位未完全发现] → 逐章复核“规则/UI/实现/参数/附录”归位清单
- [读者习惯被打断] → 保留清晰的“推荐阅读顺序”和快速入口

## Migration Plan

1) 先按新结构整体重排（只移动，不改字）
2) 再逐段合并去重与删减重复
3) 更新目录、锚点与交叉引用
4) 全文通读与链接自检
