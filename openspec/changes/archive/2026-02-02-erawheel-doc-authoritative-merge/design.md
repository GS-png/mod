## Context

- 目标文档：`EraWheel_Redesign.md`（约 2300 行）。
- 现状：内容重复、错位、提示语过密，导致阅读成本高且容易误解口径。
- 约束：不改玩法含义与默认值，不新增机制，不改代码；只做结构整理与表达优化。
- 合并规则：A+B 合并为全新 C 或并入 B 后删除 A；不保留残留引用，除非必须指向附录或默认值索引。

## Goals / Non-Goals

**Goals:**
- 建立清晰阅读路径与稳定章节顺序。
- 合并重复内容并删除源段落，形成“唯一权威”描述。
- 错位内容归位，减少跳读。
- 统一写法与提示密度，让文档干净、简洁、具体且完整。
- 统一目录与锚点，保证跳转可用。

**Non-Goals:**
- 不改动任何规则含义、数值默认值或系统功能。
- 不新增或删除玩法机制。
- 不修改代码与资源。
- 不同步整理其它文档（`WorldBox「纪元之轮：魔王轮回」MOD 完整设计文档.md`、`设计1.md`）。

## Decisions

1. **结构按“使用指南 → 概述 → 系统细节 → 数值 → UI → 技术 → 版本 → 默认值 → 附录”线性排序**
   - 理由：先建立全局，再逐层深入，降低跳读。
   - 备选：保持原顺序仅局部调整，难以根治重复与错位。

2. **口径集中到唯一权威位置**
   - 术语只在“术语速查”，默认值只在“第七部分”，实现口径只在“附录A”，大表只在附录。
   - 理由：避免正文多处重复与冲突。
   - 备选：正文保留多份，风险是口径漂移。

3. **参数入口统一为“索引式引用”**
   - 正文只保留指向 7.1.x 的链接，删去每节参数入口表。
   - 理由：减少冗余、便于统一维护。
   - 备选：保留参数入口表，仍会造成“多处重复”。

4. **提示语密度收敛**
   - 每个大章保留 1 条提示语，小节不反复提示。
   - 理由：提升可读性与信息密度。

## Risks / Trade-offs

- [风险] 合并时遗漏细节 → 逐节对照清单，合并后再通读校验。
- [风险] 目录与锚点失效 → 完成后统一检查目录跳转。
- [取舍] 文本更短、信息更密 → 在“快速入口/索引”保留检索提示，降低学习成本。
