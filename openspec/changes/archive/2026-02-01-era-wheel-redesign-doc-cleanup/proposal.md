## Why

当前《EraWheel_Redesign.md》存在阶段口径冲突、重复内容、错位章节与无效承诺，阅读成本高且容易误导实现。需要把口径统一成单一权威、删除无用描述，并把内容归位，让文档干净、简洁、完整、可执行。

## What Changes

- 统一轮回阶段口径为 6 阶段：预发展 → 预兆 → 苏醒 → 降临 → 封印战（衰弱期） → 战后重建，并同步流程图、状态图与 UI 流程条。
- 明确阶段触发链：世界达到繁荣度阈值进入预兆；预兆阶段开始将领封印衰减；将领封印归零进入苏醒；苏醒阶段开始魔王封印衰减；魔王封印归零进入降临。
- 合并“衰弱 + 封印战”为同一阶段：魔王 HP < 30% 立即进入封印战（衰弱期）；封印胜利模式为“击杀 / 仪式 / 双通道（任一达成即胜）”；回退阈值逻辑保留。
- 军团波次从预兆阶段开始生成；封印战（衰弱期）军团生成降速 50%（非暂停），新增对应 UI 参数。
- 删除无效或未定义内容：失败/灭绝/终焉结算、宿敌/相性表等。
- 将领成长口径改为与魔王相同的成长公式（基础模板 × 轮回倍率 × 轮回数），移除“将领平均等级起始值/上限”这类无参数入口的描述。
- 去重与归位：规则留在核心系统，参数只在第七部分，玩家说明只在第四部分，附录只放大表（技能池、名册等不再重复）。
- 删除“封印战_持续年数/衰弱_持续年数”相关描述与参数，避免与封印胜利/回退逻辑冲突。
- 删除无效或未定义的内容（失败/灭绝/终焉结算、宿敌/相性表等）。
- 去重与归位：规则留在核心系统，参数只在第七部分，玩家说明只在第四部分，附录只放大表。
