## Why

现有 `EraWheel_Redesign.md` 内容重复、错位与跳读明显，阅读成本高且容易误解实现口径。现在需要一次性整理为“唯一权威”的清爽版本，方便开发与玩家快速定位。

## What Changes

- 重排章节顺序，按“使用指南 → 概述 → 玩法闭环 → 系统细节 → 数值 → UI → 技术 → 版本 → 默认值 → 附录”组织。
- 对重复内容执行“合并后删除源文”规则：把 A+B 融合为新 C 或并入 B 后删除 A，不保留残留引用/痕迹（除非必须链接附录或默认值）。
- 纠正错位段落与表格，让内容回到语义一致的章节。
- 统一段落写法与提示语密度，减少啰嗦与噪音。
- 更新目录与锚点，保证跳转可用且不迷路。

## Capabilities

### New Capabilities
- `erawheel-doc-merge-cleanup`: 对 `EraWheel_Redesign.md` 做结构重排、合并去重、错位归位与阅读路径优化，并严格执行“合并后删除源文”的规则。

### Modified Capabilities
- （无）

## Impact

- 影响文档：`EraWheel_Redesign.md`（章节顺序、段落组织、目录与锚点链接）。
- 不影响代码与运行逻辑。
