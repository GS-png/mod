## Why

当前 `EraWheel_Redesign.md` 内容分散、重复、跳读频繁，读者很难一次看懂规则。为了避免实现口径不一致，现在需要整理成结构清晰、唯一权威、易查阅的版本。

## What Changes

- 重排章节顺序，按“概述 → 核心系统 → 玩家 UI → 技术基础 → 版本规划 → 附录”组织。
- 将规则、默认值、实现入口合并到同一系统小节，减少跨章引用。
- 合并重复段落，移动错位内容，删除冗余说明与残留引用痕迹。
- 更新目录与锚点，保证跳转一致。
- 仅整理文档，不改玩法目标与数值，不改其他文档。

## Capabilities

### New Capabilities
- `doc-structure-cleanup`: 规范 `EraWheel_Redesign.md` 的结构与唯一权威口径，明确每类内容的唯一位置与合并规则。

### Modified Capabilities
- 无

## Impact

- 影响文件：`EraWheel_Redesign.md` 的章节结构、目录、锚点与段落组织。
- 不影响代码、API、依赖与其他文档。
