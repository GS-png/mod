# 纪元之轮重设计文档清理

## Purpose
TBD：同步并统一「纪元之轮：魔王轮回」重设计文档的关键口径与结构。

## Requirements

### Requirement: 轮回阶段口径统一
文档必须（MUST）以 2.1.2 的“轮回阶段详解”为唯一权威，并保持全篇一致：阶段为 6 段（预发展 → 预兆 → 苏醒 → 降临 → 封印战（衰弱期） → 战后重建）。预兆触发为“世界达到繁荣度阈值”；进入预兆后出现魔王势力生成地点、军团从该地点生成、将领封印按设定速率衰减；将领封印从 100% 衰减到 0% 后进入苏醒并一次性生成 5 名将领，同时魔王封印开始衰减；魔王封印从 100% 衰减到 0% 后进入降临；魔王 HP < 30% 后立即进入封印战（衰弱期），并执行封印战规则（含击杀/仪式/双通道胜利与回退阈值）。文中不得再出现与此相冲突的触发与阶段描述。

#### Scenario: 核心章节一致
- **WHEN** 审阅者对比 2.1.2、2.2 状态图、2.4 的阶段触发描述与 4.4 流程条
- **THEN** 阶段名称与触发链完全一致，且不存在“衰弱与封印战分离”或“军团非预兆生成”的描述

### Requirement: 轮回完整流程
文档必须（MUST）明确每一次轮回都完整经历预发展→预兆→苏醒→降临→封印战（衰弱期）→战后重建，不得出现“第 2+ 轮回自动进入预兆”的表述，并同步更新状态图与流程条。

#### Scenario: 状态图与正文一致
- **WHEN** 审阅者对比 2.1.2、2.2 状态图与 4.4 流程条
- **THEN** 均展示 6 阶段完整流程，且不存在“自动跳过预发展”或“衰弱/封印战双阶段”的说法

### Requirement: 封印战阶段参数清理与补充
文档必须（MUST）移除 `衰弱_持续年数` 与 `封印战_持续年数` 的默认参数与描述，并在“军团与波次”参数中新增“封印战（衰弱期）波次速度倍率”参数，默认值为 `0.5`（降速 50%，非暂停）。

#### Scenario: 参数表一致
- **WHEN** 审阅者检查 7.1.1 与 7.1.3 参数表
- **THEN** 不再出现 `衰弱_持续年数` 与 `封印战_持续年数`，且新增“封印战（衰弱期）波次速度倍率 = 0.5”

### Requirement: 将领数量固定
文档必须（MUST）明确将领数量为“每个魔王固定 5 名”，删除“随轮回增长/可扩展”的矛盾口径，并在所有涉及将领数量的段落中保持一致。

#### Scenario: 数量口径一致
- **WHEN** 审阅者检查 2.1、2.4 与 3.2
- **THEN** 将领数量仅出现“固定 5 名”，不存在增长或上限扩展的说法

### Requirement: 将领成长公式统一
文档必须（MUST）将将领成长口径统一为与魔王相同的成长公式（以将领模板基础属性为基准，按轮回倍率与轮回数增长），并移除“将领平均等级起始值/上限”等无参数入口的描述。

#### Scenario: 成长口径一致
- **WHEN** 审阅者检查 3.2 将领成长与 7.1 参数表
- **THEN** 将领成长仅引用与魔王一致的公式，且不存在独立的将领等级起始值/上限参数

### Requirement: 军团无技能
文档必须（MUST）明确军团单位不具备技能，并移除与“军团技能”相关的描述或筛选项。

#### Scenario: 技能库不包含军团
- **WHEN** 审阅者查看 2.4.3 与 4.7 的技能库说明
- **THEN** 均明确“军团无技能”，且技能库筛选不包含“军团”

### Requirement: 遗产加成递增
文档必须（MUST）将数值类遗产的成长口径统一为“递增”（档位越高，增量越大），并移除“递减”或自相矛盾的表述。

#### Scenario: 口径无矛盾
- **WHEN** 审阅者检查 2.3.2 的遗产描述与表格
- **THEN** 对递增/递减的描述仅保留“递增”，且语义一致

### Requirement: 英雄技能池补齐
文档必须（MUST）补齐“英雄技能池”清单，并给出可读字段（名称、触发方式、效果一句话、消耗/频率口径、限制条件）。清单至少包含以下条目（保持与既有示例一致）：
- `trait_era_hero_skill_smite`
- `trait_era_hero_skill_guard`
- `trait_era_hero_skill_charge`
- `trait_era_hero_skill_heal`
- `trait_era_hero_skill_blink`
同时明确命定英雄固定被动为 P0「英勇」，S1 从技能池中抽取。

#### Scenario: 技能池可直接查用
- **WHEN** 审阅者进入 2.5.2 或对应附录
- **THEN** 能看到完整技能池表，且包含以上 5 项并字段齐全

### Requirement: 无效内容清理
文档必须（MUST）删除未定义或无逻辑支撑的内容与引用，包括“失败/灭绝/终焉结算”分支描述与“宿敌/相性表”相关表述，并不得在正文、流程图、附录或目录中保留暗示性引用。

#### Scenario: 关键词清理
- **WHEN** 审阅者搜索“终焉结算”“宿敌”“相性表”“失败/灭绝分支”相关关键词
- **THEN** 文档中不再出现对应条目或引用

### Requirement: 去重、归位与目录修复
文档必须（MUST）对重复内容执行合并：要么将 A 与 B 融合为全新的 C 并删除 A/B；要么将 A 融合进 B 并删除 A。除非为强制引用或阅读路径所必需，否则不得保留指向旧段落的引用痕迹。规则只保留在第二部分，参数只在第七部分，玩家说明只在第四部分，附录只放大表；目录与锚点必须可正确跳转。

#### Scenario: 合并无遗留痕迹
- **WHEN** 审阅者搜索被合并内容的关键词
- **THEN** 只命中合并后的唯一段落，不出现旧段落或“参见原处”的残留描述

#### Scenario: 目录与跳转正确
- **WHEN** 审阅者点击目录与附录链接并检查重复段落
- **THEN** 链接可跳转到正确位置，重复内容仅保留一处权威版本
