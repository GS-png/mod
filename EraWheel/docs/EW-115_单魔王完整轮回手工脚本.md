# EW-115 单魔王完整轮回手工脚本

## 记录目的
- 这份脚本对应 `EW-115`。
- 目标不是做长时间平衡测试，而是稳定复现一次“预发展 -> 预兆 -> 苏醒 -> 降临 -> 战后重建”的最小闭环。
- 它默认你会使用当前已经存在的调试按钮来缩短流程。

## 前置准备
- `Observed`：当前调试窗口已经有 `强制跳到预兆`、`强制跳到苏醒`、`强制跳到降临`、`重置双封印`、`强制进入战后重建` 这几类动作。
- 建议先在参数里只保留 `1` 名启用魔王，并把 `苏醒数量` 设为 `1`。
- 建议开启开发模式，方便直接打开调试窗口。

## 脚本步骤
1. 启动带 `EraWheel` 的环境，确认没有出现 `EraWheel 启动自检失败`。
2. 打开 `EraWheel -> 轮回系统 -> 运行态`，记录当前阶段应为 `预发展`。
3. 打开调试窗口，点击 `强制跳到预兆`。期望看到本轮魔王数为 `1`，据点绑定为 `1`，并且已经开始记录事件流水。
4. 点击 `强制跳到苏醒`。期望看到将领生成完成，且当前魔王绑定将领数为 `5`。
5. 点击 `强制跳到降临`。期望看到魔王实体生成，军团波次继续推进，故事列表开始出现本轮素材。
6. 如果要测真实战斗，就继续观察一段时间；如果只做闭环烟测，直接点击 `强制进入战后重建`。
7. 返回轮回运行态，确认结算顺序走完后阶段回到 `预发展`，并且轮回数只在重建完成后 `+1`。
8. 打开故事生成器，确认能看到本轮事件素材，并且故事导出还能正常写出 Markdown。

## 通过标准
- 单魔王轮回能稳定走通，不出现重复生成将领、魔王或据点。
- 战后重建结束后，下一轮状态被正确重置，但轮回历史和事件素材被保留下来。
- 故事列表、运行态摘要和事件日志三处对同一轮的描述没有互相打架。

## 未验证边界
- `Unknown`：完全不借助调试按钮、纯自然推进一整轮的时长和稳定性，还需要真实长局继续补记录。
